# 单侧可见眼球局部仿射面实验：拒绝

2026-11-19。仅新增 `observed_ocular_v6.py`，V5 与全部依赖保持冻结。没有读取新照片结果、没有调整检测器、场、强度、独立 fixture 或门槛。

## 假设与唯一变化

已知失败：V5 在眼睑根部无法同时找到细睫毛两侧的可见眼球供体，部分真实前景仍被旧核心 E=1 冻结。

候选假设：在既有细线支撑下，眼球 RGB 可由附近可见眼球的低阶平面在有限距离内估计。该假设允许单侧外推，不要求未知眼球已被直接观测。

V6 保持 V4 材料判定以及 V5 成功的双侧估计，仅对 V5 未能估计的既有 ridge + 1 px 支撑使用局部仿射面。源供体限定为 V4 原有眼球核心锚点，排除全部细线支撑，且位于源眼裂内至少 1 px。

- 局部 RGB 模型：`B(dx,dy) = b0 + bx*dx + by*dy`，三色通道独立拟合。
- 固定半径 `2*band = 6` 源像素，紧支撑 biweight `(1-r²)²`。
- 至少 6 个源观测拟合 3 系数；归一化设计矩阵条件数不超过 1000。
- 无效、非有限或越 RGB 边界的外推值直接拒绝，不裁剪或投影 B。
- 沿用 V5 的眼球/睫毛混合比例拟合和物理可行上界；没有为亮点、暗纹增加例外。
- 空间边界有限不等于语义正确：这只能填极窄已准入细线下的平滑底色，不能恢复未知高频虹膜纹理，不能跨颜色突变保证准确。

## 冻结独立测试结果

| 测试 | V5 | V6 | 固定标准 |
|---|---:|---:|---:|
| 真实睫毛一次运动的最终 RGB RMSE | 5.899756，失败 | **1.636500，通过** | < 5.650029 |
| 真实睫毛暗线质心误差 | 前一 RGB 断言先失败 | **0.061205 px，通过** | < .25 px |
| 可见虹膜亮/暗纹最大 RGB 误差 | 通过 | **170.285931，失败** | < 1 |

单侧源表面估计确实修正了这个已知睫毛样例的运动，但是整体候选失败，不能上线、不能用它提升可用评分。

## 失败因果

无睫毛 fixture 中，V4 仍识别出一条 8 像素的暗线 track；其 source pigment `[50.38,76.71,94.75]` 实际来自正常虹膜。V5 的双侧供体不可用此前碰巧阻止了这部分外推。

V6 给这条错误 track 的已有 1 px 支撑补上了 B，源像素 `(35,17)` 的正常高光 `[242,246,249]` 被底色 `[92.01,107.87,125.59]` 取代，受物理残差上界限制 E 变为 .046。其高光于是被解释为会移动的前景，最终 RGB 变成 `[71.71,94.87,111.90]`。相邻像素虽保留源 E=1，目标采样也受污染。

结论不是单侧拟合无效，而是 **底色修复无法弥补错误的前景支撑**。当前 V4 的材料判定与 1 px 支撑还不能可靠区分睫毛和高频眼球纹理。不得通过亮点特例、缩强度或放宽测试门槛接受 V6。

## 后续只读判别：源颜色线残差不能单独解决假 track

保持全部代码不变，直接量测可行性 cap 之前的有界两色模型：

`min(0 <= E <= 1) RMS(C − E*B − (1−E)*L)`。

两个固定源的旧噪声估计都为 1.0：`max(1, 1.4826*median(abs(Y−gaussian(Y,.6))))`。这是旧源亮度尺度及其下限，不是经标定的三通道噪声概率模型；下表提供尺度比较，不声称统计显著性。

| 固定源位置 | 已知角色 | 最小颜色线 RMS | 拟合 E（cap 前） |
|---|---|---:|---:|
| 无 lash `(35,17)` | 高光 | 137.605 | 1.000（无界值 4.927） |
| 无 lash `(35,16)` | 高光目标采样的上邻正常虹膜 | .282 | .0373 |
| 无 lash `(36,16)` | 另一上邻正常虹膜 | .422 | .0781 |
| 无 lash `(33,16)` | 被选作 pigment 的正常虹膜 | 0 | 0 |
| 无 lash `(38,17)` / `(39,17)` | 原有暗纹锚点 | 0 | 1 |
| 真 lash `(32,16)` | 根部抗锯齿边，coverage .594 | .786 | .3785 |
| 真 lash `(33,18)` | 线身边，coverage .563 | .181 | .4440 |
| 真 lash `(35,18)` | 线身边，coverage .719 | .475 | .3061 |
| 真 lash `(35,19)` | 线身，coverage .797 | .428 | .2186 |
| 真 lash `(38,21)` | 尖端边，coverage .344 | .215 | .6484 |
| 真 lash `(35,20)` | 极薄边，coverage .0156 | 4.010 | 1.000（无界值 1.048） |

高光的颜色根本不能由该 B/L 线段解释，cap 却把它改写成任意合法前景残差；模型拟合拒绝可以防止这类明显错误。然而输出 `(35,17)` 实际反采样源 `(35,16.10328)`，其中约 89.7% 的来源是 `(35,16)`。该正常虹膜像素被错误解释成 E=.0373 的前景，却有低于旧噪声尺度的 .282 RMS，因此只拒绝高光自身仍无法避免其被错误前景覆盖。

假 track 的 20 个估计像素颜色线 RMS 中位数 .396，真实 lash 22 个估计混合像素中位数 .346，明显重叠；最薄真实睫毛边由于 B 偏差反而具有更大残差。**颜色线拟合是必要的模型一致性检查，但不足以识别暗纹和睫毛身份，也不能成为另一个阈值补丁。** 单 RGB 中同色/近共线解释存在歧义，需要在完整源估计里比较眼球纹理与前景遮挡解释，并使用独立的结构/语义证据。

完整数值保存在同一结果目录 `color-line-readonly.json`。此次没有产生 V7，没有试跑新的准入阈值或修改任何估计器。
