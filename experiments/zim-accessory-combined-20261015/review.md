# 用户耳饰源图审核

2026-10-15。目标是解决被误冻在耳饰旁的旧脸颊肤色条，先核对源分层。没有调整几何、强度、源 RGB 或 raw alpha；没有进行生产接入。官方 score argmax 在十组调用中均为候选 2，四十张候选全部保存。分数只描述模型自身估计，不是语义正确率。

## 肤色条与未知区

源皮肤支持沿用既有规则：skin>=.9 且其它受保护语义<.05 为锚点；待诊断像素需 skin>=.5 或满足最近局部锚点均值的 Lab 色差条件，同时距离受限并排除 ears/features。模型低 alpha 只是“不是该饰品的候选”，不是“必然是皮肤”。规则数值未改变。

下表统计官方候选从原组件排除的像素（alpha<=.05），`支持`只是独立源皮肤证据，仍待变形及 F/B 验证。

1:1 原图与放大观察一致：原 parser 包含饰品与脸颊之间的暗间隙，且内侧带有一条连贯的源肤色边。新的各模式把大部分肤色边排除，同时排除了较多深色区域。combined-point 的 1522 个排除像素中，仅 222 个符合源皮肤证据，其余 1300 个维持 unknown。不能把整个饰品包络内侧填成皮肤。

这两只耳饰中，旧 upstream-mixed 与 corrected combined-point 的源皮肤支持回收数相同，均为 222；因此不能把该数量归功于 adapter 修正，或声称修正带来新增皮肤召回。这里相对粗 parser 的改善主要来自 ZIM 物体边缘候选；corrected 调用解决提示输入契约，未知区的小幅变化还需实际物理合成判定。

右耳饰对应组件 2，绿色支持域位于饰品左侧贴脸窄条；左耳饰组件 1 的绿色支持域位于饰品右侧贴脸长条。饰品与皮肤之间较宽的深色部分、耳钉上方耳垂附近，以及外部背景没有足够皮肤证据。

## 孔洞、金属高光与保真边界

两个 parser 组件均为没有内部二值孔洞的包络。十个官方 raw alpha 在 `.5` 阈值下的组件内封闭孔洞也均为 0；这只说明模型给出的 binary topology 近似实心，不证明实物没有孔洞，更不是把孔洞填成皮肤的依据。原图金属环内暗部可能来自穿孔、透明宝石、反射或背景，单图无法仅靠 alpha 消除歧义，保持 unknown。

为核查亮金属是否被擦掉，保留原坐标下原图/parser/四候选完整对照，并补充参考组件内源 sRGB 通道均值最高 10% 的诊断；该强度集合不是金属真值。combined-point 右侧 223 个亮部诊断像素 alpha 均值 .999627、最小 .960036；左侧 216 个均值 .999339、最小 .952904。肉眼未见亮链条整体消失，但耳钉附着处与混合边仍需 F/B 后实际图像检验。不能把平均 alpha 接近 1 等同于高光 100% 保真。

所有 alpha 仍是模型候选，无物理 matte 认证。仅在源肤色支持域上实验“固定饰品前层 + 可变皮肤后层”，保留金属源纹理坐标；unknown 孔隙不得参与皮肤回填。实际 ±100 几何、原尺寸接缝和脸颊位移由独立的 accessory-skin-decomposition 实验继续核验。
