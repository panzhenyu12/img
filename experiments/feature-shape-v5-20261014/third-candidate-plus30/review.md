# 第三候选：eyeSpacing +30 鼻梁软锚定

这是针对第二候选失败中“鼻梁边界导致速度场陡变”的单项因果实验。输入是真实用户原尺寸 1024×1024 图，唯一调整是 `eyeSpacing=+30`。完整眼缘仍使用同一 SE(2) 目标：左眼平移 **+5.678 px**、右眼 **−5.686 px**；没有缩放、裁剪、减小眼睛主体或改 slider 目标。

第二候选固定鼻梁约束与去掉鼻梁约束的消融，输出差异集中在鼻梁到内眼角的垂直带：最大 RGB 差 42；逆映射 x 差最多 4.61 px。第二候选固定鼻梁场的局部速度梯度最高约 **2.89 px/px**，而去掉约束会让鼻梁跟着眼睛运动，破坏鼻梁稳定性。因此暗带的可验证主因是眼包络向鼻梁固定边界传输时的高梯度，源图边界采样不是首要因果。

第三候选只把鼻梁边界 penalty 从硬权重降为有限权重 **0.18**，让 screened biharmonic 场在皮肤中扩散部分应变；眼睛的 rigid core 和实际移动保持不变。速度梯度降至约 **2.62 px/px**，眼缘面积/边长保持 1.0，眼缘 inverse 误差约 0.0013 px。输出相对第二候选最大 RGB 差 5，鼻梁 ROI 平均差约 0.015，说明这只是小步实验，尚不能宣布自然度达到目标。

## 当前判断

该候选证明“有限鼻梁锚定”确实能降低运输场梯度，但需要人工查看原尺寸图决定是否继续；它没有解决第二候选全部问题，也没有做 ±100 或其他照片扩展。`third-candidate-plus30/user-eyeSpacing30-comparison-2x.png` 是唯一建议审阅的候选图，`causal-report.json` 保留请求/实际 pose、场梯度和最终 mapper 指标。

源码与 immutable worker 仍只在实验目录，正式 Web/API 与 V4b 生产 geometry 未接入。
