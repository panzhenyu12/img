# 有界源一致 F/B：独立审核

审核范围：`project.py`、`replay.py`、`test_project.py` 及 `outputs/` 的两个 ±30 冻结结果。未修改实现、生产或任何上游冻结数据。按 code-review 的规范与功能两个角度检查；此范围未发现额外 AGENTS/贡献规范。该目录是诊断原型，不是公开产品 API。

**结论：可以保留“固定 alpha 下的有界 F/B 最小二乘投影”作为算法组件。未发现此次有效输入范围内的数学/写域错误；整图效果仍拒绝。** 它修复的是源颜色解释与覆盖一致性，不能证明 alpha、材料归属、背景或脸型是正确的。

## 数学核验

每个颜色通道独立最小化 `(F-F0)^2 + (B-B0)^2`，满足 `aF + (1-a)B = C`，且 `F,B ∈ [0,255]`。对于 `0<a<1`，将 `B=(C-aF)/(1-a)` 代入后得到严格凸的一元二次式；其无约束最优前景为：

`F* = F0 + a(C-aF0-(1-a)B0)/(a²+(1-a)²)`。

可行前景区间为 `[max(0,(C-255(1-a))/a), min(255,C/a)]`。在此区间裁剪 F*，再用同一观测方程解 B，确为欧氏最小二乘解。alpha=0 时 B=C、F 保持有界先验；alpha=1 时 F=C、B 保持有界先验。实现的最后 clip 只处理数值端点，记录的数据未出现掩盖大型不可行值的情况。

独立 `audit.py` 没有复写这个一元公式作为 oracle，而是枚举观测直线与 `[0,255]²` 方形的交点，再将先验 `(F0,B0)` 几何投影到所得线段。7,809 个通道案例包括随机 alpha、1e-10..1e-2 的低 alpha、0/1 端点和邻近1的float32值。最大颜色误差 **7.63e-6**；颜色有限且有界；源重组最大 byte 误差 **0**。现有3项单测也通过。此验证不承诺无效输入或任意超出记录精度/范围的数据。

## 冻结实图核验

已逐项验证记录的脚本、原图、native PNG、全部 trace 文件和输出 SHA256。保存的 projected layers 与原 trace alpha/target alpha 精确相同；变换直接沿用冻结 source_xy，无重新检测或几何求解。

独立 float64 双线性采样与保存 PNG 在写域内最大差 **1 byte**，与原实现float32运算顺序的舍入差一致。输出变化全部位于原 native 的 `changed & !frozen` 域；固定像素仍等于原图，输出 alpha 精确不变。此处核对的是既有冻结域，未声称修好 touching-head 实例归属问题。

原 replay 的 `255*(a0+a1)+1` 上界正确但保守。源与输出使用同一 B，且 F/B 与有效采样 F 都有界，因此每通道变化可写为 `a1*F1-a0*F0+(a0-a1)*B`，其绝对值不超过 `255*max(a0,a1)`；加1容纳最终颜色舍入。独立检查在整个写域使用这个更紧上界，仍零违规。

原尺寸独立查看 ±30 左右耳：负向旧重影有所改善，正向外耳仍有浅色旧边/包边；改善数值不构成最终画质通过。已知模型 alpha 和重建 B 不一定是真实光学覆盖/背景，投影只能在它们给定时选择最接近先验的解释，仍可能把旧肤色归入固定 B。

## 可保留部分与边界

可保留纯函数投影、alpha端点合同、有界预乘前景 `0≤P≤255a`、同一 B 的源解释/目标合成约束和上述覆盖变化上界。它比直接把全部源残差塞进前景更容易保持有效颜色范围；并不自动提供新的材料证据。

需要明确保留以下限制：

1. **源重组恒等不是 near-zero 滑杆回归。** 本 replay 只有 ±30。没有通过真实公共操作测试 ±0.001/±0.01、符号切换、参数组合或量化后响应；不能追溯声称这些已通过。
2. 仅同一探索照片，无持出照片、强强度、透明源、非normal blend、native/WASM/页面导出验收。先验 B 也是该冻结几何下的重建结果，不是已知真实隐藏背景。
3. 当前采用编码 RGB 中的欧氏距离，不是线性光学混合或感知误差度量；代码注释已如实说明，不应包装为物理真值恢复。
4. **移植时需保留 float 图层直到最终合成。** 具体反例：C=1、a=.5、先验 F0=0/B0=1，投影得到 F=.5/B=1.5，正确最终结果为1；若先把F/B分别转u8再混合，结果为2。当前Python实现没有这个错误；不能只把PNG式u8图层塞回旧Rust管线就声称0byte合同仍成立。
5. 几何自然度、耳环约8%非刚性变形、多人头发桥误归属以及新露出纹理的真实性都不是这个投影解决的问题。
