# 固定 alpha 的有界源一致 F/B 分解

状态：隔离数学组件，**整体图像未验收，不接生产**。继承 ZIM whole-person 原始 alpha 和冻结 V2 位移，只改变前景/背景颜色分解及合成。没有重训练、没有减少瘦脸幅度。

## 问题和算法

原估色和最终背景不能精确解释原图；在覆盖率不到 1% 的区域，最终合成仍产生最大 34–36 byte 改色。单独把分解残差固定在原位置会留下旧轮廓；全部跟随前景运输又会得到超出物理范围的预乘颜色。

本组件固定观察颜色 C 和 alpha a，将估计的 `(F,B)` 投影到 `aF+(1-a)B=C` 与 `0≤F,B≤255` 的交集，最小化两层颜色修改平方和。a=1 时 F 必须等于 C，a=0 时 B 必须等于 C；混合区沿可行线段投影。再用原逆位移采样 `aF`，在目的坐标用同一个最终 B 合成。实现为 `project.py`。

这是编码 RGB 中的确定性约束基线，不是物理光照模型，不是新论文或 SOTA 声明。`test_project.py` 特别保留反例：错误 alpha 会迫使旧前景颜色进入 B；源重建完全正确仍不能证明分层真实。

## 实图结果与限制

用户原照 ±30、全部几何/alpha 与上游保持不变。可写域沿用 Rust trace，冻结域、域外和图像 alpha 均未增加变化：

| 指标 | +30 | -30 |
|---|---:|---:|
| 原图重建最大误差 | 0 byte | 0 byte |
| 原来低覆盖区域最大改色 | 36 byte | 34 byte |
| 投影后低覆盖区域最大改色 | 2 byte | 2 byte |
| 低覆盖区域改色 >8byte 像素 | 1579→0 | 569→0 |

“低覆盖”是源、目标 alpha 均小于 .01 的诊断域。候选满足 `255(a+a')+1byte` 的每通道变动上界；这不等于所有背景逐像素恒定，也不证明该域没有真实细发。

root 已看原尺寸 ±30 双耳对比，主要消除了远处重涂，但 +30 仍有旧浅色细线，耳缘/饰品自然度未完成。错误覆盖、错误背景、其他人物归属和金属饰品形状不在本组件中得到解决。尚未进行 ±100、多原照、Rust/WASM 对照或实际近零滑杆验证。原图零位移的代数恒等不能代替这些测试。
