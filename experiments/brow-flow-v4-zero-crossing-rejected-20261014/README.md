# Rejected brow-only SVF activation

With nonzero eyeSize, browPeak 0 to 0.001 switches the entire operation from direct displacement to RK4 and changes the non-target eye by 5/255. The saved production source contains the failing regression; its log preserves the failure. The final implementation activates the same method for all semantic feature geometry and tests the final full mapping plus RGBA for four cross-family transitions.

This rejection concerns the algorithm switch. The velocity and continuous fixed-domain equations used by the 42 nonzero-brow V4 photo cases are unchanged in the final implementation.
