# 独立背景边缘重建与已知纹理留出实验

2026-10-15。**全部保持实验状态，未进入生产，不构成8分验收。** 实际照片上的完整轮廓、右耳尖口和发丝纹理仍未过关。该实验沿用现有LaMa基线，不把它称作新模型或SOTA。

## 验证的问题

冻结woman +100的V36几何、corrected ZIM源分解和显式B（皮肤在头发前）假设，检查两个因素：

1. 用原图已观测头发的反射纹理构造未知背景上下文，再只补真实露出的细条，是否好于把整片未知前景都遮掉。
2. B合成中无条件贴回的混色边缘H估计，是否把原皮肤色带回旧轮廓；把这部分也交给独立背景重建会发生什么。

反射上下文是一个**隐藏材质假设**，不是已观测背景。所有反射/最近邻供体坐标来自独立允许的原头发域；改变全部被排除原RGB，虚拟上下文逐字节不变。未知处没有被偷偷读取。它并不能恢复真实隐藏纹理。

## 结果与拒绝理由

- `outputs/`：256/512局部补全及纯反射对照。只更换背景上下文仍保留旧亮线。
- `combined/`：先逐字节复现既有B+LaMa256，再连接上述新背景。仍有旧橙细线；这部分不能解释为几何改善。
- `mixed-edge/`：将背景写域扩大到原露底域与既有B写域的并集，并不再强制贴回估计H。virtual-context减少了大部分旧橙线；observed-only仍有绿色细线。两者仍有暗条、底端细点和右耳尖口。
- `mixed-edge-protected/`：独立审计发现原露底域含38个软耳/饰品像素；新版在推理及写入前明确排除`ears/accessories>=.05`。相对完整初始B新增保护区变化为0；初始B相对源图本来有42个软保护像素差异，另外记录，不能把它们宣称已修复。旧失败代码、图片和独立坐标清单均保留。

背景新版的最终写域为15477像素；不改前景RGB、源alpha、逆映射或位移幅度。独立重建验证原mixed-edge两组的最终输出与冻结前景/alpha合成逐字节一致。**observed-only与virtual-context同时改变上下文RGB和推理mask，是联合conditioning对照；不能将其称为只改RGB的单因素消融。** 两组输出端均只替换背景贡献。

## 已知隐藏纹理验证：反射方案失败

`holdout.py`从三张原图高置信头发内自动选最大内接方块，隐藏整个右半面，只评价紧贴可见边界的窄条。真值只用于评分；供体选择和模型上下文不能读取被隐藏RGB。原图/模型/alpha/裁剪规则和坐标均保存。额外oracle-right-context保留右侧实际背景，只作为有更多真实信息的对照，不能与实际露底任务混称。

| 原图 | 未知半面LaMa平均RGB误差(byte) | 反射上下文+LaMa | 纯反射 |
| --- | ---: | ---: | ---: |
| woman | 9.330 | 10.778 | 11.410 |
| user | 18.378 | 25.040 | 30.774 |
| hair | 5.597 | 12.541 | 15.020 |

反射方案三张图的颜色误差与梯度误差都更差。因此，即使woman实际照片上的旧橙线减少，也不能说纹理重建更准确，更不能用它换一个8分。测试针对三块已知头发纹理，不代表穷尽背景材质，也不替代最终审美评审。

## 可保留的结论

源RGB重建成功不等于分解出的隐藏H颜色正确；强制把不可靠的H贴回会残留旧边。前景与背景分开控制可定位这个问题，但当前反射上下文不能作为可靠补全方案。后续需要提高背景真实上下文/修复模型能力，并先过已知纹理留出验证，再评完整照片。

## 复现与证据

使用`services/background-worker/.venv/bin/python`，所有脚本默认拒绝覆盖历史输出。

- `run.py --output <新目录>`：原背景虚拟上下文，256/512与prior-only。
- `combine.py`：固定B组合，默认`combined/`。
- `edge.py`：保留软保护缺口的失败实现，默认`mixed-edge/`。
- `edge_protected.py`：显式保护版，默认`mixed-edge-protected/`。
- `holdout.py`：3张原图的已知纹理留出，默认`holdout/`。

各目录`report.json`包含输入/输出SHA、模型摘要、固定buffer、实测耗时与不变量。独立审计在`independent-audit/`。此处没有下载新模型、没有修改生产Rust/WASM或服务。
