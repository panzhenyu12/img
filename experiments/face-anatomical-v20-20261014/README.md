# 源曲线相对脸型 v20：隔离研究，待效果审核

基线是当前正式 v19 联合脸颈核心，包括连续的横向 QP/纵向请求、硬冻结与非 normal soft blend 权限修复；完整源码和依赖在本目录，原 `face.rs` / `face_flow.rs` 另保存为 baseline。`production-baseline-sha256.json` 记录来源，研究不修改正式核心、公共 WASM、图形协议或前端开关。

## 原图诊断

用户1024²源图与+100输出原尺寸核对：额耳、眼睛、鼻子和嘴基本固定，瘦脸集中在嘴下；颧颊到下颌形成斜直侧，下巴显尖，上颈侧被带到新的窄脸宽度。现有 `flow-geometry.json` 对应源曲线 y383/y479 实际位移0、y525约15.81px、y557约19.02px。单个最大20px、无fold、连接没有大黑缝，均不足以说明自然度。

完整只读诊断见 [`../../doc/qa/face-v19-anatomical-diagnosis-20261014/review.md`](../../doc/qa/face-v19-anatomical-diagnosis-20261014/review.md)。v19请求把脸宽在大半侧曲线设成约20px等量横向位移；真实耳/发/饰品的附件可行性在QP之前就把y383–492上脸请求归零。QP不是上脸归零的主因，另对+100左右下颌目标作最大5.145/4.034px修正。旧弯曲项没有按非均匀v间距离散。联合alpha避免内部分类透明切口，却没有给真实颈侧独立形状目标；颈侧由脸RBF自由外推，y617以后才开始中轴衰减。原物理alpha在y545宽度205→162px，不能只看控制点最大误差.297px就称自然。最终物理外皮肤边缘与face/neck内部标签分别核对，不用内部标签位移冒充外轮廓。

## 拟验证的单个新假设

1. 以眼轴坐标与个人源侧曲线的横向宽度比例生成faceWidth目标，左右独立；仅在无附件连接约束的原侧弧上归一化，保留原约20px预算，不強求真实固定上脸也达到20px。原下颌肩部的目标由其源宽度决定，避免每段等量位移。本轮没有新增下颌角/颏部语义landmark，不冒称已完成解剖分区重建。
2. 目标与约束都立足源曲线：拟合局部位移，惩罚与限制相对原切线/曲率的变化，保留原有合法转折。使用成熟Clarabel解QP。拟合、斜率、二阶导数用非均匀v区间积分权重，平滑物理尺度为源侧弧v跨度/28，不依赖采样数；同源曲线0.5x/2x及非均匀重采样核对。取消把整条侧曲线逼成统一全局凸性的规则，但离散约束并不证明真实运输曲线的自然度。
3. 由联合物理alpha沿眼轴射线找外皮肤边界，以连续face/skin/neck证据分别估计左右颈连接，容许单class的阈值缺口；不使用一条横切alpha边界。由附近已QP脸控制位移生成源颈曲线相对位移，再quintic渐停到原低颈，新增零目标颈侧控制参与shooting。它仍可能夹窄上颈，首图须报告宽度/切线；fade端点一二阶导数为零，但没有拟合上端脸侧位移导数，不能称整条脸颈C2。
4. 耳、发、饰品、五官、用户保护和选区权限沿正式基线，实际目标与到达位置单列；不靠减弱全局幅度、擦掉孤点或改检测来掩盖失败。附件影响范围须由逐stage诊断决定，不能以"美观"取消真实固定域。

这些是本项目针对实证问题的候选研究，复用紧支撑RBF、SVF、成熟QP组件。仓库研究中的Inpaint4Drag提供形变/补全任务分离思路，DragDiffusion/FreeDrag的追踪思想提供实际到达验证思路；这些论文不提供现成的人脸审美分区曲线，也不证明本候选达到SOTA。三维FLAME/DECA路线已按用户决定取消，不重新引入。

## 固定验收范围

先仅用户同一1024²原图 +30/+100；通过独立首图审核后再决定±30/±100及两张不同人像 `portrait-woman`（1280×1920）与 `portrait-makeup`（1280×1128）的原尺寸回放，全部沿同一源图缓存检测。低分辨率parser插值不是新的图像样本或物理真值，旧原图含AI水印，明确区分。图像、图形与尺寸见 `inputs/manifest.json`。

分别保存原尺寸源图/v19/v20、脸缘局部、颈侧、请求/可行/实际曲线，源曲率和位移分布；核对耳发五官/ROI/低颈/alpha、scene、反向误差/Jacobian。只读独立审核后再作结论，失败保留。native总耗时包含解码/graph/kernel/PNG，不称稳态Web实时。
