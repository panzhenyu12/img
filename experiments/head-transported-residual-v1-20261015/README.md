# 头部颜色分解残差的运输实验

状态：隔离因果实验；**未接入生产，也未通过完整画质验收**。固定整体脸型 V2 的源图、人物归属、原始 alpha、位移及背景，只比较分解误差放在哪里。

## 证据与方法

源图为用户提供图像的 1024px canonical-source，SHA256 `5f15e92b14c44a468d924af5ac985a7cc7dc1c87d8ab235f2c94b2e88b173c73`。V2 冻结 binary SHA256 `2355e919c57a3dbd30041108eeaa7f31f4e582e9254eb9452cad5f045baa0880`。输入来自 `../whole-face-shape-v2-20261015/outputs-scoped-owner/user-face-contour/`；各图层哈希在 [report.json](outputs/report.json)。

首先用导出的实际预乘采样值和最终背景重组合 V2，两向均与实际 public renderer 的可写像素 **0 byte 差异**。设源图 `C`、源覆盖 `a`、估计前景 `F`、最终背景 `B`，定义分解残差 `R=C-aF-(1-a)B`。比较：

1. V2 原合成；
2. 原位补回 `R`；
3. 与前景共用原逆采样坐标运输 `R`。

这不是新的 SOTA 算法，也没有模型训练。第三种只用于验证“把误差留在原坐标”是否会形成旧轮廓。alpha 为零的源背景禁止当作前景残差运输；alpha、冻结域、原位移均保持不变。

## 结果

- 原尺寸查看 ±30 的整脸、双耳和发际对比，运输残差显著减弱了用户原照左耳外侧的亮/暗双边；原位残差则使旧耳边和耳环边更明显。双向各额外改变约 5794/5071 个像素，限定在 V2 已渲染域内，冻结域和图像 alpha 不变。
- 源图中甚至 `a=1` 的像素也有明显估色偏差。例如全图 `(347,145)` 的观察 RGB 为 `[255,253,249]`，估计 F 为 `[202,197,192]`；本轮另开已知颜色边界实验验证多尺度估色是否破坏已知材料。
- **仍拒绝直接采用**：源 `aF+R` 有 2169/2175 个像素超出物理可行预乘范围 `[0,255a]`。例如耳环与低 alpha 的颈部实质材料不能由现有 matte 加暗背景解释。即使最终 RGB 截断后看起来较好，也不能把这种修饰当作可靠 alpha/材质恢复。
- 报告的 `sourceIdentityFromExactDecompositionMaxByte=237` 是整个局部框的数值，包含明确排除运输的 `alpha=0`、背景补全区域；不能当作近零滑杆或源恒等通过。该候选尚未执行近零连续性、±100、多原照和 WASM 验收。
