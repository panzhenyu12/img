## 已复现的问题

fashion-standing 右大腿一侧从 t=.375 到 .875 的原半径是 50.12/46.85/43.36/40.21/38.47px，单调渐细。旧 +100 的实际目标是 38.67/34.67/33.45/34.33/36.88px，产生原图没有的中下段凹陷。原版按所有肢体共用的中点钟形乘源半径；仅更换更宽钟形会把异常推向膝。

## 候选和边界

每侧独立测量远端半径，取 t=.875… .953 的可测半径最大值 rK。对大腿超出参考半径的部分按 d=max(r−rK,0)、g=.85*d²/(d+max(.04*rK,1)) 计算位移，并平滑限制为最多 .26*r。r±g 严格递增，可靠源渐细段不会仅因该标量目标变成反向鼓包。源关节宽度、源左右差异仍分别保留；髋端和 t≥.875 膝端固定。

26% 是整半径位移的上界，绝非实现了26%体围变化。既要固定等宽圆柱两端又禁止新增极值，会导致无处可改；初稿因此让直筒滑块失效，被已有行为测试拦住。当前按源落差/远端可测程度的连续可信度混合旧目标。直筒保留旧行为，中间可信度**不具有完整候选的无新极值保证**。保留初稿源码和二进制以供审计。

## 观察与决定

- 站立右腿 +100：同平均位移的旧算法仍有浅谷，候选维持渐细方向，说明存在曲线层面的改善，不完全由减量解释。但候选把厚度变化压得较平，尚不足以证明普遍自然。
- 站立左腿：一侧最大仅0.17px，另一侧8.66px。前者源半径大部分小于膝参考，正部差直接关闭该侧。该不平衡需要后继实验，不能宣称完整瘦腿。
- 瑜伽收缩：避免部分中点夹紧，膝附近连接仍需仔细检查；扩张主要鼓起短裤，裸露大腿变化偏小，衣料/皮肤过渡没有获得可靠的自然度提升。
- ±30：变化小，和匹配旧版没有稳定可辨的视觉优越性。
- 未改变横向分段线性纹理映射，布纹折角、分割误边、复杂背景新露出窄带仍未解决。

结论：仅保留实验，未达到上线或8分标准；不替换生产。源曲线驱动正确区分目标方向，但膝参考/衣物轮廓不等于肌肉解剖，需要继续分开验证。

28个默认body测试通过，含新增真实渐细数列、源映射单调、固定关节和非对称、圆柱不失效、源可信度连续过渡；数学和合同通过不构成画质达标。见 body-test.log。
