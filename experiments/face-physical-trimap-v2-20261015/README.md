# 脸颈物理边缘漏像素修复 V2

2026-10-15。本候选只修复源图层的物理 alpha 归属，不改变瘦脸目标、流场、滑块强度、关键点、原始语义蒙版或背景重建算法。整体脸型和颈部形状仍未通过美学验收；本修复不代表达到 8 分。

## 独立复核结论

V1 将原位置 `x407–408,y547–552` 从肤色改为暗背景判为“暗洞”，这个判据不成立。+100 时，这 12 个位置的目标前景 alpha 全为 0；真正的新左轮廓位于 `x429–431`，相隔 21–24 px。原肤色应随人物离开旧位置，随后露出邻近暗背景。保留旧肤色才会产生悬空小岛。

V1 清除了 9/12 个点。剩下 3 个点不是缺少几何运动，而是单像素颜色线残差越过硬阈值：两个相邻点残差 436.30、433.99，阈值 432；相同肤色上下邻点通过。源 alpha 中的这些小孔也被运到新轮廓，产生暗点与锯齿。V2 清除了全部 12 个旧位置残留，同时修复相应目标边缘 alpha；没有往新轮廓内填暗背景。

原复核材料保存在 `first-audit` 和上一版目录，没有覆盖旧结果。1× 与放大对照见 `replay/100/face.png`、`replay/100/island.png`。

## 实现与边界

在已确认的脸颈连通层中，只考察原物理 alpha 为零的像素。恢复同时需要 selected-person 观测、到原已归属组件的有限距离、邻近 skin/neck 语义、可用的已观测前景/背景 RGB，以及颜色线支持。头发、耳朵、饰品、另一人物、用户保护均保持排除。包含透明像素的输入不推断额外物理边缘。

V2 在 V1 基础上增加颜色连续性传播：候选必须先通过相同的归属、人物、语义、供体与保护门控；再要求紧邻已有支持的 alpha，预测 alpha 相差不超过 .15、局部 RGB RMS 差不超过 8。逐轮同步更新，避免扫描方向影响结果。传播受原 fringe 半径限制，不扩大语义蒙版，不修改控制点，也没有按这张照片的坐标打补丁。照片坐标只用于 QA 查询。

这是一项局部、可解释的物理分层缺陷修复，不是新的学习式分割模型，也不能恢复完全没有观测支持的遮挡内容。语义分割和物理 alpha 仍有不确定性，不能从三张照片推导普遍的零伪影保证。
