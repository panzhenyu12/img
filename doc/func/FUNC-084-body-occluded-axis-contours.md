# FUNC-084：遮挡中轴与两侧身形曲线解耦

2026-11-19。Rust 核心已修复一类真实双峰缺陷；`action-suit` 的同源 `0/±30` 回放有改善证据，不能据此宣称通用美体或整体 8 分。算法尚未接入 Web 新检测流程。

## 触发条件与原因

持电脑的人像中，电脑右缘在部分高度遮住躯干骨轴。旧 `ContourProfile` 仅在中轴材料 coverage ≥ 0.5 时测量左右轮廓；否则将两侧半径一起置零，再沿纵向扩散停动区。远离电脑的右西装外缘因此交替运动、固定，产生两个凸峰和尖折。此时局部逆映射 Jacobian 仍为正，说明“未翻折”不能证明曲线自然。

自动归属另有独立缺陷：从整人衣物提案减去两袖提案后，把所有剩余像素都当躯干，误收了孤立袖边。两项问题分别修复，不能用冻结外套、缩小强度或修改光学 alpha 掩盖形变目标错误。

## 实现与边界

- Rust 根据每侧第一段可见材料独立测量轮廓。中轴不可见时，仅在中轴有明确保护物证据或既有封闭孔几何支持时继续查找；骨轴落在开放背景中的错位情况不允许任意采用旁边独立片段。无部位解析的肢体仍要求中轴可见。
- 实际保护区域继续逐像素固定并连续衰减。输入材料 coverage 不被填实，不推断隐藏躯干；选择域、保护、请求幅度与双线性单元四角 Jacobian 检查均保留。
- Python 自动源提案仅保留与原图躯干观测点连通的剩余衣物组件。其余组件标为未分配并固定，不能当作光学背景或已识别袖子；无躯干观测的情况拒绝，不自动选最大组件。
- 骨段采样保留原三点的位置：中点被语义证据拒绝后，两个端点不能被当成相邻观测区间。

入口：`prepare_body_inverse_displacement`、普通 `body.adjust` 以及显式源分层使用同一 Rust 场。源候选生成和选择仍在独立算法脚本中，不属于已发布自动检测功能。

## 核对证据

公开字段行为回归先复现“电脑遮中轴导致另一侧被固定”，修复后验证两向有明显响应、单峰曲线及固定像素不变。另一回归先复现“错轴跨开放背景采用旁边片段”，增补源证据条件后通过。既有内部 aperture、开放通道、背景保护、透明度和各部位宽度回归继续定向运行，不以合成回归替代成片审核。

真实照片使用全新原图检测保存的同次 FASHN 后验及固定 SAM2 候选，自动选择两袖和整人提案，不手选候选 ID，不更改原 Pose/保护/幅度。V3 已恢复右衣摆归属，但旧 Rust 场产生双峰；独立两侧测量使双峰消失。源组件筛选从 160,524 个候选躯干像素中排除 3,324 个无躯干证据的孤立像素，其中左内袖残条 566 个；右衣边诊断区域内 11,345 个像素均保留。V3/V4 派生选区和 region 逐值相同。

最终 `connected-side-v2` 零值逐 RGBA 不变；两向原 92,885 个保护像素、原图固定的电脑/手/袖核心及背景线探针均不变。明确保护物条件加入前后的这张照片三档成片逐 RGBA 一致。两向进程约 1.40/1.48 秒，包含原尺寸 PNG 编解码，不能写成实时性能。独立成片审查见 [评审记录](../qa/body-independent-sides-20261119.md)。
