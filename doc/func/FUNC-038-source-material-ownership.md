# FUNC-038：独立衣物与颈部源归属

状态：2026-10-28，默认 Rust 核心已能处理显式提供的源材质证据，7 项准备算法合同、2 项实际渲染回归通过。Web 检测、公开操作图与 MCP 尚未自动提供这些内部证据字段；本项不是系统接入完成。颈部边界向量场仍为隔离候选。

## 实际根因

hair 原照片的黄色衣领被旧颈部解析标为 `neck=1`，所以提高原颈部置信阈值无法排除它。仅凭像素颜色残差也失败：与肤色兼容的衣物样本比某些真实颈部更多。简单把 person-only 区域全冻结，则会同时留下漏检的真颈部。

使用已有缓存 FASHN 模型的独立服装/躯干语义后，领口 `(404,453)` 具有 top=.664、torso=.023，而漏检颈部 `(362,390)` 为 top=.0076、torso=.748。该证据可以约束材质身份，但不是物理透明度，也不能当作模型永远正确的证明。

## 准备算法

小源码保存在 `experiments/face-source-material-20261028/`。18 类后验与原解析支持全部在同一原图像素网格取样；验证有限性、非负和按 byte 量化误差允许的归一化范围。衣物类别总概率必须高于其全部补集才确认固定衣物；近均匀后验保持未知，不覆盖旧支持。

新增裸露皮肤支持仅限原 neck 定位不确定带，避免把整片裸胸当作颈部。原 `semanticMasks`、脸廓、请求和原解析分辨率保持不变。输出独立原图网格的衣物身份及 skin/neck 支持；这些后验不直接成为物理 alpha。

已否决两版：只取 argmax 会把约 5.56% 的近均匀结果判为硬衣物；分别在原图和低分辨率网格分类会丢掉细颈/衣物交界的真实皮肤。两类反例及非法后验检查均已加入测试。

## 核心处理

当前内部证据字段为 `__sourceGarment`、`__sourceSkinSupport`、`__sourceNeckSupport`，公开命名和 source hash 绑定留待算法验收后的接入工作。

Rust 保存独立 `material_fixed` 身份：它禁止衣物作为皮肤供体、进入移动皮肤种子或被 RGB fringe recovery 重新招为皮肤；固定材质加入几何约束，但不冒充耳朵/饰品。缺失颈部回退、测试物理 alpha 覆盖和 own-edge 释放也不能覆盖这一身份。

同肤色高领反例暴露了旧候选的另一处真实错误：`material_fixed` 与 `inferred_person_fixed` 同时成立时，后续恢复错误地解除了固定。修复将材料身份直接加入 `strict_forbidden`，在源恢复前阻止错误归类，而非最后把原图贴回去掩盖形变。

## 验证范围

- Python 7 项准备算法合同通过。
- 主核心 2 项针对性渲染回归通过。开领 fixture 在没有证据时确实误动衣物；加入证据后衣物全部原样、邻接颈部仍有可见形变，正负 100 均检查。同肤色高领在实际 fringe recovery 后仍固定，旁边真颈仍被选中且未冻结，正负 60 均检查。
- 与最新源配对、场景备选证据及 v3.1 颈部候选组合后，150 项人脸合同通过；hair/dark/tilted ±60 的完整照片回放及独立审核显示领口缺口消退，未见新增明显颈部断缝，衣物/固定低颈全量字节保持，检查到的网格 Jacobian 全正。
- 组合的总体脸廓响应接近可行目标，不代表每个控制点到位。tilted −60 的局部最大目标误差约 0.230 px；目标超过 0.5 px 的部分控制响应不足，需要继续处理固定域附近的求解。

默认几何与组合候选必须分别记录，不能把候选图片当成当前 Web 输出。最终默认几何的直接核心回放（三图正负方向）保存在本机 `/tmp/face-source-material-main-20261028/`；组合证据在 `/tmp/portrait-material-combo-20261028/`。

默认核心实图使用 `face::material_regression::replay_explicit_source_material` 的显式离线入口，先验证原操作，再附加三个内部源证据字段，直接调用真实 `face::adjust`，没有启用向量颈部。公开 `image-render` 的 graph validation 仍拒绝这些内部字段；没有为实验放宽生产协议。三图正负方向共六个候选中，衣物身份域（各图 145,955 / 220,544 / 126,182 像素）均无输出变化。无源材质证据的 user +60 与前一已接受核心输出逐字节一致。

独立主核心复核：未见新增可见裂缝或全脸形变退化；dark 正负 60 原有 58/55 个衣物误改像素归零，hair 变化很小，tilted 双向与无材料版本逐像素相同。这仅证明当前输入下材料修正有效且没有观察到新增明显退化，不将组合向量场的 Jacobian/目标响应数值套用到这组默认几何。优化构建直接核心单图约 0.4–2.4 秒，仍不满足实时拖动预算。

## 仍需解决

独立语义仍会误分，高领、头发遮挡、多人和复杂服饰需要更多照片。混合像素的材质身份不等于光学分解真值。v3.1 的低颈长度先验仍依赖裁切内观测，不能因为三图通过就无条件替换默认几何。本项不恢复 8 分或整体可用的结论。
