# FUNC-087 Adaptive Face Contour v2

## 状态

研究候选已进入有条件的默认路径；整体人像修图仍未达到通用可用。

## 目标

让脸型、颧骨和下颌的宽度调整随真实轮廓变化，避免固定像素横向位移在窄下颌上过度收缩，并避免强档组合在硬上限处出现曲率突变。

## 算法合同

- 只在输入提供至少 24 个点的 `faceContour`，以及独立的 `leftEye`、`rightEye`、`lips` 多边形时启用；证据不足时回退旧路径。
- 以轮廓横截面的局部半宽作为位移尺度，并限制在源脸宽的 `0.55..1.10` 范围。
- 位移沿源轮廓外法线运输；下巴接近竖直切线时平滑降低法线分量，宽度参数不直接缩短下巴。
- 眼睛、鼻子、嘴唇和下颌高度构成 C2 分区曲线；多个滑杆先合成，再用奇函数 `tanh` 平滑饱和，避免硬 `clamp` 的导数跳变。
- 输出目标经过相邻边方向、最小边长和面积方向检查；强档出现折返时逐级回退到最近的安全目标。
- 几何目标不承担光学前景 alpha、前景 RGB 或背景 RGB 的推断；没有同源物理层时不得把几何回放当作无裂缝保证。

## 验证

- Rust 几何回归：零值恒等、正负对称、局部半宽缩放、下巴长度、平滑饱和、轮廓 winding。
- 三张缓存人像 native replay：`user`、`dark`、`woman`，每张 `±60`；声明区域外变化为 0。
- 回放与人工检查结果记录在 [face-adaptive-lateral-v2-20261119.md](../qa/face-adaptive-lateral-v2-20261119.md)。该记录只证明响应和几何连续性，不能证明所有真实照片自然度。

## 已知限制

Web 端目前仍只传语义 mask，没有完整的同源 optical alpha、前景 RGB、背景 RGB 层合同；耳侧头发、颈缘和复杂遮挡仍需独立材料验收。身体服饰的 source identity 与 occlusion order 也未解决。
