# FUNC-059 脸颊与邻发的连续材料域

日期：2026-11-13。状态：Rust 原生隔离算法已实现，woman 常用 ±30 的既有
下颌折点有真实成片改善；公共默认未接入，整项瘦脸尚未验收。

## 原因

同一条脸颊轮廓旁，原算法主动让部分邻发随脸移动，却因 head 类别置信度
低谷把中间几个像素留下固定。固定像素又通过网格单元共享顶点连带固定邻近
皮肤，造成轮廓某一点不动、两侧移动的突兀拐弯。

已经分别排除“只需扩大形变幅度”和“只需精确固定像素中心”的解释：前者
加重邻点转角，后者在原域和第一版修复域中都产生逐字节相同的照片。

## 实现

`core/image-core/src/face_upper_width.rs::promote_interface` 保留共同域策略，
加入两个仅限 `cfg(test)` 且需显式设置的候选开关：

- `__experimentalOuterSubjectOccupancy`：外部判定使用已有 head 与 person
  类别占据的并集，避免内部类别低谷沿颈侧、躯干连到图边，被误认为人物外缘。
- `__experimentalSharedSubjectAdmission`：在原轮廓距离、纵向范围、头发
  证据等限制内，允许低 head 的连续内侧邻发连接到原可移动节点。整个采样
  支持及外缘余量均要求高 person 占据；孤立概率岛、真实背景孔、受保护的
  连接节点不能让新材料进入。

person 占据来自同一解析器的非背景类别集合，不是物理 alpha 或独立实例
真值。新域仍会通过 skin/hair 准备影响后续 alpha 和源背景配对，因此每次
都重新生成源图层，不能只比较几何结果。已有显式保护和材料固定仍参与求解。

实验导出器直接提取当前 Rust 函数，不维护另一份 Python 算法。准备好的
公开 graph 删除研究字段，并验证再次运行原 promotion 不会改变语义。

## 同源实片结果

woman 原图、前 128 个轮廓控制点、精确目标、`.24` 导数界和采样器均保持。

| 项目 | 原方案 | 完整候选 |
| --- | ---: | ---: |
| ±30 下颌目标响应 | .7202 | .9996 |
| 下颌目标误差 RMS | 1.668 px | .0021 px |
| 下颌最大目标误差 | 4.505 px | .0061 px |
| 三点弦转角误差 RMS | 5.22–5.87° | .007–.008° |
| 原外背景像素改动 | 0 | 0 |
| 保留冻结区、五官核心改动 | 0 | 0 |

原固定拐点在正负两个方向均明显改善，原尺寸脸颊边缘没有观察到新增裂缝。
几何误差和目标响应仅用来解释问题，不是审美评分。当前求解约 10 秒/档，
这也尚未满足实时交互要求。

user 样本新增一处准备节点，同一逆向场下原/候选源图层渲染逐字节相同；
native 各自求场仅 66 个像素相差 1 码值，原冻结区和背景无新增差异。dark
准备完全不变。后续 ±30 独立回放已完成：user 的完整耳饰随动、context5
源层链和 dark 固定耳饰路径分别与旧完整候选逐 RGBA 相同，没有新增退化。
woman ±60 也已审图，原右下颌拐点未复现；左下颌另有局部约束饱和，
见 FUNC-060。不从这些局部结果推断所有功能可用。

## 验证与边界

15 项针对性 Rust 测试覆盖内部类别谷、真实外缘与封闭背景孔、孤立邻发岛、
弱占据证据、材料与显式保护、受保护种子、原几何范围、缺失输入及关闭开关
的原行为。红色失败对照和最终通过结果均保留。

仍需解决：更多人物/发型的实际画质、相邻人物与遮挡材料的身份、强档耳形
和局部纹理压缩、交互性能。单人候选不能自动推广到跨脸前发、另一个人的
头发、围巾/衣领误分类。没有进行 Web/Go/WASM/MCP 构建或接入。
