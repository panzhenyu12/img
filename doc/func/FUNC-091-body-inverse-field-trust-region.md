# FUNC-091 身形逆场正雅可比信赖域

## 目的

身形局部形变的运动场由多个解剖轮廓叠加得到。语义分割边界、保护区和两条相邻肢体在亚像素位置相遇时，逐像素边界限制仍可能让某个双线性网格单元翻折。旧实现把这种情况直接返回错误，导致正常的 `waist=+30` 请求无法渲染。

## 实现

`core/image-core/src/body.rs` 的 `build_motion_field` 先按原有轮廓、保护距离和选择域构建位移场，再调用 `validate_inverse_field` 检查每个网格单元四角的双线性 Jacobian。若原场不满足正 Jacobian，新增的信赖域步骤在同一场上做最多 16 次二分搜索，寻找最大的全局缩放系数 `s∈[0,1]`，使 `s·field` 通过同一验证器。位移方向、各解剖 profile 的相对形状和零位移区域均保持不变；只有达到几何可逆性的最大安全步长被采用。

当安全系数小于 `1e-3` 时仍拒绝请求，并提示调整选择或保护区。这保留了真正不可行请求的错误边界，同时避免普通滑杆因为单个边界单元翻折而整次失败。

## 约束

- 不改变 source、part mask、optical alpha 或保护 mask。
- 不通过降低某个局部 profile 或跳过 Jacobian 检查来掩盖翻折。
- 0 值请求仍要求逐字节 identity。
- 结果在 WASM 与 native 共享同一 Rust 实现。
