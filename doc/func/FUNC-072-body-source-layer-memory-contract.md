# FUNC-072 身体形变的源光学层内存合同

状态：算法内部入口已实现；默认 `adjust` 保持兼容。未接入 Web、Go 或 MCP，未据此宣布真实复杂遮挡照片可用。

## 为什么需要独立输入

FUNC-071 的固定场照片实验确认，白衣外缘被旧语义 alpha 错当背景时，调整形变曲线不能修复其台阶。当前新增 `body::adjust_with_source_layers(source, params, layers)`，由调用者明确提供同源材料的物理覆盖；几何仍读取原 `params` 中的部位、关键点、subject/part driver、selection 和保护。

`SourceLayers` 包含与源图相同的 `width/height`、完整分辨率的 `optical_alpha: &[f32]`（范围 `[0,1]`），以及可选的 `paired_background: &RgbaImage`。这些是内存数据，不是模型地址或新的 JSON/MCP 参数。

## 处理规则

- 光学 alpha 不再与 partMask 取 min，不被当成分类置信度重新 refine，也不用于测量新的身体几何。
- 复用 `face::layer_pair::pair` 和 `sample_residual`。采样预乘残差 `P=C−(1−a)B`，在同一固定 B 上合成，避免字节前景量化破坏源重构和跨零连续。
- 显式 B 必须同尺寸、不透明且可与源图/alpha 配对。若配对需要实质修改 B，则报错；输入数据不修改。唯一例外是 alpha 的半个相邻 f32 ULP 所能解释的 RGB 可行区误差，保留原 B 和 alpha；没有常量 RGB 容差。
- 未提供 B 时，只从源图与 alpha 取得已有 F/B 估计的 B，配对后固定。没有根据形变强度、方向、输出孔洞重新补写 B。估计缺少观测时明确报错；全 optical alpha=0 是无前景移动的例外，可精确返回源图。
- region、selection、显式 protect 与原几何场决定运动权限。旧 `semantic alpha<=.01` 和 `holes` 写入门不用于新路径；原来 alpha=0 的真实孔洞可以被移动后的同层衣料覆盖，而显式保护仍保持。
- 保留 body 的边界坐标 clamp 规则，避免复用透明越界采样语义后产生画布边缘背景条带。

当前明确支持**不透明 RGBA 照片上的软材料覆盖**，不等同于支持整张 RGBA 图透明。透明照片由旧 `adjust` 路径处理，新入口拒绝不支持的输入；即使调整为零也先验证显式合同。

## 回归

`body_source_layers_regression.rs` 覆盖以下行为；原有 29 项 body 回归继续保留：

1. 同一光学衣料中的语义孔不切开材料，±60 仍有方向正确的实际运动。该用例先在委托旧路径时失败，再通过新渲染。
2. 真实光学孔随材料移动；新露出的像素准确等于空间变化的固定背景，已空的源位置可以被材料覆盖；显式保护的孔内下层保持原像素。
3. 固定软边及纹理 B 下，0 精确重构，±0.001/±0.01 无有限色跳，±1 确有图像变化，source/alpha/B 不变。
4. 光学覆盖扩到全图，也不改变 region 外、selection=0 和保护像素，不复制受保护前景到可动区域。
5. 同一 source/alpha 使用不同有效固定 B，输出不串缓存；全 alpha=0 精确不动。
6. 尺寸、alpha 长度/范围/非有限值、不一致 B 和整图透明等非法输入在零调整时也拒绝。
7. 全 opaque material 且无背景观测时，不静默拿原衣服当隐藏背景。该用例有失败到通过记录。
8. 材料贴画布边缘时，正负调整不引入透明外推的假背景带。
9. 手臂 driver 不改用整个光学躯干的宽度，保留可见边缘响应与远端躯干不动。
10. `C=10,F=0,B=100,alpha=.9` 的 f32 表示误差可通过；超出半 ULP 的不一致仍拒绝。该用例先失败后修复。

独立构建入口为 `experiments/body-internal-aperture-20261117/build_source_tests.py`，实际使用核心 body 与共享 source-pair 源码；没有运行整站或 WASM 构建。具体日志与构建哈希在本地 `test/results/body-current-diagnosis-20261117/source-layer-contract/`。

本轮最终独立 Rust 回归结果：**39 通过、0 失败、0 ignored**（原 29 项加本轮 10 项）。根线程统一 Cargo `body::` 也实际得到 39/0/0；这不是系统接入验收。

## 真实照片的新入口验证

复用 FUNC-071 同源 `tilted-shirt` 与冻结 MEMatte shirt-only alpha，原几何 params 保持，只修改 waist 强度为 `0/±.01/±30/±60`。实际运行新内存入口，采用 `paired_background=None`：源图与光学 alpha 估计 B，再配对并冻结。没有按目标孔洞填 B，也没有用旧诊断图片假装新 API 输出。

- 6 个非零档的位移场，在原诊断 trace 窗口内**f32 逐字节相同**，差为 0。窗口覆盖原几何作用区。±30/±60 最大位移约 9.56/19.11 px，没有降低幅度。
- 0 输出与源图逐 RGBA 字节相同。±.01 的场有约 .0032 px 的非零最大位移，最终字节图也与源图相同，符合微量运动未跨过量化阈值。
- 实际消费 alpha 字节与源缓存相同；7 档配对 B 的 PNG SHA 都为 `2206db9c02f4e0cb9bd116aaf117f83e43bdfae370426e43663a47fc2726ae31`。
- ±30/±60 有约 1.5 万个缓存 alpha=1 的像素发生变化；完全不透明的反采样与独立源 RGB 双线性结果相差不超过 1 个码值。缓存 alpha=1 是模型估计，不作为真实材料标签真值或质量评分。
- 独立视觉复核在原尺寸及两处局部对照中确认：±30/±60 未重现旧 `y358..366` 上缘大台阶及 `y395..405` 衣料断层，衣纹随轮廓接续；未见新增白边、旧轮廓竖条、双边或局部脏背景。强档这两处与此前诊断 MEMatte 一致，可接受**该张衬衫外缘与连续衣料的局部改善**，无需继续围绕这两点微像素调参。

不透明裙子探针 `(293,510)` 的源 RGB 为 `[47,20,3]`，缓存 alpha=0，所有档位都保持原 RGBA。它揭示 shirt-only 输入的覆盖限制，不能把裙子不动算作裙子形变通过。真实前层袖子、躯干和裙子的独立遮挡仍未验收。

回放与只读 trace 脚本为 `build_source_replay.py`、`replay_source_layers.py`，位于同一实验目录。结果、逐档输入/输出哈希、场一致性及局部对照在本地 `test/results/body-current-diagnosis-20261117/source-layer-replay/report.json`、`upper-join.png`、`former-cloth-tear.png`。
