# FUNC-019 Web 编辑器功能区布局

## 目标

让人像美颜、局部塑形、修复去人和色彩工具在桌面端有清晰层级，在移动端也能完整访问参数，不因为固定窄侧栏导致控件拥挤或被截断。

## 当前实现

- 左侧工具按基础、人像美颜、局部塑形、修复与移除、色彩与风格、蒙版分组。
- 桌面端使用独立的工具栏、画布和参数栏；参数栏加宽到 360px，并保留图片信息和当前工具标题。
- 右侧参数区内部可独立滚动，图片信息和工具标题在滚动时保持可见。
- 修复与去人拆成三步：圈选区域、自动去人/去物、手工填补与主体保护；客户端和服务端模型入口仍分别保留。
- 移动端改为工具栏、画布、参数区纵向布局，参数区使用完整屏宽，避免在 390px 视口内把滑杆和按钮压缩到不可操作。
- 保留现有工具按钮文本、ARIA 标签和操作图层入口，兼容已有编辑器自动化测试。

## 验证

- `npm run build`
- `npx playwright test`：43 项通过
- 手工检查 1440×900 与 390×844 视口，覆盖导入图片、脸型检测和参数区滚动入口。
