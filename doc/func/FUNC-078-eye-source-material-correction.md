# FUNC-078 眼部源材料人工修正

2026-11-19。状态：**独立算法实验，人工材料修正已实现；不是全自动眼高完成，也未接入 Web、MCP 或 Rust 公共 `feature.adjust`。**

## 解决的问题

自动源估计会把虹膜暗纹和反光邻域误当成随眼睑移动的睫毛。单独改底色拟合不能可靠解决材料身份错误。本接口允许在未修改的源图上确认材料角色，再由算法估计图层；标注不包含真实 alpha 或隐藏眼球 RGB。

实现位于 `experiments/eye-closing-source-20261119/`：`source_material.py` 负责源绑定、分类标注与输运检查，`explicit_source_layers.py` 负责明确移动材料的源图层估计，`robust_source_surface.py` 提供源局部表面估计，`run_closure.py --materials` 完成离线对照。具体命令和格式见同目录 `RUNNER.md` 及人工材料说明。

## 输入与行为

材料 JSON 绑定原始文件 SHA-256、宽高及 `pixel-index` 坐标；整数 XY 表示源像素中心。每只眼分别接受矩形、多边形或圆笔划，不接受把连续 alpha 冒充材料标签。冲突、尺寸或源哈希不符、标签超出源眼区域均明确报错。

| 标签 | 含义与处理 |
|---|---|
| `ocularAnchors` | 确认可见眼球。令源眼球颜色 `B=C`、暴露率 `E=1`；也可作为明确的源底色供体。 |
| `movingLashSupport` | 确认随眼睑移动的细睫毛及相接混合边。只在许可域中估计底色和暴露率，不要求用户提供 alpha。 |
| `unknown` | 尚未确认的材料。非零编辑若依赖该区域或其逆采样足迹，则拒绝；不能默认为已观察眼球。 |

源图层只准备一次，复用于零值与各档闭合。人工和自动对照严格使用同一位移场。分类标注、源拟合都不读取目标图像或按输出坏点扩展区域。

对已确认移动的材料，使用明确眼球供体作局部稳健仿射底色估计；前景允许源皮肤与睫毛颜色混合。图层需有限、有界并重建源 RGB。底色始终是估计值；颜色模型近似误差以 `modelUncertain` 报告，不能冒充材料身份未知，也不能称为观测真值。缺供体、域外或数值非法仍为阻断性的 `unknown`。这一许可不授予自动检测出的可疑暗线。

合成保持 `C'=R(q)+E(q)B(x)`：前景随眼睑场移动，眼球纹理保留在原位置。不通过输出 RGB 裁切掩盖错误。

## 已完成的验证

人工材料的 5 项定向行为测试通过，包括：固定源矩形纠正假虹膜暗线、固定笔划修复漏判睫毛的一次运动、未知材料依赖拒绝与零值保持、源绑定及标签冲突、RGB/许可域输入检查。最终 RGB 和睫毛位置沿用先前独立测试的门槛；实现不接收其真 alpha 或真底色。已知层反例中，亮暗纹最大 RGB 误差从 170.29 降至 0；漏判睫毛的 RGB RMSE 从 16.13 降至 2.73，低于固定 5.65 门槛，暗线质心误差 0.081px，低于固定 0.25px 门槛。这是对应反例的算法行为验证，不是审美评分。

用户原图 768px 的两处可见眼球多边形已作 `0/-15/-30` 同场回放。−30 时两个既有高光点的最大 RGB 偏差分别由 29 降至 5、由 24 降至 0；−15 分别由 14 降至 2、由 12 降至 0。左侧仍有残余变化，不能称两点完全恢复。独立审查已检查两眼两档完整虹膜、标注边界和 −30 全脸，未见新增多边形硬边、暗环、双睫线或眼睑断裂，接受该样片范围的人工眼球材料修正。此图 `movingLashSupport=0`，不能替代真实照片中人工睫毛支路的验收。

另在 makeup 原图的右眼，仅据源图标注一根眼白前细睫毛及相邻眼球供体：26 个移动支撑像素、38 个供体像素，源标注在出图前冻结。同一算法和位移场完成 `0/-15/-30`；26 个支撑均有合法估计，其中 13 个保留 `modelUncertain`。独立审图检查完整眼部、整脸及睫根/线身，细线随轻闭小幅移动，未见新双线、旧位黑块、硬标签边或高光损伤。接受这一根实拍细线/这些轻档的有限验证；相对自动结果变化细微，不称为明显画质跃升，更不外推浓密交叠睫毛、眼镜或任意照片。

此前冻结自动 V5 在 makeup、beard、longhair 三张新源的轻档取得有限视觉成功，见 [新源记录](../qa/eye-closure-fresh-source-20261119.md)。自动 V5 的已知真睫毛反例仍失败，后续 V6/V7 也未解决自动材料误判；这些失败没有被人工路径的通过覆盖。

## 范围与后续

当前仅为不透明 RGB、已提供源眼部观测的轻闭合实验，固定回放 `0/-15/-30`；未提供自动睁眼、遮挡后真实纹理恢复、任意参数组合或眼镜处理。它验证了少量人工材料标注能纠正算法，不代表整套软件或全自动眼高达到 8 分。

普通 Rust 公共 `eyeHeight` / `eyelid` 仍未开放。JSON 可作为后续手工工具及 MCP 的材料输入合同，但本轮没有构建、部署或声称实现这些系统接口。照片、数组、模型和原生回放二进制仅保留本地，不纳入 Git。
