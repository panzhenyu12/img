# FUNC-026：多尺度眼镜语义候选与上下文分离

状态：独立算法 adapter 已实现并验证；未接入系统。细框材料提取未通过。

## 解决的问题

为包含长发/头顶，原解析器会扩大人脸裁切并递归返回最后一次结果。
这会降低细眼镜的源分辨率，并无条件丢掉先前有效 class6 预测。
眼镜街拍源图验证了眼镜预测从初轮 3170 个≥0.5源像素降为最后一轮 0 个。

## 实现契约

`experiments/glasses-source-detection-20261020/multiscale.py` 接收所有原始解析轮次，
包含原图 crop、19 类浮点概率、模型分辨率和轮次名称。
眼镜 class6 选择覆盖原始人脸点包围范围、源像素采样间距最小的一轮。
选择依据是源范围与分辨率，不是置信度比较、独立 QA 或修图输出。
头发、头部上下文和耳环继续使用最后完整上下文解析。

输出分别是 `eyewear_probability`、`earring_probability`、`hair_probability`、
`head_probability` 和来源/投影记录。它们是不同尺度的独立语义候选，不能
作为联合分类分布相加，更不能直接当不透明框、镜片 alpha 或硬固定范围。
只对已确认问题的 class6 保留细尺度候选，未泛化到任意初轮类别。

`replay_multiscale.py` 从已保存模型输出重放 adapter，登记跨尺度冲突，不回写
原图缓存、保护范围或变形图。原 raw logits/probabilities、source transform、
模型与脚本 hash 均留存于忽略的测试目录。

## 验证与边界

- 多尺度回归先复现失败：后轮看到额外长发，但眼镜概率从0.9丢为0；修复后
  原源坐标眼镜保持0.9，额外长发保持0.95。
- 暗脊原型回归：语义边界偏移3px且内侧存在更强瞳孔，合成细环可恢复。
  该测试通过不代表真实细框成功；真实上框误走眉毛，原型已拒绝。
- 两张真实源图独立重放：眼镜街拍保留3170个class6候选像素和上下文长发；
  用户无眼镜原图保留完整头顶上下文，class6≥0.5仍为0。两图hair逐值等于上下文。
- 眼镜图有1个eyewear/context-hair同时≥0.5的源像素，登记为未决，不强制归属。
- 一次冻结源提示的ZIM四候选都包含镜片内眼睛/皮肤，按官方分数选2后仍拒绝
  将其当细框/光学alpha。未使用QA调点或重选。
