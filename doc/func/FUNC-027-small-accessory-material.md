# FUNC-027 小耳圈细尺度解析与随动保形

状态：隔离 native 算法实验；暗光独立人像同请求 +30、+60、−60 已得到真实照片改善。未接入浏览器或服务，未代表全部首饰、整耳或人脸美学达到 8 分。

## 实际问题与原因

脸颊连续场可以消除明显裂口，但如果没有单独的附件材料合同，约 10×14px 的耳圈仍会随局部场拉宽或压窄。不能以几何行列式为正、整体图无明显裂口代替小附件保形。

本图旧缓存没有 accessories/ears 字段。对同一原图复跑现有 BiSeNet 模型的裁剪规则后，找到了另一个可重复的尺度问题：初始约 527px 人脸裁剪可识别两个 class-9 耳圈，投回源图有 282 个概率 ≥.5 的像素；头顶触及裁剪边界后，规则为了完整头发扩大到约 897px，耳圈最高概率降至 .193，最终没有概率 ≥.5 的附件像素。若只保留最后一轮，正确的细尺度附件证据就被覆盖。

隔离修复按任务保留尺度：头部完整性使用大上下文，小附件保留自己的细尺度概率和来源。源尺度语义不是光学 alpha，更不能直接当真实金属蒙版。

## 具体算法合同

1. 自动细尺度 BiSeNet class-9 连通区域只负责定位附件候选。原图、原 graph、模型和概率文件均绑定哈希，不检测修改后的照片。
2. 每个源区域在原图上做局部 ZIM，提示为源类别框外扩 4px、类别内最亮的源 RGB 像素；上下文每边扩 2 倍区域最长边。保留四个原始输出，采用模型官方分数最大项，未按成图美观挑候选。
3. 最高分 ZIM 在本图左侧包含了少量耳垂尾部，不能直接升级为完整金属 alpha。当前仅将细尺度 class-9 ≥.5 与 ZIM alpha ≥.9 的一致区域登记为高置信附件几何材料核心，左右各 103/110 个源像素。它仍可能含阴影、孔洞或遗漏细金属；不用于透明度合成。
4. 从同源耳概率 ≥.5、距材料核心 ≤2px 的真实邻近像素取得 21/2 个局部邻接点，明确它们是图像邻接，不是已知机械关节。没有手绘全耳框，没有移植其他人的耳环标注。
5. 材料与局部邻接共享一个自由平移量。沿用现有原始脸轮廓请求插值得到位置 prior、权重 100；附件跟随脸侧运动，不固定在原图坐标。保留完整源到请求扫掠及 1px fringe，检查实际求解后的完整扫掠。
6. 原 18446 个脸轮廓、unknown、颈线目标及全部权重、硬保护、网格和几何界限逐项不变。仅追加两个附件组，再使用已有 Rust native 连续场求解与真实照片采样。原眼眉完整材料合同仍保留。

脚本位于 `experiments/face-dark-accessory-20261021/`：`segment.py` 取得源局部 alpha 候选，`prepare.py` 登记源材料与邻接，`verify_shape.py` 验证真实源材料形状，`review.py` 生成同请求照片比较。细尺度概率由已有 `experiments/glasses-source-detection-20261020/audit_parser.py` 取得，其新诊断允许没有旧附件缓存，并分别保存 class-9 与耳概率。

## 已执行验证

先用未修复 +60 的最终 f32 场运行同一源材料保形回归，左右共享平移形状最大误差 .918/.733px，明确失败；添加附件材料后重新求解，误差均为 0，实际完整附件扫掠没有缺失，左右附件及双眼眉共四组 PNG 平移参考差均为 0。

旧源定位小区与金属高光 proxy 没有进入生成。使用相同的这些独立诊断点复核，+30/+60 新两侧局部主伸长均为 1、刚体拟合 RMS 为 0；之前 +60 可见金属 proxy 的较大主伸长中位数为 1.2327/1.2028。−60 的同一独立金属 proxy 主伸长中位数也回到 1，但其边缘包含未登记材料，仍有左 .000425px、右 .000116px 的刚体拟合 RMS，不能扩展为整片金属严格不变。

三档均逐张人工核对原照片、同请求旧结果和新结果的 10× 双耳圈、完整双耳、整脸及颈部：观察到正档耳圈拉宽、负档耳圈压窄改善，耳垂连接连续，未观察到新增硬缝。主审已独立查看 +60 左耳圈、完整右耳与整脸，以及 −60 整脸与右耳圈，确认局部改善且整耳变化仍保留；其余上述部位由实现审查者核对。不把同一人的反复查看当独立盲审。

源证据与结果位于忽略缓存 `test/results/face-source-relative-width-20261020/`：`dark-accessory-source-parser/`、`dark-accessory-source-zim/`、`dark-accessory-source-material/`、`dark-accessory-shape-red.json`；三档结果分别在 `dark-accessory-+30-offline/solve-2/`、`dark-accessory-+60-offline/solve-2/`、`dark-accessory--60-offline/solve-2/`，对应 `dark-accessory-low-review/`、`dark-accessory-positive-review/`、`dark-accessory-negative-review/`。三个 source shape green 文件分别为 `dark-accessory-low-shape-green.json`、`dark-accessory-shape-green.json`、`dark-accessory-negative-shape-green.json`。源图及原始双向结果见 [暗光源比例双向实验](../qa/dark-source-relative-20261021.md)。所有失败和旧图保留，没有重跑已通过的系统基准或重新编译整体工程。

边界：这是单张原图的算法修复和人工审查；自动模型核心尚非完整金属真值，局部 ZIM 官方得分也不是质量验收分。其他首饰、旋转附件、大侧脸、透明耳饰、复杂耳部遮挡及端侧延迟需要独立验证。

## 完整耳部后续

同请求 +60 的单次源软材料候选减轻了完整耳的拉伸，同时保留附件与邻接。
但最差原请求实现从 96.65% 降到 92.31%。进一步源审计发现原 128 个“脸轮廓”
控制点中 21 个在耳廓、4 个在耳饰，原幅度峰值也落在耳轮上，存在目标语义冲突。
已逐点保留旧账本并生成本图可见皮肤/耳交界；新的独立目标合同已做一次 +60
实图，真实脸侧响应改善，但耳根下端仍有约 1.04px 过冲及边缘局部应变，未验收。详见
[完整耳材料及源目标归属](../qa/dark-ear-material-and-source-roles-20261021.md)。

后续已把平均耳位置改为同源可见耳根的 SE(2) 拟合，并单独对照旋转不变有限
应变。+60 下耳根误差由 1.04 降到 .53px、目标峰值响应改善，但整耳刚体残差
和部分压缩有回退，整体视觉提升小，停止正向同目标调参。原 −60 请求也已
独立重建角色与姿态，单次组合候选的耳廓压窄有可见改善；新脸侧最差响应
67.57%→94.82%，原 128 账最大误差却从 .477 增到 .968px，完整保留这一取舍。

这仍为研究候选。反向在不变目标、权重和保护下追加两次材料位置更新，完整
源耳步长 3.6767→.4200→.0336px，达到登记材料坐标闭合；最终新脸侧最差响应
97.10%，右耳伸缩 .9938–1.0175。原 128 最大误差仍 .9538px，左耳局部最大伸长
1.0779，全部保留。每步核对完整耳形、源脸侧残差、原 128 账、耳饰和眼眉；
没有把坐标闭合称为全场最优或 8 分。有限材料消除的是额外
旋转惩罚，并不自动保证解剖合理或美学达标。实现入口集中在
`experiments/face-dark-ear-material-20261021/`，逐项结果见上述 QA 文档。

用户原照的后续单独登记为[源角色与有限材料对照](../qa/user-source-role-and-finite-material-20261021.md)：
没有迁移暗光图的耳点重分类。单改耳材料后整脸收益不明显；A0上脸目标仍有
接续斜率跳与左耳完整材料峰值回退，均未晋升。当前新因素是[源额顶—下眼睑
完整上脸曲线A1](../qa/face-anatomical-upper-transition-20261021.md)，重新定义自动
上脸轮廓请求，以源解剖锚点建立C2包络，保留颊部参考、下脸请求与全部真实
保护。它是独立的脸型目标候选，不能计作耳材料能量又一次通过，也不代表
照片美学已验收。实现及冻结单次对照入口为
`experiments/face-user-source-roles-20261021/anatomical_upper.py`与`a1_run.py`。

后续[细网格完整源支持实验](../qa/face-dyadic-source-support-20261021.md)证明，逆场中
不断累加移动材料扫掠会限制眼眉位移；加密后部分目标误差降低，但耳部局部应变
退步、整脸改善有限，未晋升。由此追加[源坐标小纹理原型](../qa/source-forward-texture-prototype-20261021.md)：
固定源材料完整方形足迹，构造正向场，再严格反求图片采样。双向小样的实际
像素几何、附件式矩形材料与邻近固定材料通过；非二进制参数出现一个严格
float64 RGB 舍入失败，完整保留。该原型不是完整人脸实验，也没有新增8分结论。
