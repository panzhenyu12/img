# FUNC-037：稳定源底图与前景配对

状态：2026-10-28，已进入默认 Rust 的联合脸颈路径；128 项人脸定向回归通过，12 项真实原图/正负参数已用主 native 核心生成并独立审核。没有构建或部署 Web/WASM，颈部向量场和衣物解析候选不包含在本次默认修改中。

## 要修复的实际问题

旧管线先估计前景 F、背景 B，再根据本次形变露出的空洞重新求 B，却仍采样旧 F。源混合方程 `C = aF + (1-a)B` 因此不再成立。真实倾斜人像中，约 0.001 像素的运动也会出现几十级色差，颈部出现并非几何裂缝造成的色块。

仅在露出空洞处重新配对仍然不够：当某个目标像素从部分覆盖变成完全覆盖时，空洞开关会改变源 F。独立反例中，位移从 0.99999 增到 1.0 像素，输出跳变 40 个码值。这个版本已拒绝。

## 默认实现

1. 联合脸颈路径的裁切范围只依赖源轮廓、源头部上下文和预留空间，不跟随当前目标轮廓取整。沿用原有求解余量，只在合法目标投影超出时补足。目标位移上界不等于积分流场上界，仍须另验边界支撑。
2. 源材质与供体权限不再因本次目标是否覆盖旧边缘而改变。缺失或断开的颈部证据仍使用既有脸部路径及其覆盖权限。
3. 在采样前，以完整源前景域求解底图；后续目标空洞不再决定这张底图。使用既有场景观测、供体排除和固定材质规则。
4. 对不透明照片，将底图 B 投影到给定 C、a 的可行 RGB 区间。`a=0` 时 B=C，`a=1` 时全部源颜色属于前景。透明图层保留原来的处理路径。
5. 采样预乘前景残差 `P = C - (1-a)B`，然后以同一 B 合成。使用双线性采样和浮点残差，避免把 F 先量化为 byte 再乘 a 引入新的插值误差。不改变形变请求、alpha 或用原图混合减弱效果。

实现：`core/image-core/src/face.rs`、`face_layer_pair.rs`。独立求解/采样回归：`face_source_pair_regression.rs`。

## 数值与行为验证

- 主核心 `cargo test --release --manifest-path core/image-core/Cargo.toml --lib 'face::'`：128 passed，0 failed，2 ignored。
- 12 项配对合同覆盖源颜色重建、alpha 端点、透明输入拒绝、亚像素采样、越界规则与滑杆跨覆盖开关连续性；另有 4 项实际底图求解合同，覆盖完整源域、目标薄边反例、衣物供体排除和固定配对。
- 独立实际 f32 采样检查：95,748,096 组枚举及 2,000,000 组随机源像素重组均逐 byte 一致。这只证明零位移源重建，不证明任意亚像素结果绝对精确，也不证明估计的分层是真实分层。
- 修复极小合法 alpha 导致可行区间反转的崩溃：区间相对已知可行点 C 表达，避免相减消去。具体反例 `f32::from_bits(612368385)`、C=255 已加入回归。
- 独立解析插值对比中，前景 byte 量化引起的 11,895/100,000 次一字节偏差，在残差采样中降为 1 次；剩余例位于浮点半字节舍入边界。

## 实图证据与限制

隔离验证先使用颈部向量候选，五张原图正负方向的源 alpha、固定权限、供体权限、材质标签、底图和裁切哈希一致。倾斜人像的局部颈部色块消退。随后专门验证最小固定 ROI 与原默认几何，避免将颈部曲线改变误归因于合成修复。

最终主核心对照包含 user ±60、hair ±60、dark ±100、makeup ±100、tilted ±1/±60，源图和操作图逐项核对一致。独立复核未见新增连续裂缝或大块肤色污染；user 低位颈边、dark 红衣领、tilted 小档颈部污染减少。user `(480,470)` 由旧输出 `[91,76,68]` 恢复为源背景 `[6,3,2]`；先前已修复的 `(471,380)` 仍为 `[29,22,20]`，保留源场景备选证据收益。旧输出未动的像素上有少量新变化（每图 1–34 像素、最大 1–3 码值），不能宣称所有背景逐字节不动。

中间隔离包曾漏带 FUNC-036 当天已接受的场景备选模型，导致旧脸颊亮点重现；发现后没有以该包验收，最终对账使用保留该修复的真实主核心。原输出与中间实验不是同一算法版本，不能混用。

本次只建立同一源分层的颜色一致性。耳旁旧轮廓残点、错误颈部/衣物语义、曲线自然度、隐藏背景纹理真实性仍需继续解决；额头/太阳穴启用时会改写共享发际域，跨该语义分支的组合连续性尚未获本项证明。不能据此宣称所有美颜可用或达到 8 分。
