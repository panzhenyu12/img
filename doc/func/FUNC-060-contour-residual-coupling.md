# FUNC-060 受约束轮廓的残差耦合

日期：2026-11-13。状态：隔离算法候选，未作为默认；不是画质达到 8 分的证据。

## 要解决的问题

即使源类别正确，某段脸颊离固定头发或五官太近时，请求可能超出安全位移范围。
逐点拟合会让这几个点先停住，邻点继续走，形成局部折角。继续增大导数上限
不能解决材料身份或自然曲线问题。

`face_bounded_field.rs::ContourResidual` 在原点目标上增加闭环残差二阶项：
`sum(w_i * length^4 * |D²_source_arc(d-request)|²)`。
使用源轮廓的非均匀弧长；处理的是未完成的位移，不是把原脸曲线拉直。
原轮廓目标、源图层和已有固定/刚体/防折叠条件仍在。

`bending_length` 用源像素表示，图像等比缩放时也必须等比缩放；固定 12px
只是本轮对照值，不是跨分辨率或所有人脸的默认参数。

## 已否决的无边界版本

二阶平滑没有最大值原理。独立 native 反例在局部产生 11.24% 超额位移，
而整体响应反而下降；不改目标不代表实际运动不会超过目标。
真实 dark 样片也出现少量额外沿目标过冲。因此无边界版本不能直接采用。

可选 `limit_projection=true` 对每个非零轮廓请求增加
`0 <= dot(d, request/|request|) <= |request|`，并在解后再次核对。
这明确改变了可行域，不能称作单纯数值优化。它只限制请求方向的投影，
不限制正交位移总幅度。零请求不定义方向、不加这两条约束；本轮只评价
单一 faceWidth，不外推到多功能组合相消的情况。硬刚体与此边界冲突时
报不可行，不悄悄缩短刚体请求。

## 实片与限制

woman ±60 在同一原图、同一源层和同一目标下：

| 指标 | 原候选 | 加耦合及投影上限 |
|---|---:|---:|
| 全轮廓响应 | .9749 | .9652 |
| -60 三点弦转角误差最大值 | 7.71° | 5.40° |
| +60 三点弦转角误差最大值 | 11.16° | 7.70° |
| 最大位置误差 | 3.033px | 3.033px |
| 沿请求方向过冲/反向 | 原有少量过冲 | 0/0 |
| 冻结区、零位移重构误差 | 0 | 0 |

转角是控制点诊断，不是照片审美分数。独立先看图审查认为 woman 的自然度
改善很小，无法确认稳定显著收益；dark 仅有轻微局部变化。没有新增明显裂缝，
也不能因此称为画质升级。无界 dark 响应 .681→.613 的损失必须保留报告，
不能只报告更平滑的数字。该项暂时保持可选，不取代源材料分类修正。

原本无约束冲突的 woman/user ±30 未见明显新增破坏。woman 浮点采样仍有
最多两通道为 255.00002（不是新增可见裂缝）；没有把它写成严格零越界。
