# FUNC-082 固定附件侧脸曲线的数值可行性

## 实际失败

新的眼镜正脸完成源材料准备后，普通 `faceWidth=+30/-30` 均返回 `side curve QP status PrimalInfeasible`。0 档保持原图。失败不是请求太强：原约束设计允许所有点停留在源位置，源曲线理应总是可行解。

从普通 Rust 入口捕获的两组实际输入各有 28 个样本、8 个固定点。曲率约束第 95 行只涉及三个固定变量；固定等式残差为 0，但该行与源位置相差 `1.2348133396e-6`，构成严格矛盾。输入均有限、相邻高度不重复。根因是曲率边界先在 f32 中相减，再转为 f64，而约束矩阵乘法直接使用 f64，源基线不一致。

## 修正

`face_flow.rs::project_side_curve` 改用源位移变量 `d=x-source`，源坐标先转换为 f64，再计算所有差分。目标仍是接近所需位移，并惩罚位移二阶差分；原本的人脸形状不被平滑目标重新拟合。

- 固定点仍为 `d=0`。
- 每点范围仍在源位置与请求位置之间。
- 一阶与曲率约束按同一源基线转换到位移坐标，右端非负，零位移成为明确的可行见证。
- 保留原最大迭代数、求解器容差和最小间距；不删眼镜保护、不缩小请求、不忽略失败。

这是同一数学意图的一致数值实现。旧的浮点矩阵本身含矛盾，不能声称新旧矩阵或成片逐比特相同。修复也不能保证复杂源轮廓的审美质量。

## 验证

真实失败输入被缩为源码内的坐标回归，不依赖照片或模型。先确认旧实现复现 `PrimalInfeasible`，再验证新实现通过正负方向、固定点逐比特不动、自由点仍有响应、点位不超请求区间。另有全固定源曲线反例，以及两项既有曲线形状测试；共 4 项定向测试通过。

新眼镜图普通 `0/+30/-30` 已能出图：零值逐 RGBA 恒等，正负档分别改变 36,025 / 36,117 像素。随后新增 `±60` 也完成独立原尺寸全脸、2×镜框、双耳颊、胡须颈部审图：双向响应可见，未见新增镜框弯曲/双影、脸颊台阶/硬缝、胡须断裂或颈边色线。14,607 个眼镜核心像素及眼睛、眉毛、鼻、嘴的受保护核心全部不变。结论只限这张正脸与这些档位，详见[独立实图复核](../qa/face-glasses-source-independent-20261119.md)。

三张既有源（胡茬、长发、用户原图）的当前配套源材料分别回放 `0/±30/±60`，均成功；与修复前相同输入的输出相比，零值完全相同，所有非零档最大每通道差为 1/255。改动像素数分别为 848～1140、357～597、10～88，符合数值实现变化的微小取整差异，不能报告逐比特相同。用户图另有旧源配套的对照，单独保留，不替代当前配套源验收。

本地证据位于 `test/results/face-new-frontal-20261119/side-curve-failure/` 和 `candidate-source/ordinary-curve-fixed/`。临时失败输出代码已移除；照片、矩阵 trace、生成图片和二进制不提交。
