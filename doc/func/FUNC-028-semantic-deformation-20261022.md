# FUNC-028 部位语义目标与连续形变实验

日期：2026-10-22
状态：隔离算法实验，未接入 Web、Go、WASM 或 MCP，未达到自然度验收。

## 目的

解决统一图像拉伸带来的脸部轮廓断裂、背景弯曲和五官位置冲突。当前实验把职责拆成四层：

1. 部位和关系描述：区分固定位置、保形随动和可编辑部位；
2. 功能目标控制：整体脸宽等操作单独生成源坐标目标；
3. 连续形变求解：在原始细网格上使用受限的降维连续场；
4. 可见性与材质审计：独立检查逆场、固定像素、材质覆盖、背景线和最终照片。

该拆分借鉴 LaTo 的几何条件与外观条件分离、AAGN 的部位关系、Inpaint4Drag 的 warp／显露区／修复分离。它不是这些论文的复现，也没有把生成模型作为实时美颜核心。

## 已实现

- `experiments/semantic-deformation-20261022/rust-controls/`：Rust 目标控制器。目标使用原图坐标，整体脸宽与五官/衣物等部位的运动规则分开；关系带有来源和置信状态，不会把标签自动当作物理约束。
- `reduced_field.py`：在原始 2px 源网格上建立嵌套降维基。保留原目标、材料角色、固定像素、背景线和能量块；粗控制点用双线性场，局部细自由度用于被几何审计拒绝的区域。只声明 C0，未宣称 C1。
- `input_contract.py`：执行冻结输入审计，重组原始 Hessian/RHS，核对目标、源材料、固定像素、映射、背景等式和文件哈希。
- `reduced_constrained.py`：可选的两轮有预算源 SOC 活动约束实验。Clarabel 只在 `--constrained` 时加载；代理源角点、求解状态和最终 f32 图像门槛分开报告。
- `refine_failed_cells.py`：根据实际逆场失败像素单元生成局部源节点，保持请求和阈值不变；不自动宣称修复成功。
- `run_reduced_photo.py`：离线运行、渲染和审计工具；拒绝覆盖结果，几何失败不渲染，RGB合同失败只标为诊断图。
- `focused_correction.py`：根据实际逆场失败单元的完整源坐标包围盒、过度压缩源单元及一圈邻域补齐约束，保留旧约束。每次仅求解一轮，12秒求解上限，R、目标、权重和源角色不变。

## 初始对照与保留的失败记录

在两张本地照片上运行了相同源目标的降维实验；第三张 hair 图目前只做了源目标审计：

- user `+30/-30/-60`：局部细化后的 `+30`、`-30`、`-60` 通过源/最终几何、材质和固定像素门槛并生成图；单次总耗时约 5.8–7.1 秒（包含离线审计），这只是实验机数据。
- woman `-60`：通过全部现有图像门槛并生成图，约 4.4 秒；`+60` 仍被最终几何门槛拒绝。
- user `+60`：无约束降维和可选源 SOC 约束均未通过最终几何门槛；约束分支最终状态为 `Solved` 但两轮预算结束、源代理未通过，因此只保留诊断，不渲染。
- Rust 整体脸宽控制器的独立 `user +30` 输入已通过冻结源审计，替换前 128 个脸部目标，保留其余 6,225 个源行、材料、锁和背景文件；第一次降维因 2 个逆场单元失败，加入局部自由度后通过全部图像合同并生成离线图。该新控制器与旧 lateral-gated 目标的实际输出差异很小（旧/新成片平均绝对像素差约 0.01），因此它是正确的目标接口改造证据，还不是可见审美跃升。
- **提交前勘误：** Rust 控制器 `user +60` v1 使用了 +30 父输入，仅改变脸部前128行；颈部与耳饰仍是 +30。内部数组和哈希一致性检查未发现这种语义错误。该实验在源场被拒绝，但不能用于判断完整 +60 目标的可行性；原目录保留为混档输入负例。此前完整 +60 父输入的其他实验结论不受影响。

现有通过图说明连续场和材质审计链路能工作，不能说明脸型自然度达到 8 分。轮廓曲线、身份纹理、耳颈连接和审美仍需逐图人工复核；数值无折叠也不等于好看。

## 继续推进：固定形变下减少采样变柔

针对上述眼睫毛变柔，新增 `resampling.py`、`run_resampling.py` 独立实验。完全冻结两份hair结果的实际f32逆场，先用Python双线性逐RGBA字节复现旧Rust成片，再比较局部有界Lanczos3。新核在不透明内部使用6×6邻域，每通道限制在相邻2×2源样本范围；透明邻域、图像边缘和alpha沿用双线性，整数/零位移保持原字节。没有按固定像素蒙版补写结果。

| 实验 | 复现与保护 | 采样耗时（Python/NumPy） |
| --- | --- | --- |
| hair +60 bounded-lanczos-v1 | 双线性全图逐字节复现；原场不变，5,591固定像素和alpha完全相同；181,798次移动采样中73,509次限幅 | 新核0.676秒，双线性0.110秒 |
| hair −60 bounded-lanczos-v1 | 同上；72,724次限幅 | 新核0.701秒，双线性0.113秒 |

主代理及另一模型实际查看脸部和眼部对照：新核的眉睫细节较双线性清楚，未见明显新增光晕；负档眼部仍偏软。已知连续正弦信号的三组RMSE由0.618/4.836/10.703降至0.019/0.456/4.649，仅说明这三种信号的重建误差，不能作为人像自然度评分。5项新采样测试通过，本实验目录累计27项Python行为测试和9项Rust测试通过。

这是成熟重建方法的针对性对照，不冒称最新论文算法。单次耗时约为双线性的6倍，未测Rust或浏览器性能。固定核不解决各向异性缩小时的混叠；逐通道限幅可能压低真实极值或影响边缘颜色。新6×6采样范围也不同于原2×2材质合同，未把旧RGB oracle结果挪用为新核验收，尚未替换生产渲染器或声称达到8分。

## 继续推进：嘴侧比例诊断与独立分区目标

`diagnose_face_proportions.py` 对冻结的原轮廓、请求轮廓与实际轮廓测量：user / woman / hair 的 +60 嘴宽／同高脸宽分别从0.4726 / 0.5919 / 0.5807升到0.5172 / 0.6424 / 0.6309。嘴高度脸宽实际与目标差小于0.03px；鼻唇不动而脸颊收窄约8%，是笑口相对显大的主要几何来源。不是求解器把本应移动的嘴唇漏掉，也不由“嘴侧未碰撞”证明比例合适。

新增 Rust `regional_contour_v1`，保留原 `whole_face_width_v1` 行为。显式height/gain节点用PCHIP插值控制原半径位移，仅改变位移分配；全1节点与原目标逐点相同。保形部位使用同一profile在源锚点上的平移。profile不排序、不自动归一化，不称原轮廓C1、解剖真值或审美标准。

首个探索候选在成图前固定：顶部及眼高gain=1，嘴高gain=0.60，归一化高度0.94和1的gain=1。源眼/嘴高度来自本图已有多边形；0.60和0.94不是研究认证参数。另用统一gain匹配候选的**请求轮廓面积**（hair 0.872813、woman 0.872774），用来区分“区域分配”与“整体少修一些”。统一gain对照明确比旧整体+60弱，不叫同强度修复。设计记录见[研究协议](../research/regional-face-target-experiment-20261022.md)。

`prepare_regional_input.py` 只接受已支持的原始woman/hair源输入；128脸点由Rust重新生成，hair的18个颈点按同一profile的源弧入口gain联动，保留原弧长渐变。独立SciPy PCHIP核对目标和颈部规则。原材料、固定像素、映射、权重、H与背景等式不变；未知附件与非零附件位置先验拒绝，防止再次出现名义同档而附件混档的问题。

## 约束和失败处理

- `R` 必须有独立锚点；若活动源变量出现零行或无锚点，构造立即失败，禁止静默锁死目标。
- `source_direct_proxy_pass` 只表示源网格角点的几何代理检查；`source_convex_gate_pass` 还需要实际约束求解状态。二者不替代最终 f32 逆场、RGB、材质域、固定像素、背景线和照片审美检查。
- Clarabel 的 `MaxTime`、不可行性证书和代理通过分别记录，不能把其中任何一个改写为照片通过。
- 所有强度仍使用原请求，不通过缩小滑杆、剪裁目标、放宽裂缝阈值或大面积模糊来制造“通过”。

## 下一步

整体脸宽目标适配、同档强度检查和独立分区目标已实现。下一步从源图证据建立部位语义，区分眼高、嘴侧和下颌区域；不能把无标签36点oval直接称为精确骨相定位。扩展未用于调参的不同脸型／表情与遮挡，沿用相近编辑量对照。每个操作都要保留目标、执行器、可见性/修复和人工照片复核四类证据。生成式修复只作为显露区的后处理候选，不能替代连续形变或阻塞手工链路。
