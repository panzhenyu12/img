# FUNC-028 部位语义目标与连续形变实验

日期：2026-10-22
状态：隔离算法实验，未接入 Web、Go、WASM 或 MCP，未达到自然度验收。

## 目的

解决统一图像拉伸带来的脸部轮廓断裂、背景弯曲和五官位置冲突。当前实验把职责拆成四层：

1. 部位和关系描述：区分固定位置、保形随动和可编辑部位；
2. 功能目标控制：整体脸宽等操作单独生成源坐标目标；
3. 连续形变求解：在原始细网格上使用受限的降维连续场；
4. 可见性与材质审计：独立检查逆场、固定像素、材质覆盖、背景线和最终照片。

该拆分借鉴 LaTo 的几何条件与外观条件分离、AAGN 的部位关系、Inpaint4Drag 的 warp／显露区／修复分离。它不是这些论文的复现，也没有把生成模型作为实时美颜核心。

## 已实现

- `experiments/semantic-deformation-20261022/rust-controls/`：Rust 目标控制器。目标使用原图坐标，整体脸宽与五官/衣物等部位的运动规则分开；关系带有来源和置信状态，不会把标签自动当作物理约束。
- `reduced_field.py`：在原始 2px 源网格上建立嵌套降维基。保留原目标、材料角色、固定像素、背景线和能量块；粗控制点用双线性场，局部细自由度用于被几何审计拒绝的区域。只声明 C0，未宣称 C1。
- `input_contract.py`：执行冻结输入审计，重组原始 Hessian/RHS，核对目标、源材料、固定像素、映射、背景等式和文件哈希。
- `reduced_constrained.py`：可选的两轮有预算源 SOC 活动约束实验。Clarabel 只在 `--constrained` 时加载；代理源角点、求解状态和最终 f32 图像门槛分开报告。
- `refine_failed_cells.py`：根据实际逆场失败像素单元生成局部源节点，保持请求和阈值不变；不自动宣称修复成功。
- `run_reduced_photo.py`：离线运行、渲染和审计工具；输出覆盖前拒绝，失败只保存诊断，不渲染成通过图。

## 实际证据

在两张本地照片上运行了相同源目标的降维实验；第三张 hair 图目前只做了源目标审计：

- user `+30/-30/-60`：局部细化后的 `+30`、`-30`、`-60` 通过源/最终几何、材质和固定像素门槛并生成图；单次总耗时约 5.8–7.1 秒（包含离线审计），这只是实验机数据。
- woman `-60`：通过全部现有图像门槛并生成图，约 4.4 秒；`+60` 仍被最终几何门槛拒绝。
- user `+60`：无约束降维和可选源 SOC 约束均未通过最终几何门槛；约束分支最终状态为 `Solved` 但两轮预算结束、源代理未通过，因此只保留诊断，不渲染。
- Rust 整体脸宽控制器的独立 `user +30` 输入已通过冻结源审计，替换前 128 个脸部目标，保留其余 6,225 个源行、材料、锁和背景文件；第一次降维因 2 个逆场单元失败，加入局部自由度后通过全部图像合同并生成离线图。该新控制器与旧 lateral-gated 目标的实际输出差异很小（旧/新成片平均绝对像素差约 0.01），因此它是正确的目标接口改造证据，还不是可见审美跃升。
- **提交前勘误：** Rust 控制器 `user +60` v1 使用了 +30 父输入，仅改变脸部前128行；颈部与耳饰仍是 +30。内部数组和哈希一致性检查未发现这种语义错误。该实验在源场被拒绝，但不能用于判断完整 +60 目标的可行性；原目录保留为混档输入负例。此前完整 +60 父输入的其他实验结论不受影响。

现有通过图说明连续场和材质审计链路能工作，不能说明脸型自然度达到 8 分。轮廓曲线、身份纹理、耳颈连接和审美仍需逐图人工复核；数值无折叠也不等于好看。

## 约束和失败处理

- `R` 必须有独立锚点；若活动源变量出现零行或无锚点，构造立即失败，禁止静默锁死目标。
- `source_direct_proxy_pass` 只表示源网格角点的几何代理检查；`source_convex_gate_pass` 还需要实际约束求解状态。二者不替代最终 f32 逆场、RGB、材质域、固定像素、背景线和照片审美检查。
- Clarabel 的 `MaxTime`、不可行性证书和代理通过分别记录，不能把其中任何一个改写为照片通过。
- 所有强度仍使用原请求，不通过缩小滑杆、剪裁目标、放宽裂缝阈值或大面积模糊来制造“通过”。
