# FUNC-076 源轮廓混色与背景上下文配对修正

状态（2026-11-19）：隔离算法候选，已由普通 Rust 人脸入口回放；未切换应用默认源准备。不是整个美颜产品可用或 8 分的声明。

## 具体问题

瘦脸露出的背景包含旧胡茬灰影；只改善背景后仍留下与新脸缘分离的细暗线。前者来自模型把边缘混色当成可读背景，后者来自原 trimap 将仍含前景的像素硬判为背景。分别核对背景、覆盖和成片，不能用平滑几何掩盖。

## 候选合同

1. 沿用同一源图、模型与形变参数，256px 局部窗口、128px 步长、sin² 重叠权重。模型可读背景与原编辑支持之间留 4 源像素未知带。无已知上下文的窗口剔除后必须仍完整覆盖要接受的区域，否则候选不可执行。
2. 原 trimap 非背景支持向外 4px 范围内的硬背景降级为 unknown，前景种子及其他类别不变。同一 MEMatte 模型重估一次；不直接复制原 raw alpha，不将新 alpha 自动当成运动权限。
3. 新覆盖必须配合同一源域真实预测的背景。worker 已把写入 mask 外像素恢复为原图，故不能把该合成结果称为外圈预测。以扩展 target、零额外 dilation 取得相同模型输入的外圈预测，并验证旧域输出等价。
4. 对照同时包含旧 official alpha、新 official alpha、新 alpha 配新外圈背景三组；保留旧 paired alpha 成片作为参考。普通入口可能按背景提高覆盖下界，不能宣称实际消费 alpha 固定。
5. 零档须逐 RGBA 等于源图。源图、运动界面、附件许可、用户保护及脸型目标均保持不变。模型预测只是假设，不是隐藏纹理或透明度真值。

## 验证与边界

- `portrait-614810`：0/±30/±60 三组共 15 张普通入口输出。独立审图确认新配对清除了本样本双侧旧轮廓细线，未见新增断层/亮边，脸宽仍响应。新 matte 的最大差异位于颈衣领；该区域四个非零档仍逐 RGBA 等于源图。
- `portrait-762020`：同规则、无调参完成另一组 15 张输出；审查结果记录在下面的 QA 中。
- 用户原图：沿用原检测与源准备，固定规则完成新候选0/±30/±60；与历史普通入口对照核对后未见新增裂缝、残线或首饰断裂。该回归保留既有脸型曲线的评价边界，不宣称重新通过所有脸型效果。
- 独立静态背景暗线的已知真值合成反例：两次同模型推理，扩展未知带后未出现超过 1 字节的模拟误拖，但 alpha 误差略增；不能据此证明复杂阴影安全。
- 当前仍不具备实时滑杆性能：复用现有 native 二进制、同一 1024×874 源与 +30 请求连续两次，成片逐字节一致，但算法调用约 5.7/6.1 秒（本机并发开发状态，非独占性能基准）。源分层与背景准备仍在每次调用重做。已有分段计时的 `sample grid` 包含源背景重建和运动场，不能把其约 4.4/4.8 秒全部归因于重采样。该测量不含前置模型、PNG 编解码，不是浏览器速度。
- 当前只接受原 mask 内 32px 加外圈的背景预测。更深区域接边、复杂背景、真实投影与更多姿态仍需验证；不开放无界自动扩域或循环调阈值。
