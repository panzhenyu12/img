# FUNC-056 手工源类别纠正与饰品保护

日期：2026-11-10。状态：**隔离源算法候选；一张独立照片的手工选区流程完成0、±30、±60、±100成片审查。自动类别识别未通过，未接入系统，不能据此宣布整体8分。**

## 解决的问题

独立深色人像含两个小耳环。ZIM最高分附件候选将左耳环旁红色耳垂也识别为附件。形变器正确遵守这个错误输入，将真实皮肤固定，可动皮肤alpha同时为0。提高模型分数、保持“附件核心不变”或只补光学alpha都不能证明修复。

源是683×1024原图；SHA-256 `c1999306aa24f649f2aff3c078cbb5f33f060903f88b3326ab2365657336a548`。原语义网格342×512，先通过相同faceparser模型的原生细crop补充耳和附件，再进行源类别实验。RGB未重采样或修改。该原生Pillow/ORT概率不等于旧浏览器Canvas logits。

## 保留的失败证据

- 源自动点框最高分候选吞耳垂；不能按较低分候选视觉更好就替换。
- 从原始 `P(skin+ears)≥.95`、`P(accessories)≤.05` 的可靠区域自动生成负点。左耳分数从.7747升到.7828，误分皮肤alpha仍接近1。右耳无可靠负点，不伪造提示。
- 助手查看源图后明确标注皮肤负点 `(246,526)`，实际ONNX labels `[1,0,2,3]` 正确；最高分候选在负点仍有.999695 alpha。不是工具丢了negative token。
- 两个源金属点和一条源耳垂笔刷配合宽unknown MEMatte，能排除刷过的点，却扩大到更多耳上皮肤。这个结果未用于成片。

这些失败说明：当前模型不能可靠地仅靠少量点自动区分本图细小金属与皮肤。修图流程需要明确源类别纠正能力。

## 已实现的源处理流程

代码与完整复现位于 `experiments/face-interface-multiphoto-20261110/`。

1. 查看原生源像素，显式用12顶点多边形定义完整耳环类别支持，含暗反射和环内暗区，并排除下方红色耳垂。这是助手模拟手工选区的源标注，不是用户已操作过，也不是自动泛化成功。
2. 8倍几何栅格计算多边形面积覆盖，再BOX传入原342×512语义网格。几何graph固定后，任何matting输出都不能覆盖它。多边形覆盖不是光学不透明度。
3. 对静止材质另保留内部unknown及外侧1.5px窄带，只把看清的金属笔触设为已知前景。该静止材质matte单独存储，未注入本轮成片，也未拿来替代可动皮肤alpha。
4. 独立从原skin/ears/neck/person/hair与纠正后的附件支持生成moving-skin trimap。448×448源crop无缩放，1273个实际注入点全部unknown。MEMatte在这些点估计可动皮肤覆盖，不能将“排除附件”直接当成皮肤。
5. 使用同一冻结原生二进制和已有Rust源层、形变、反向采样成片，没有构建Web/Go/WASM/Cargo。

本图试验使用**固定的小型耳环角色**。主用户图的悬垂饰品需要跟随耳根做刚性运动，不能共用“所有饰品都固定”的假设。附件是什么，以及附件如何随主体运动，应是分别可修正的输入。

## 实际核对

同一源手工标注完成0、±30、±60、±100。检查整图、原生整脸连完整颈部、左右耳局部以及右颈放大，未只盯着被修改的饰品。

- 原生手工支持144个完整核心像素，各非零档均逐RGBA保留。±60另核对传输后116个附件核心，全部保持。
- 暗部 `(241,519)=[18,0,0]`、`(240,518)=[20,5,1]` 和环内暗区均保留，没有用亮度阈值剔除暗反射。
- 真实耳垂 `(247,528)` 从错误固定、alpha0恢复为可动、alpha.99949；±60分别横向−1.166/+1.371px。两处源金属观察点仍固定且RGBA相同。
- 自动→手工时，前128个源轮廓控制与requested值相同，附件控制总量310→309；投影目标与完整场不同。不能宣称这是“保持全场不变的纯光学改善”。
- 手工graph固定时，再增加moving-skin alpha的±60对照，controls/requested/feasible/realized和完整forward/inverse逐字节相同；新增变化245/481px，最大13/20色阶。
- 0输出与源逐RGBA完全相同；所有被测输出alpha通道不变。0使用同一冻结二进制关闭trace单独检查，未伪造几何trace。

±30整脸响应温和，没有观察到新的大裂缝、断饰品或右颈独立旧边；±60的错误固定耳垂已释放，局部没有新增撕裂。±100仍保留饰品，脸型变化更明显，固定附件对局部曲线的限制也更明显，强档审美不能由这些数值验收。原有领口阴影并不是新裂缝。该单样本手工路径已能作实际编辑验证，自动流程和一般自然度还不能验收。
