# FUNC-036：源照片边缘与背景误差分离

状态：2026-10-28，默认 Rust 核心的源背景证据已修正；整体瘦脸仍未通过可用性验收。Web/WASM 未重新构建或部署。

## 问题与实现

原图边缘的 RGB 混合宽度不等于人脸解析 mask 的非零范围。直接冻结解析零值会留下旧轮廓；反过来，把 RGB 与预测背景的所有差异都解释成前景，又会带动真实背景纹理。

`core/image-core/src/face_scene_edge.rs` 只读取源照片、源覆盖率、已观测连接人物及保护层。它在窄边带外寻找可见背景，拟合局部仿射颜色；拟合样本需有二维空间支撑，并通过逐通道残差和梯度检查。纹理背景或被头发、耳饰、用户保护区隔开的样本不能强行外推。

默认实现包括：

- 使用与方形栅格采样一致的八邻域距离，禁止从两个被保护像素之间斜穿；斜边不会比竖边少恢复半个边带。
- 背景拟合验证范围至少覆盖允许外推的距离，避免把周期纹理的一小段误当成完整渐变。
- 保留每通道拟合残差，将背景视为有误差的区间，再计算源混合方程 `C=aF+(1-a)B` 所需的透明度下界。已被模型误差解释的背景差异不新增移动 alpha。
- 后层头发不能作为遗漏皮肤被重新纳入移动层；同一源混合关系用于旧覆盖、采样和底图。

透明度下界不是准确物理 matte；背景模型也不能证明隐藏区域延续相同纹理。此实现没有改变脸型请求、滑杆幅度或使用最终图像磨糊。

## 背景观测接入连续求解

dark 正向样片的颈侧色块来自另一处明确原因：`sceneBackground` 在空间中由无变有时，旧实现直接覆盖已重建的底图。例如 `(442,587)` 到 `(442,590)` 的新前景覆盖均为零，背景仍跳变约 15 个码值，局部观测的有效区域被画成了多边形。

`face.rs::reconstruct_with_scene` 将拟合场景颜色作为一个局部软数据项，加入与邻接孔洞相同的浮点重建求解，删除最后的逐像素硬覆盖。保留原始源混合可行区间、低 alpha 处的高精度背景观测、保留纹理及零前景处的原 RGBA。此举只约束隐藏底图，不改变脸部位移。

新增独立线性背景真值：八像素宽的露出条带只有斜向半域拥有准确场景观测，旧后覆盖产生 8 码值的错误接缝；新求解通过相邻差不超过 3、可靠区域误差不超过 2、已观察棋盘纹理逐字节不变的合同。另一项 `alpha=.05` 的混合纹理真值要求背景误差不超过 2，并保留原 24 级纹理中至少 20 级对比。两项及原八项底图回归全部通过。

七组新默认成片在 `/tmp/face-scene-solve-20261028/`；dark 已定位的多边形色块消失，源旧轮廓细点与颈部几何运动问题仍需继续处理。

独立复核七组及细尺度耳饰组合：未见新增明显视觉退化。dark 两个已定位相邻像素跳变由 13→5、14→1 码值；仍有局部弱变化，不把可见多边形消退表述为所有梯度归零。最终脸部定向回归 **108 passed、0 failed、2 ignored**，未进行整仓构建。

## 验证

### 最近场景模型失败时的备选源证据

后续对用户图 +60 的颊缘亮点逐像素追踪，确认 `(471,380)` 新的前景采样已经为零，但底图仍是 `[109,80,72]`。原因是原透明度约 0.276 过低，源混合可行区间强迫背景保留旧肤色；最近背景块恰好没有通过模型有效性检查，算法便丢掉了全部场景证据。

同一原始搜索范围内还有七个可见背景块通过原有检查，颜色预测相互一致。因此默认 `prepare` 增加一个受限分支：仅在最近模型失败、原 alpha 大于 1/255 时，检查同范围内其他可见模型；每个模型仍须通过原有拟合条件，全部有效模型的逐通道误差区间必须相容。使用它们误差区间的并集保留不确定性，不选择最暗结果，也不把相关样本当成额外置信度。零 alpha、保护像素和原修改范围都不扩大。

四项新回归覆盖最近块失效、可见异质背景、带非零解析概率的周期背景、零 alpha/附件保护，与原有测试合计 15 项场景证据测试通过。四张真实照片共八组对比中：用户 +60 的 165 个像素、−60 的 76 个像素改善原边缘亮点/黑齿；dark ±60 只改变颈侧窄带；hair ±60 和妆容图 ±100 与旧默认逐像素一致。独立复核未见新连续暗边、肤色断层或耳饰损坏。用户图上述亮点变为 `[28,22,20]`，受保护附件位置不变。

这项窄修复已进入默认 Rust 核心；附件旁细残线、dark 旧轮廓和颈部形状仍未完全解决。补查背景块增加计算量，两处等价短路前后成片逐字节一致，但当前单次 debug 数据不能证明整体加速或实时。图片、密集源证据及对照二进制只保留本机 `/tmp/user-scene-evidence-20261028/`，不加入 Git。

合入后仅重新构建 native 算法核心，`face::` 定向回归 **112 passed、0 failed、2 ignored**；主核心重新生成的用户 ±60、dark +60 与独立审过的候选 PNG 文件逐字节一致。该验证证明采纳的是已审算法，不代表 Web/WASM 已更新或整体审美验收。

低对比周期背景曾在 96 个纯背景检查点中误增 94 个 alpha，最大 0.013014；纳入背景误差后，该反例为 0 个。扩大至 18 个周期、相位、方向组合，默认算法的 1728 个检查点无误增。已知遗漏边缘仍满足背景误差小于 0.8 码值、源混合重建误差不超过 0.51 码值。

独立附件测试覆盖耳朵/饰品、正负 100、65%/25%/10% 混合边；源位置保持不变，周围无附件颜色副本，另一侧脸廓仍实际变化。该结果排除了当前固定附件采样的一种怀疑，不代表模型能检测所有附件。

本轮默认 `cargo test --manifest-path core/image-core/Cargo.toml face:: --lib -- --test-threads=4` 为 **106 passed、0 failed、2 ignored**。其中三项为明确隔离的尾部候选合成测试，不能计为默认算法效果证据。

## 真图边界与未采用候选

七组既有原图回放位于本机 `/tmp/face-scene-interval-20261028/`。用户图和头发图的大面积颈侧断层未再出现，但原脸缘仍有细小残点/暗线；妆容图负向强档曲线仍不自然。耳饰检测修复单独见 [FUNC-035](FUNC-035-face-detail-parser-scales.md)。

把边缘带从四像素直接扩为八像素，并用布尔连通性筛选，虽然通过合成测试，却在头发图制造了新尖刺，已从默认路径撤回。受控消融确认该例的尖刺来自连通性筛选撤销了已有背景支持；关闭筛选又失去孤立背景残差的保护，因此也没有直接采用。仅保留测试入口，实际失败不得被合成测试覆盖。

进一步的源尾部候选仍在 `/tmp/face-tail-ablation-20261028/` 隔离比较。必须同时保留已有效的源分解、消除旧尾部、保持真正背景与附件，并通过真实多图正负方向审核，才可替换默认。

测试照片、渲染图、模型、密集 trace 和二进制不加入 Git。
