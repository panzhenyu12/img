# FUNC-050 脸颊与邻接头发的共同运动候选

日期：2026-11-06。状态：仅原生 Rust 测试入口的算法候选。未接入 Web/WASM、未部署，不能作为整体瘦脸可用或 8 分结论。

## 原问题与范围

默认路径将全部头发作为位置固定的附件。脸颊紧邻头发时，原瘦脸请求被附件距离过渡压成零。共同运动候选允许一段观察到的邻接头发与脸颊一起移动，同时保留外部发缘、远处头发、五官和显式保护。

这是编辑语义上的选择：移动相邻头发纹理，不是检测出后发，也不意味着头发是皮肤。当前实验适配器同时改变运动许可和共同前景的光学准备，不能将结果解释为只验证了某一个几何变量。它尚未成为公开 API。

用户照片的主要障碍不同：耳廓和耳饰旁 1–2 px 内的控制点受到自动附件位置锁；这些位置没有头发。扩大共同头发区域不能修复这张照片。请求到可行目标阶段已将大部分运动删去，增加积分精度或迭代次数不能补回来。

## 外发缘保护

最初的候选只在低分辨率 mask 中心检查 head≥.98，遗漏了该节点的双线性支持范围。真实照片 ±30 中，外侧发缘出现 0.8–2.6 px 位移，因此该版本没有采用。

当前保护从原始 head mask 确定与图像边界连通的低置信外部；只有完整 mask 双线性支持加 3 个源像素的观察/采样余量都不接触该外部时，才允许共享该节点。该区域只取决于源证据，正负滑杆共用；没有按目标强度突然开关局部区域。内部分类孔洞不自动等同外部背景。

额外修复了适配器没有验证实际被写入的 `skin` raster 尺寸的问题。缺失、长度不符或同长度但宽高不同的 skin 输入不再进入适配，避免越界和错位。

## 同版真实照片对照：保护层增量

输入均为已有缓存 PNG 和 graph，不重新检测、不改变原请求。每图 ±30，同一源码分别执行当前默认路径与共同域候选。独立审计以原始 head/hair 定义外部连通的 2 px 高置信发缘圈。

五张照片、十组参数中，该圈的输出 RGBA 变化为零，前向位置精确不变。相对默认路径，四张邻发照片仍有实际响应提升：

| 样本 | 默认请求实现比例 −30 / +30 | 加外缘保护的共同域 −30 / +30 |
|---|---:|---:|
| woman | 6.5% / 6.3% | 61.8% / 70.7% |
| makeup | 16.4% / 16.9% | 47.9% / 49.2% |
| hair | 16.5% / 17.9% | 70.7% / 70.4% |
| roll | 15.7% / 15.3% | 38.8% / 38.3% |
| 用户照片 | 33.8% / 34.3% | 基本不变 |

比例为前 128 个原轮廓控制的 `Σ(request · actual) / Σ|request|²`，不是美观评分。请求完全相同，默认版照片与上一次默认照片逐 RGBA 相同。已查看四张原尺寸脸部双向对照，未见早先的矩形裂口；仍存在耳部过渡和局部压缩风险。

例如 makeup +30 的最小局部尺度约 .420，默认为 .611，说明响应更明显也可能伴随更强纹理压缩。正的采样 Jacobian 不等于自然，也不证明连续全路径或全局不交叠。makeup 的原耳/耳饰 mask 为空，不能用零改动声称这些部位受保护。

## 成片回归发现的另一个问题

`face_occlusion_regression` 直接渲染带坐标纹理的肤色/邻发图，检查两方向的实际肤色边缘移动、非空保护区、远发和外侧背景。保护区还做无保护对照，避免本来没动就被算作保护成功。

加入外发缘保护后，中脸位移回归失败。trace 显示中脸本身 `jointOwned=true`、权重为 1，却由约 −1.5 px 请求得到零目标。上部固定点通过旧单侧 QP 的绝对侧向单调约束，将一整段中脸请求压为零。这不是需要撤掉外缘保护的证据，而是曲线约束与编辑目标冲突的反例。

小幅 `0/±.01/±.001` 输出检查没有发现光学跳变，但小幅通过不能抵消中幅度无响应。

## 源相对曲线投影：已实现的合同和未通过项

`face_displacement_curve.rs` 将未知量改成源轮廓上的侧向位移。数据项按源弦长积分，正则只作用于新增位移，不要求原脸型单调或凸。固定位置、请求方向/幅度、相邻位移差不超过源弦长的 .25 都保留。它是一维目标投影，不是整幅图的拓扑或自然度证明。

实拍验证否定了直接采用第一版：makeup −30 的最差局部尺度由 .473 降至 .243。其原因之一是把已被附件限制的 desired 仅作为软目标，平滑又向低可达区搬入了位移。独立回归复现：局部容量 .15 px，输出却为 1.245 px。

容量修复将 `source ↔ clamp(desired, source, requested)` 设为硬范围，首末两个点保持输入 desired 来约束子段连接；固定点优先，范围与梯度冲突明确报错。实际 makeup 控制90的 preQP 位移 .1218 px 不再被抬成 2.3369 px。新 trace 记录 `preProjectionContourTarget`，可区分原请求、局部可达意图、投影目标和实际运动。

较宽的 `L/10` 弯曲尺度又造成明显降幅和连接处新转角。当前隔离版本使用统一的 `L/25`，没有按照片调参。合成成片 ±30 双侧均有 32/32 行发生正确方向的可见移动；36个显式保护像素、12800个外侧背景像素和504个远发像素均不变，无保护对照中保护块36个像素确实会动。8项曲线合同和3项共享域/成片回归通过；相关默认积分、发际线和脸颈回归也通过。

同版五图 ±30 的原请求实现比例为 woman≈70.6%、makeup≈46.1%、hair≈72.0%、roll≈41.7%、用户≈34.2%。44,184个实际变化、原hair≥.5的输出点，其真实 f32 逆采样四角正权重未碰到原发缘、耳、饰品保护圈；这些固定圈 RGBA 不变。这一检查不包含 RK 连续路径，原实拍没有显式 protectMask。

**仍不采用为默认算法：** woman 某个原目标转角约1.035°的位置，实际转角约4.713°；roll −30 的最小局部尺度约 .315。原尺寸对照未见明显黑裂，但局部曲线与纹理需要继续改。进一步的 ±60 回放中，woman 两方向出现端点/梯度约束冲突，另外八组能够渲染；渲染成功不表示强档效果验收。没有静默退回旧曲线或降低滑杆值。

因此目前完成的是可复现的错误定位、外缘保护、局部容量与连接合同。耳廓/耳饰的固定身份、容量曲线本身的锯齿和实际场压缩仍是不同问题，不能靠继续调单个平滑常数宣称修复。

## 连通耳廓候选与非耳材料回归

隔离模式 `shared-cheek-ear-v1` 在共同域/源相对曲线候选之上，将观察到且连通的耳廓作为柔性前景随同一场运动。耳语义保留，不改标为皮肤；分类先验只进入原有物理 matting，不直接当作不透明度。饰品、用户保护以及不连通耳岛继续固定。只有完整的脸颈连接证据与非空高置信耳 mask 才启用，因此空耳输入与 `shared-cheek-curve-v4` 必须逐像素一致。

第一轮用户照片 ±30 的请求实现比例从约 .34 增至 .55，但出现明显下颌咬口。实际源点 `(461.5,401.5)` 不是耳廓，却被新策略的全局 inferred-person 条件固定，距可动轮廓只有约 2.45 px；最差局部尺度降至 .034。此版本否决，不能把响应提升视作可用。

修复只撤销耳策略对原有非耳脸颈连接/边缘恢复的全局阻断，不取消真实饰品、衣服或用户保护。实际 `adjust` 回归中，独立 skin/person 仍观察到、head/face/neck 漏检的 8 个带纹理颈部点：修复前 ±60 均为参考版 8/8 移动、耳候选 0/8；修复后两方向均 8/8 移动。另验证非空耳区的显式保护，空耳 ±30 与参考版全图字节一致。实拍仍需检查下颌曲线、耳外缘的旧纹理残留与实际采样，测试通过不能代替成片验收。

修复后的同版实拍已确认下颌咬口与颈侧突起消失；该针点恢复约4.4px运动。用户±30整场四角最小尺度恢复至 .751/.689，550像素显式耳部保护的成片与前向位置保持不变，实际逆采样未碰到原饰品或外发缘。**但耳外缘仍有残影，不能据此采用整个候选。** 实际渲染探针显示这些点没有冻结、逆采样也未越过保护：耳先验约 .48/.68 被局部颜色线压成物理alpha .0017/.0208，原耳边颜色因此留在静止背景板。收缩时新前景alpha已为0，输出仍接近原耳边色。进一步扩大几何许可不会解决这个光学错误。

## 闭环曲线候选

局部转角并非积分器跟不上目标：用户控制28在请求阶段约−5.45°，附件距离限制后的目标已变为−12.92°，投影为−13.03°、实际为−12.87°。人工子段恰从27开始，首两点非零锁把这个坏转角钉住。woman强档同样存在矛盾：锁定位置到低容量点需下降4.1675px，而 .25 梯度与源弧长只允许3.9090px，零位移本可行却被人工锁排除。

先尝试把两侧子段分别扩展到已观察零容量区，保持原物理弯曲长度。真实两图±30/±60均可渲染，用户28的−30转角改善至−8.09°，但成片回归发现左右区会在非零容量点重叠，故否决分开的开放子段方案；未用先后覆盖、平均两解或放宽测试消除错误。

当前 `shared-cheek-ear-periodic-v1` 对原始128点闭环共同求解源相对侧向位移。数据积分、二阶差分及 .25 梯度约束都包含首尾连接，仅保留真实固定和原始局部容量；没有人工非零端点锁。物理弯曲长度是原两侧核心弧长之和除50，即两侧旧长度/25的平均，**不是声称每侧旧平滑尺度完全不变**。轴向请求保留，此侧向投影不保证完整二维切线或成片自然度。

16项曲线测试覆盖容量、真实固定、正负、缩放、非均匀采样、闭环起点旋转与逆序；实际渲染的重叠反例已由失败改为通过，±30双侧各32/32检查行均有正确可见位移，36像素保护/外背景/远发均保持。零与微小正负量没有出现光学跳变。另两项耳策略回归通过，共20项当前定向检查通过。真实照片和源耳边光学验证继续独立进行，尚无可用或8分结论。
