# FUNC-033 额头高度与内部发际线联动

日期：2026-10-27。默认 Rust 算法新增可见发际线的高度调整；本批独立照片审查支持保留这项改善。未构建 Web/WASM、未部署，不代表全部美颜可用或达到 8 分。

## 功能与输入

沿用 `face.adjust.adjustments.forehead`，正值提高发际线、增加额头高度，负值降低发际线。需要已有的独立头部 alpha、实际面部轮廓及其 alpha、头发类别和五官保护。使用真实可见材料，不生成被遮挡的发际线。缺少观测证据时保留原有轮廓路径。

额头宽度、太阳穴、整体脸型、身体和妆容不是本项的交付内容。

## 原因与算法

原路径把所有头发设为固定附件，再按附件距离压低皮肤的轮廓请求；发际线正处于这条边界，真实请求因而接近零。单纯解除冻结或在极窄过渡带恢复全幅位移又会产生局部纹理挤压。

新路径将观测到的发际线两侧视为同一个头部内部图像域，统一逆向重采样皮肤和相邻头发。头部外缘、背景、五官、耳饰和显式保护不参与运动。头部内部的皮肤/头发类别置信度可以不互补；不能把分类不确定性当作透明洞或固定墙。轮廓控制必须在脸部纵轴两侧找到可信皮肤与头发，且观察路径位于头部内部。

同向标量速度先由正权控制插值形成请求上界，再求八邻接最短路的最大可行包络：每条水平/竖直边的速度差不超过 0.45，每条对角边不超过 `0.45√2`。这是一项作用于速度场的约束，不是裁切输出像素。固定边界留出保护带，随后一次正权 3×3 平滑保留差分界；平滑不保证每个像素仍低于原始上界，只保留全局最大值和差分约束。

双线性速度场经同一 RK4 积分正反向输运。理想连续场的梯度界不能替代有限精度采样、实际材料边缘与照片审查；相关证据见 QA 文档。

## 组合与蒙版合同

- 额头映射单独准备，其他脸型参数使用既有路径，再组合两张映射的渲染结果。第二个滑杆跨零不会取消额头效果。组合存在两次图像重采样，不能声称无重采样损失。
- 操作透明度和最终混合只应用一次；普通混合的软选区/软保护参与速度请求，不重复混色。
- 冗余的源轮廓 `mask` 沿用旧的标准化与支持范围规则；真正的选区仍受尊重。
- 非普通混合不得给未动区域重新染色。

这只是兼容性合同；多参数强档组合的完整审美验收仍需独立覆盖。

本批组合审查仍发现 makeup 耳颊接缝的既有阶梯/色块，与旧脸宽结果一致。额头兼容改善不代表组合整张可用；该缺陷保留为后续算法阻断。

## 实现与验证入口

- `core/image-core/src/face_hairline.rs`：观测界面、固定材料域、标量场与图像重采样。
- `core/image-core/src/face_scalar_field.rs`：最大可行标量包络和独立数学回归。
- `core/image-core/src/face_hairline_regression.rs`：公共图操作入口，真实颜色界面、纹理次序、保护/隔离组件、类别不确定区、软蒙版、混合参数与透明度。
- `make quality-face-hairline`：仅额头公共入口回归；`make quality-face-field`：相关脸部算法回归。均不构建前端、Go 或服务。

最终检查：9 项额头公共入口回归通过，相关脸部算法共 70 项通过、2 项手动测试忽略，非测试 Rust library check 通过。24 组单项照片与独立审查结果逐像素一致；另有 6 组额头/脸宽组合照片。没有据此验收其他组合或前端实际运行。

## 可用范围与未完成项

六个已有数据集（其中 roll 是 makeup 的旋转派生，user 含 AI 创作标记）各 ±60、±100 的单项对照完成。新版真实移动发际线，本批没有再发现明确裂缝或折叠阻断。高强度仍受固定侧额和外边界限制：不能保证每一段都完成原始理想请求，也不能把降低局部响应包装成全幅实现。
