# FUNC-043：源背景证据的透明度边界与颜色中心分离

状态：已进入默认 native Rust 的不透明源配对路径，已完成真实照片消融；不代表瘦脸整体可用。日期：2026-10-29。

## 问题与边界

暗肤色照片强正向瘦脸后，原颈缘有一条灰色残影。其一部分来自背景颜色估计的证据混用：已有源场景模型将原图 RGB 投影到模型误差包络，得到“最接近原图、可支持保守 alpha 下界的颜色”。这不是隐藏背景 B 的点估计。旧代码又用这份投影覆盖 F/B 估计，并以 `4*((1-a)/a)^2` 的权重重用它，同时加入同源的单位权重 scene prior。低 alpha 时重复项权重很大，清晰可见的背景供体也无法纠正旧边缘颜色。

本次只修正颜色证据的角色。保留原场景模型准入、备选模型相容条件、背景投影、minimum_alpha、几何场、请求强度、材料保护和源颜色配对。没有扩大 matte，没有削弱瘦脸，也没有加入神经补全。

## 实现

- `face_scene_edge.rs`：既有 `background` 保留原数值，继续用于 alpha 下界。新增 `model_center`：最近有效平面使用其预测中心；备选模型使用所有原已准入且相容模型的逐通道中位数，再投影到共同区间。保留原相容检测允许不超过 0.5 字节的小间隙，用间隙中点避免无效 clamp。
- `model_error` 记录单模型观测残差或备选模型包络的跨度。它是经验诊断数据，**不是真实隐藏背景的误差上界，也没有被当作重建方差权重**。备选包络跨度可能超过单模型的 8 字节阈值。
- `color_prior()` 只为仍然被接受的 `background: Some` 返回中心；后续过滤拒绝的证据不能通过残留 center 重新进入重建。
- `face.rs`：只有 `stable_source_layers && joint_neck && opaque` 的源配对路径，其颜色初始化与源底板重建使用上述中心；若同一点有 scene prior，不再把由同源证据覆盖的 F/B prior 加成第二份高精度观测。原 visible-ray、邻域平滑、源混合可行区间和 `layer_pair` 保持不变。
- 手工/旧式 joint 不必具有稳定源 skin raster。它们保留旧投影与旧 precision，不能把尚未通过源配对可行投影的中心用于 F/B。既有 `reconstruct_with_scene` 入口保留旧语义；新增内部 `reconstruct_source_background` 由真实配对入口选择独立颜色模式。
- 没有新增公开操作参数或模型依赖。实验开关、照片、trace 不进入提交。

## 已知真值回归

实际调用配对路径内部 `reconstruct_source_background` 与 `layer_pair`；同时验证旧 `reconstruct_with_scene` 的非配对入口仍保留原输出。独立指定 `alpha=0.1`、`F=[250,100,80]`、`B=[200,200,200]`，对应原图 `C=[205,190,188]`。将旧保守投影 `[205,192,192]` 作为 F/B prior，真实模型中心 `[200,200,200]` 作为独立 scene prior。

- 修复前：实际重建输出 `[205,192,192]`，测试失败，最大真值误差 8。
- 去除重复权重后：输出 `[200,200,200]`；实际残差采样重新组合原图仍逐字节一致，清晰背景逐字节不变。
- 补充实际 `prepare → color_prior → reconstruct → layer_pair` 链路：已知背景 200、可见供体含零均值稀疏 ±3 噪声；混合边缘 MAE 从误用投影的 0.9167 降至模型中心的 0.1389，源 RGB 仍精确复原。
- 源模型回归覆盖：所有 24 种备选遍历顺序、0.5 字节相容间隙、最近模型被红色异常供体拒绝时的备选中心、不相容模型拒绝、后置拒绝不泄漏 center。

## 未解决

1. dark +100 `(448,570)` 的源 alpha 与新 alpha 都为 0，仍为原图 `[200,193,190]`；**旧轮廓残线仍存在，未修复**。需要区分漏掉的混合尾巴与原本背景纹理，不能通过扩 matte 抹除原景物。
2. 一些亮边像素受已有 alpha 的源颜色可行区间约束，模型中心不能直接采用。这说明透明度证据与颜色估计仍有不确定性，不能声称隐藏背景已还原。
3. makeup ±100 全图未变化，原黄色边缘与强负向颊侧形状缺陷仍在；几何自然度不属于本次修复。
4. 当前方法仍是局部模型和可见供体估计，不负责生成被遮挡的复杂纹理。未达到全功能可用验收，更不能以此宣布 8 分。
