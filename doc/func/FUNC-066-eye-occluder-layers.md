# FUNC-066 静止镜框与眼后层独立运动

状态：**隔离算法实验，未接入系统。** 合成真值回归通过；一张眼镜源图的 `eyeSize/eyeTilt/eyeSpacing 0/±30` 已完成候选回放，解决了本例“眼睛响应与镜框静止相互冲突”的几何问题。源框材料边界和真实反射尚不可靠，不能宣称自动眼镜修图已完整可用。

## 具体问题

将 glasses class6 当成不透明配饰会冻结镜片后的眼睛，三个眼控非零值全部无响应。将 frame-only mask 当成同一个变形场的零速度障碍，又会压扁临近的眼睛。直接移动含旧框的原照片再贴原框，会留下第二道框影。实片失败和公共入口证据见[眼部材料审计](../qa/eye-feature-material-audit-20261116.md)。

## 算法

源图记为 `C`，一次估计的去框脸部底图为 `S`，静止前框覆盖为 `A`。保存源残差 `R = C - (1-A) S`。原有完整眼场只作用于 `S`，输出为 `R + (1-A) warp(S)`。镜框从眼后层的几何障碍中解除，继续作为静止光学前景；头发、耳朵和眉毛的已有保护不变。

源已知像素必须保持，只有被框遮住的源位置允许生成底图。零值直接返回 `C`，避免浮点抵消或重复量化。保留带符号的源残差，不把它冒称恢复出的真实框颜色。当前照片只采用原 frame-small 默认 `p>=0.5` 二值覆盖假设，没有手工 QA 曲线、膨胀、阈值筛选或输出反推。二值分类并不等于真实光学 alpha。

## 已验证

- 六项独立行为测试：已知真值下静止半透明框与眼后层完整平移同时成立；零值原 uint8 不变；无前框时精确退化为已有 warp 输出；生成器不能改已知源像素；直接 warp 原复合图再覆框和未去框底图均明确产生双影。
- 源照片底图只推理一次，沿用已固定模型输入视口与官方默认框掩码，LaMa 不作额外膨胀/融合，源已知像素变化 0。生成内容是被遮挡脸部的一种估计，不是真值。
- 一张源图三项 `0/±30`：三个零值精确等于原图；六个非零值正常响应；前景覆盖内变化 0，输出越界通道 0。
- 镜框 QA 的 4 px 源带共 1,193 px，六个非零输出均保持；旧坏点 `(346,263)` 保持源 `57/35/42`。
- eyeSpacing 后层整眼距离比恢复约 1，左眼位移恢复 ±1.9236 px；eyeSize 恢复约 0.91393 / 1.09417，eyeTilt 恢复刚体。源左右 eye polygon 的 115/102 个像素与当前 `A=1` 重叠均为 0，没有靠把整眼遮住消除错误。

独立审查已查看源底图、三项四列对照和眼距正负/大眼正档原尺寸：本张低分辨率输入未看到新框双影、旧眼残留或明确眼角/镜框色缝，眼睛确有变化，源框保持。只接受“单图 ±30 分层概念验证”；二值框模型明显比真实细框粗，不能升级为通用眼镜可用。

另将四份无眼镜输入三项功能的 36 个既有 native 输出送入 `A=0` 退化合成，最大 RGB 差为 0。这是已有输出的光学合成回归，不冒充再次运行 native 或重新检测。
