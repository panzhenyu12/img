# FUNC-054 源场景先验与照片边缘残差

日期：2026-11-12。状态：开发中，原生算法隔离验证。关联 `face.adjust` 的脸宽/瘦脸轮廓；补充 FUNC-037、FUNC-047、FUNC-052。没有修改公开 Operation、前端或后端接口，没有构建或部署系统。

## 要解决的成片问题

原图耳缘的窄亮边在收窄后留在旧位置。仅增加抠图分辨率没有解决：相同形变下，1024源alpha回映768的候选反而把诊断像素从 `[248,237,218]` 提亮到 `[252,241,222]`，该候选不采用。

原因之一是当前颜色配对强制 `0 <= F <= 255`。给定偏低的alpha，即便独立场景颜色更合理，配对仍会把观测到的过亮/过暗边缘留入静止背景B。不能把“零值能重建源图”当作分层正确的证据。

## 实现和适用范围

新增 `core/image-core/src/face_source_plate.rs`，只由 `cfg(test)` 的原生实验调用。流程为：

1. 在未编辑源图上确定观察区域，现有LaMa以原始可见背景为上下文生成隐藏场景候选。人物、头发、耳饰等联合遮挡及3px观察边带的RGB不提供给模型。
2. 将原生有界配对作为基线，在明确源选择区内以固定源权重替换B。只允许源alpha大于 `1e-6` 且未冻结的像素。源权重距selection内缘3px达到1；不读slider、目标轮廓或编辑结果。
3. 使用现有 `sample_residual` 计算 `P=C-(1-a)B`，把选中的源照片对比度随材质运输。允许P为负或超过 `255*a`，不再用物理F区间投影把亮边重新写回B。采样与目标合成使用同一份不可变B，仅采样一次。

这是有明确区域归属的**照片编辑假设**，不是恢复真实物理前景，也不保证模型猜中了被遮挡的背景。已验证的范围是当前源耳区域的平滑背景。不同人物、复杂背景和模糊材质归属不能自动继承此结论。

`sourcePlatePrior` 只存在于原生回放的私有参数：描述源PNG、全源prior PNG和逐像素f32权重。读取时验证源图逐RGBA相同、完整画布尺寸、opaque图像、有限 `[0,1]` 权重及crop范围。公开graph/MCP不会接受文件路径。缺少模型或证据时原有手工路径不受此实验影响。

## 实测与回归

- 3项原生采样回归通过：已知锐化边缘移走后露出正确背景且零值精确；错误prior不能重分配零alpha固定场景线或显式保护；真实软透明边缘仍与已知层合成一致。
- `±60` 原生输出和独立浮点重组逐RGBA一致，最终B也逐字节一致；两方向B完全相同。更换B不改变alpha、控制目标或形变场。
- `+60` 原耳外亮脊明显减轻；例如 `(250,270)` 从 `[248,237,218]` 变为 `[235,221,204]`。`-60` 未观察到新增强亮环或裂口。两方向最终浮点输出没有颜色越界。
- `±30/±100` 真实原生回放并查看耳局部；冻结像素变化0。零值及 `±.001` 输出与源图逐RGBA一致。极值耳廓形状问题仍是几何问题，此颜色候选没有解决。
- 针对低透明度暗金属边缘另做 `scene-lower-bound` 对照：在固定先验B下，仅在已有源选择和非冻结、非零alpha内把alpha提高到每通道物理可行下界；不改B和形变。`±60` 浮点越界从23/7通道降为0/0，源身份与冻结区仍精确。该下界不是透明度真值，强档仍出现暖色低频光晕，不能单独提高可用性。
- 复用预先固定的 source unknown `3px+5px` contiguous holdout 生成更宽的 source-only B；`±30/±100` 重新合成后，用户图耳后 `+100` 暖色斑明显减弱，已知零覆盖背景四档逐 RGBA 保持。该推理已经参与候选选择，证据角色改为 context sensitivity；不能再把它当作独立 holdout 验证。
- 一次连续5px源可见背景留出：邻耳645点 MAE 2.084、RMSE 2.909、绝对通道误差P95为6。支持这个平滑场景先验，不代表隐藏背景真值。
- 独立负对照保留：如果prior错误删掉混合边缘里的真实固定细线，残差会随人物带动那条线，两方向最大误差43/129码值。即使源身份精确、颜色未越界，此错误仍存在。因此不将该策略无条件用于全图或复杂背景。

本项不提高整体评分。耳饰随动的联合几何和残影处理见后续 FUNC-055；身体、五官、皮肤等功能需要各自验收。
