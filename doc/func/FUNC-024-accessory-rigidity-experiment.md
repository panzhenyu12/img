## 功能合同

整体脸型重塑时，允许脸、耳自然联动，同时让金属耳饰保持源形状。当前仅实验“悬挂附件保持重力方向并平移”；不是所有附件的通用物理模型。

- 同一个 SVF 处理皮肤、耳垂、金属；实际可见耳垂接触区域与附件共享映射，无独立贴图、旧位置残差或固定整耳。
- 刚体支撑必须覆盖完整扫掠轨迹；只给上/下两小段，不能保证中间细杆完整。
- 源实例归属、刚体几何支撑、物理透明度分开保存。几何包络不能冒充 alpha。
- 源接触必须绑定选定头部；明确用户保护（含部分保护）优先，冲突时拒绝刚体运动。
- 未提供附件证据时保持基线行为。所有扩展目前仅实验 Rust/native 接口，WASM/UI/MCP 未新增承诺。

## 本轮结果

用户 1024×1024 源图 0 / ±30：原金属尺度约 +9.2% / −8.9% 误变形降到 1.000；脸型目标不变，实际轮廓相对基线最大变化 0.334 / 0.255 px；source F 与 alpha 不变。耳外亮边仍存在。

独立 1280×1128 长耳饰：先复现同人细杆 152px 被当外部上下文；用源图给定的实例归属修正后，原物理 alpha 大面积缺失又造成黄色断口。2×2 对照确认，独立源图 ZIM alpha 与连续刚体支撑同时存在才能恢复完整直杆。后者杆线位移一致，Jacobian 最小 0.614，但最终 1× 图像仍有明显模糊，未验收。

## 测试与尚缺证据

2 项刚体/保护反例、1 项源归属反例完成 red→green；最终 7 项 flow、8 项归属/整体脸型/保护、4 项图像与来源检查通过。两图无附件证据的 0 / ±30 回放与 V2 像素一致；所有 0 值保持 RGBA identity。

这些检查不能换算成 8 分。独立长耳饰实例和连续结构来自源图手工注释，未证明自动识别；ZIM alpha 是模型估计而非真值。尚缺多人物接触、极端遮挡、侧脸、大强度、透明图、native/WASM 一致性和实时性测试。先解决物理分层与细节模糊，再考虑产品接入。
