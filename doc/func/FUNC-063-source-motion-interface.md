# FUNC-063 同源运动界面与脸侧固定岛修复

2026-11-16。状态：隔离 native 算法修复。woman 常用及较强档已通过本次独立视觉复核；尚不能认定所有人物、脸型功能或完整产品可用。没有 Web/Go/WASM 构建、部署或接入。

## 缺陷与修复

细分割 v3 的新 hair 证据落在旧光学 faceContour 内部。旧 `promote_interface` 排除所有 polygon 内部位置，外侧邻发可动而内部窄带仍固定。固定带再通过整格网格约束锁住脸颊，形成可见轮廓台阶。woman 的两个见证控制原请求约 4.505px、实际位移为 0。

增加仅用于 native 实验的 `__sourceMotionInterface{mask,contour}`：以同一后验、同一选区生成的皮肤界面决定邻发运动许可；原 landmarks Frame、光学 faceContour/head/subject、目标位移公式不变。接口与滑杆正负无关，源准备只做一次。显式非法接口报错，不退回旧轮廓。

本项仍复用旧 hair→skin 派生编码，因此是运动准入及派生源层的联合修复，**不是材料身份、光学覆盖与运动权限已经完全解耦**。原始类别证据独立保存；准入改变后必须重新生成 source trace/cache。

实现位置：

- `core/image-core/src/face_upper_width.rs`：准入消费同版源界面，保留原光学字段及 Frame。
- `core/image-core/src/face.rs`：实验接口形状、范围、网格与等值线校验。
- `core/image-core/src/face_profile_replay.rs`：通过测试 case 的独立文件注入实验接口，继续严格校验公开 graph；baseline 不注入实验参数。
- `experiments/face-attachment-motion-20261110/prepare_motion_interface.py`：同源后验/模型/原图/选区校验、无 guard 重复准备幂等、严格保留无关字段。未通过准备返回失败。

## 已核对的证据

本地证据根目录：`test/results/face-usable-20261112/motion-interface-20261116/`。图片、后验、trace 和 native binary 不提交。

- 六项新增行为测试：旧函数 17/21 通过、四项预期失败；新函数 21/21 通过。覆盖旧轮廓内邻发、真实外发、背景孔、显式保护与非目标材质边界。
- 无接口新旧程序的源层、固定域、位移场及最终 PNG 完全相同；metadata 仅输出 image 绝对路径不同。
- woman raw 与 prepared 两次真实 native 结果的源层与位移场完全相同，重复准入没有新增修改。
- 长度错误、网格不匹配、轮廓越界三类显式接口均由实际 `face::adjust` 拒绝，不生成候选 PNG。零强度沿用已有恒等早返回，不宣称它验证了接口。

## 后续驱动与剩余阻断

另在同一 source cache 下，仅将前 128 个驱动换成同版细分皮肤轮廓。三图 `0/±30` 已完成且零档逐像素不变。woman 的原 v3 新驱动误差 1.452px 恢复至约 .00218px；user/dark 的新驱动误差仍约 1.648/1.120px。不同控制轮廓之间不能直接比较旧响应百分比。

剩余 user/dark 高误差主要出现在真实耳饰旁：本身可动的皮肤被邻近耳饰占据的整格网格锁住，局部已达到导数限制允许的位移上限，导致曲线转折。dark 上耳缘还有真实外发边界限制。不能靠提高目标权重或取消附件保护解决；下一步验证耳廓/耳饰保形共动合同，保留原始材质、显式保护和完整采样足迹。

本项不提高五官、皮肤、妆容、身体、去人等未在本轮复核功能的评分。

## 同版驱动下的耳廓保形复核

固定新 source cache 与同版驱动，只重放已有 W10 耳材料项，三图 0/±30 完成。独立实图复核确认 dark 的耳槽随宽度调整而拉宽/压窄的现象减轻；user 未新增耳坠断接，woman 的轮廓改善保留。三个零档仍逐 RGBA 等于原图。允许保留该候选材料项，但它不解决耳饰绝对固定造成的连接冲突。

扩展 glasses-street 复用了核验哈希和 crop 的既有 19 类后验，没有新模型或人工修饰。该样本仍未通过：无强耳核心的低概率耳碎片被额外冻结，造成眼镜下方皮肤不动，另有真实镜框保护。这两种原因分别处理，不能将眼镜误当悬挂耳饰。后续修复及实图结果另行记录。
