# FUNC-018 手动瑕疵修复笔刷

## 目标

用户圈选痘痘、色斑或局部瑕疵后，自动选取附近干净纹理完成修复。笔刷只负责用户选中的圆形区域；没有用户圈选时不自动扫图识别痘痘，也不修改其它功能的输出。

## 算法

`repair.heal` 在 Rust 核心中执行，浏览器 WASM 和 native/Go 渲染共用同一实现。

1. 采集笔刷边缘 1.05–1.30 倍半径的上下文环，按颜色差、局部梯度、供体内部纹理和目标距离评分附近四个半径环的候选 patch。
2. 自动供体必须满足完整 patch 的 alpha、保护 mask 和其它 heal stroke 检查；透明 RGB 不参与评分。搜索范围是笔刷附近有限窗口，避免每个笔刷在整张大图上搜索。用户显式选择 `sourceX/sourceY` 时，可读取被冻结区域的纹理；输出仍受冻结约束，透明和越界源像素仍不能复制。
3. 对目标环与供体环拟合局部低频平面，使用圆盘上的 8 阶谐波修正将目标光照/渐变传给供体纹理；保留供体高频毛孔与细碎反光。边界不满足条件时返回明确错误，不用透明黑或越界颜色假装成功。
4. 人工 `sourceX/sourceY` 仍保留；`repair.clone` 的中心复制和 alpha 行为保持兼容。结果只写 RGB，原 alpha 与透明像素字节保持不变。
5. 零透明度、空蒙版、全冻结笔刷和不相交选区，在供体搜索/光照拟合前判定为 identity；不会因为隐藏图层缺少供体而阻断后续可见编辑。实际有可写目标但无供体、或显式源的光照边界越界，继续明确报错。

Rust 单测覆盖已知侧光渐变+毛孔参考重建、自动供体纹理、透明 RGB 污染、保护供体、无供体错误、clone 透明行为和颜色快捷路径。三图的圈外像素、alpha 和透明 RGB 均为零变化。

2026-10-14 集成复核修复了显式源落在冻结区时 clone 无输出/heal 报错的回归；新增公共 graph 测试，要求冻结源可读、原冻结输出/alpha恒等。另以四种无可写目标加越界源的 graph 验证 identity，并验证后续曝光层继续执行；非空同参仍报错。Go 真实照片 HTTP 与 Playwright 的 native/WASM 对照覆盖同样合同，最终结果以 [current-validation](../qa/current-validation.md) 为准。此修复不提高小瑕疵自然度评分。

## 当前评分（2026-10-13）

手动圈选小红痘/白头：**7.8/10 暂评**。白头已去除且周围油脂高光/毛孔延续自然，少年脸小红痘基本消除。深层囊肿：**6.8/10**，中心减弱但仍有淡红晕；需要更大选区、结构化皮肤色度模型或生成式修复，不能把小范围结果外推成自动祛痘达到 8 分。自动全脸痘痘识别：未实现，不评分。

## 限制

当前 patch 修复适合小范围、局部皮肤瑕疵。大面积疤痕、重复纹理、发丝/衣服/结构物体应使用 `repair.inpaint` 或模型工作流；用户取消选区则操作为 identity。评分来自固定 1024px 输入和 native 总进程，未代表 8K、RAW、广色域或完整手势热运行性能。
