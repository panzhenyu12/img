# FUNC-021 分部位轮廓与形状保持

状态：研发中，尚未通过效果验收。2026-10-14，v19 接入后的真实网页导出已与 native、Go API 逐像素核对，但用户明确指出瘦脸不自然、人脸曲线不好看。接入结果保留在 [集成记录](../qa/face-joint-v19-integration/review.md)；下一轮候选单独保存，不覆盖原图、旧版本和失败证据。

## 需要改变的行为

形变场连续只解决像素如何运输，不能决定变形后的脸或身体是否自然。目标轮廓必须根据当前照片的部位、原始形状、关节/五官位置和真实遮挡分别生成。不得把同一个收缩函数换坐标、换幅度后当作全部部位的完整算法。

| 部位与操作 | 应保留的结构 | 需要单独验证的目标 |
| --- | --- | --- |
| 脸宽、颧侧、下颌、下巴 | 原骨相、颧颊过渡、下颌转折、下巴圆弧与左右原有差异 | 不能将上脸受限后的运动集中到嘴下，造成长直斜边或尖下巴 |
| 脸颈连接 | 可见皮肤连通、耳根附着、颈侧原曲线、衣领/首饰 | 连续运输不应自动变成瘦颈；外颈也需要目标和过渡约束 |
| 眼距、眼睛倾斜 | 整条眼缘、眼睑和虹膜的原形状 | 平移/旋转应尽量保持整体形状，不能在眼内用位置权重造成不同幅度的变形 |
| 眼宽、眼高、眼角 | 内外眼角、上下眼睑的不同作用，虹膜与眼白 | 不能把所有调整都等同于整个椭圆的缩放；缺少定位证据的结构不能靠模板臆造 |
| 眉形 | 本人的眉头、眉峰、眉尾和毛发纹理，邻近眼睑 | 保留毛流和分段曲线，不能统一拱起或牵动眼睛 |
| 鼻翼、鼻尖、嘴唇 | 鼻孔/鼻翼连接、唇峰、嘴角、内外唇线和口腔 | 分别建立局部目标，不将眼睛或整脸的轮廓模板复用于这些部位 |
| 腰、胯 | 原始腰凹与胯部外缘、躯干轴线、衣服实际轮廓 | 腰部收束和胯部宽度不应由同一个轴向鼓包函数决定 |
| 大腿、小腿、上臂 | 髋/膝/踝或肩/肘连接、各段肌腹位置、左右非对称 | 保留关节与原轮廓的粗细变化，避免把肢体修成等宽管或统一沙漏 |

## 当前诊断与候选边界

脸型 v19 的初步逐阶段检查显示，宽度请求在上脸受附件/曲线约束削弱，实际运动集中在下脸；上颈没有独立目标，只承接脸部 RBF 流场及高度衰减。需要分别核对请求目标、附件约束后的目标、QP 后目标和实际运输结果，不能凭最后一张图把全部责任归给插值器。

五官现有 `LocalWarp` 在椭圆内用同一种衰减权重乘平移、缩放或旋转。不同参数已有不同位置和幅度，但这并不等于保留了整个器官的形状。下一候选先检验眼距/倾斜的整体形状保持；不将一个候选自动扩展到鼻、唇和眉。

身体现有轴线与左右轮廓采样已经区分部位，但截面目标仍共享同类轴向衰减。下一候选从源轮廓和关节位置检查腰、大腿、小腿的差异；衣服外轮廓是实际可见证据，不冒充衣服下面的裸身体形。

三个方向分别保存于隔离实验目录。只有通过原尺寸对照和回归的改动才进入公共 Rust 核心，保持手工、WASM、native、API/MCP 使用同一操作协议。

## 验证要求

- 保留相同原图、检测、数值和不可变旧/新二进制，至少比较零值、正负中档与强档。旋转图、裁切和不同数值不增加独立原片数量。
- 同时记录请求、受约束目标与实际移动。简单降低整项强度、只展示缩略图或以像素变化数替代部位效果，不能证明修复。
- 检查部位特有的结构：脸颊/下颌切线与曲率过渡、颈宽、眼缘整体形状、关节和肌腹，而不只检查通用 Jacobian。
- 检查保护、非目标结构、背景、纹理、alpha、零值与组合跨零；所有有效分支均应有默认回归，真实照片用于补充视觉证据。
- 记录完整实际采样结果和运行开销。数值无折叠、测试通过或双端一致均不等于美观，也不构成 8 分验收。

首轮脸型 v20、五官 v5 与大腿 v1/v2 已有原尺寸对照及独立复核，均未获准替换正式算法。脸型 v20 的部分颈侧改善伴随最大实际位移从约20px降到12.64px；五官 v5 整眼刚性成功但鼻梁皮肤挤压且有硬阈值跳变；大腿虽避免部分新增凹陷，关节/衣料自然度与作用幅度仍有限。证据、失败边界和后继验证见 [分部位曲线复核](../qa/anatomical-curve-review-20261014/review.md)。

后继正在分开验证饰品前景遮挡与人体连接点、眼睑/皮肤连续延拓，以及脸颈物理边缘漏像素。尚未给未通过原尺寸评审的候选标记已部署或8分。

## 2026-10-15：源物理 alpha 漏点子项

独立复核确认：用户原图瘦脸 +100 后，旧轮廓上的 12 个肤色像素已经位于新轮廓外，本应被邻近背景替代。此前将这些像素变暗直接视为“暗洞”的判据已纠正。真正的问题是源物理 alpha 的语义零漏点被原样保留，并在运输后的新轮廓上产生暗点。

隔离候选 `face-physical-trimap-v2-20261015` 只恢复有原人物观测、连通皮肤/颈部邻接和局部 RGB 支持的物理边缘，保护类保持排除；没有更改脸型目标、滑块力度或流场。V2 清除了用户原图全部 12 个旧肤色点。三张冻结原片各比较 0/±30/±100；portrait-woman 全部与生产一致，portrait-makeup 仅在真实肤色/黄色背景混合边缘恢复低 alpha。固定类、ROI 外、输出透明度与零值回归通过。209 项 Rust 单测、10 项公共图操作契约与 clippy 通过；关闭连续性修复时，新增已知 alpha/背景真值回归会失败。

这是边缘归属的独立缺陷修复。整体瘦脸的曲线、颈宽与旧背景重建块仍需继续优化，不标记整体效果达到 8 分。精确补丁、不可变输入/二进制与原尺寸对照见 [V2 复核](../../experiments/face-physical-trimap-v2-20261015/README.md)。合入、native/WASM 及真实网页/API 验证由主线程记录，候选报告不代替部署证据。

2026-10-15 此物理 alpha 子项已合入共享核心并更新本地服务，主核心209+10测试与9档真实网页/native/Go/WASM逐像素对账通过；见 [接入记录](../qa/physical-fringe-v2-integration-20261015/review.md)。其余形状候选继续隔离，不能把本条更新理解为瘦脸已达8分。
