# FUNC-044 额头采样保护范围与观察头部域修正

日期：2026-10-29。状态：**已进入默认 native image-core，未部署 Web/WASM**。最终实现修正额头高度路径中过宽的静止采样圈，以及 landmark 横向框对同一已观察头部的错误截断。不代表额头强档、其他脸型或整体美颜达到 8 分。

主树确认：15项 `face::hairline_regression` 通过，包含旧四像素圈真实失败的新行为回归。user ±60 与 tilted ±1 的主树实际成片和已审查联合候选逐字节相同；没有重跑整体应用。日志及4图对齐输入在本机 `main-regression.log`、`main-replay.log`、`main-spec.json`。

## 问题与独立反例

原额头路径先计算到既有禁区的四邻接距离 `d`，把 `d / √2 <= 4` 的格点请求置零，再做 3×3 平滑。整数距离 0～5 都进入这条静止带；它明显宽于双线性源采样需要的范围。

tilted 的端点 77 位于 `(207.9531, 19.7308)`，最近真实头部外缘禁区格点是 `(207.5, 15.5)`，距离约 4.255 px。forehead ±1 的原请求只有 0.06559 px；该点四个插值邻格的旧距离为 `[4,5;5,6]`，其中三个请求被额外保护带置零，最后只实现 25%～26% 的幅度。`误差 < 0.1px` 会掩盖这个明显失效的相对响应。

另有独立闭式反例：半平面 `y<=0` 固定，格距 1，请求 0.05 px，源点 `y=4.25`。旧保护和平滑后的局部速度为 `v(y)=0.0125(y-4)`，实际双向响应只有约 6.2%。同一个小目标在保留必要采样保护时能完整移动 0.05 px，且所有源采样仍远离固定材质。反例没有使用照片、检测器或优化器的结果作预期答案。

## 第一版：采样保护范围候选

将保护距离改为八邻接 Chebyshev 距离；3×3 平滑之前保留两圈零请求，平滑之后仍留一圈严格零速度。任何包含禁区源格点的双线性单元，其四角速度都保持零。

原始请求、控制点、头部外缘、眉眼等语义保护、显式保护、原有选区和人物连通域不变。继续使用原 0.45 速度差约束、正权平滑、同一 RK4 输运和重采样器。没有缩小请求，没有改结果统计的分母，也没有在输出上盖回原图来隐藏位移。

上述范围关系不是任意浮点轨迹的严格证明。实际回放另外导出逆场，独立检查每个移动像素的四个源采样格点；检查最终场的两种对角线、四个有向三角形与主伸缩。

## 材料与图像验证

本批 12 个候选结果中：

- 原有禁区格点集合、控制点与请求完全一致；禁区速度、前向位移和 RGBA 修改为零。
- 头部外部、额头处理域外、显式保护、已提供的眉眼/鼻唇/耳饰保护以及求解裁剪之外，RGBA 修改均为零。
- 平滑后完整一圈采样支持严格零速度；独立逆场审查的禁区源采样贡献数均为零。
- 最终场四种三角形均为正。强档最小有向面积比约 0.608，主伸缩整体范围约 0.617～1.621；这只是本批离散采样结果。

实际查看 user/makeup 各 ±60 的源图、旧结果和候选上额图，未定位到新增裂缝或孤立贴片。改善主要位于侧额过渡，中央观感接近；不把数值响应提高写成显著审美提升。

## 剩余缺口的不同原因

三个端点的最近禁区并非同一种原因：

| 样本与端点 | 最近禁区距离 | 禁区来源 |
| --- | ---: | --- |
| tilted 77 | 4.255 px | 真实不透明头部外缘 |
| user 27 | 1.848 px | landmark 横向 frame 裁剪，**不是实际材质障碍** |
| makeup 38 | 2.809 px | 已知眉眼等语义保护 |

因此，不能把所有剩余低响应都称为“物理不可达”。第一版没有调整横向域；后续实验如下。靠近真实头缘或眉毛的强档还需明确可达性与局部应变的冲突，不能删光采样保护或提高阈值强行通过。

## 最终联合候选：让观察到的头部材质定义横向域

user 控制 27 距离真实头部外缘约 16.269 px、最近眉眼等保护约 35.952 px，却被距离仅 1.848 px 的 landmark 横向框裁断。这个框用于解剖尺度，不应替代独立头部材质的边界。

联合候选取消 `frame.left <= u <= frame.right` 这一条横向条件，保留纵向 `-0.40 <= y < 0.42`、接口距离、已观察 opaque head、region/selection、真实保护和原有连通域筛选。另一块未与所选发际连通的头部/材质岛仍不能进入运动域；没有扩展到未观察到的头部。

user 同请求消融没有重选控制点或目标：

| 观测项 | 只修采样圈 | 联合候选 |
| --- | ---: | ---: |
| 控制 27，−1 / +1 响应 | 20.75% / 20.75% | 99.92% / 99.92% |
| 控制 27，−60 / +60 响应 | 0.98% / 0.98% | 65.74% / 69.99% |

### 实际 Rust 行为回归

最终隔离候选的 `face::hairline_regression` 原 **14 项通过**，另补 1 项旧圈失败、新圈通过的采样范围回归；完整补丁共 15 项。新增的前 3 项直接走 `face.adjust` 的公共图像渲染入口：

- 解剖 landmark 框之外、同一观察头部上的可见侧额发际必须双向移动；
- 位于原框外、靠近接口的第二独立材质岛及背景间隙逐像素不变，所选发际仍移动；
- 显式 region 与 selection 之外逐像素不变，内部额头仍实际移动。

第 4 项 `sampling_guard_preserves_reachable_small_motion_next_to_fixed_material` 直接调用真实 hairline prepare/输运/渲染，使用独立的矩形头部和平直发际：中心合法请求为 ±0.08145 px，距真实禁区 4.75 px。读取实际场避免 8 位量化；旧四像素圈实际仅移动 0.01543045 px，断言真实失败，新两圈通过同一断言。该测试同时验证真实固定点及其一圈采样支持双向恒等，逐一检查实际逆场四邻源采样都属于独立已知的可动材质，并渲染验证固定像素和绿色禁区标记不外泄。断言不读取或模仿算法的距离数组。

已有回归继续核验真实头发/皮肤边界与纹理次序、眉眼/耳饰保护、有独特颜色的禁区源采样污染、类别不确定区、软蒙版、混合和组合控制。干净补丁包含 4 个新增行为回归和一个只在测试时编译的输运查询方法，不包含用于消融的实验开关或诊断文件导出。更广泛遮挡下，若输入 head 掩码错误地把两个实例连成一个实体，仍需实例分割证据；这批第二孤岛测试没有证明该情形已解决。
