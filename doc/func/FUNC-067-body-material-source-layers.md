# FUNC-067 身形驱动分区与连续衣料光学层分离

状态：**隔离算法实验，未接入系统。一张裸臂单人图、一张前袖遮挡图和一张上衣接半裙图的自动源流程与 ±30 收腰结果已获独立原尺寸初步验收；收腰泛用能力、速度及身形功能 8 分仍未验收。** 已修复衣料内部运动断点和光学 alpha 被旧算法二次覆盖问题。放大可见的细边残差保留，不继续以单点补丁作为推进方向。

## 已确认的问题与改动

`body.rs::separated_adjust` 把 `min(partMask, subjectMask)` 同时当成驱动分区和前景光学覆盖。身体解析器在一件连续衣服内部产生的腰部边界，因此会变成虚假的前景/背景边界，截断衣纹的运动。

隔离 `material.rs::adjust` 接受单独的连续材料覆盖，保留腰/躯干控制、Pose 轴、用户选区、正负强度和显式保护。只在允许的腰/躯干实验中，将这份覆盖用于光学层和外轮廓测量。不能由此推断交叠袖子与躯干属于同一运动层。

第二个问题是旧颜色线 `refine_alpha` 会再次修改已经由抠图模型给出的光学透明度。新增隔离 `sourceAlphaKind=optical` 路径保留这份覆盖；原分类置信度输入仍走旧路径。该标记目前只存在于实验 native 入口，没有宣称公共 API 已支持。

## 实际验证

| 场景 | 观察结果 | 证据边界 |
|---|---|---|
| 连续纹理布料，中间插入 9 px 语义空隙，±30 | 独立红通道坐标尺沿纵向的最大跳变由 4/5 降为 1 个色阶；非零形变保留 | 合成真值回归，证明内部语义分区不能制造运动缝 |
| 显式保护、零值、未支持部位 | 保护区及零值保持；前臂等未支持部位拒绝 | 不靠停用所有形变隐藏问题 |
| 单张自动 Pose 瑜伽照片 | 原腰部下方 y448–460 的黄色衣纹在 +30 完全不动；连续材料候选约 −1.48 至 −0.58 px 平滑衰减 | 诊断颜色/坐标只用于测量，不进入算法 |
| 光学透明度直通 | 旧路径 1,166 px 与模型 alpha 差值超过 .01，最大 .614；新路径最大差约 3.68e−5，来自 native 栅格插值 | 模型 alpha 本身并不等于真实覆盖 |
| 原生分层回放 | 同源层用于 0/±30；零值及冻结位置精确保持 | 仍有实拍青蓝衣缘，不作为整体验收 |

已有 5 项材料 native 行为回归、7 项 Python 源输入/准入回归、5 项分层采样 native 行为回归通过。未进行 Web、Go、WASM 或整体系统构建。

## 自动源证据和未通过项

源照片的可见 Pose 骨段中点、躯干/头部中心和图像四角生成 ZIM 提示，采用官方候选选择；随后只运行一次 MEMatte。不存在手工涂 mask、按输出缺陷选提示或按衣服颜色生成覆盖。四个 ZIM 输出仅作独立语义证据，不能直接当光学 alpha。

当前连续腰层实验要求单人、四段手臂的 mask 覆盖自身可见 Pose 骨段，并且手臂支持不进入腰部选区及其有界反向采样范围。这张瑜伽图通过。另四类既有源图因袖子交叠、骨段覆盖不足或缺少完整手臂证据被拒绝。该准入规则是本次实验的适用域说明，不是通用袖子处理能力。

两次自动源 LaMa 背景生成均留下人物状纹理，不采用为可信底图。为隔离问题，另复用一份历史 ObjectClear 底图：其源 RGBA 完全相同、历史移除 mask 与本次自动 mask 仅差 116 px，但历史 mask 最初来自人工提示，因此该底图只用于因果诊断，不能算自动管线已成功。

固定源底图、光学 alpha 与 ±30 几何场后，采用量化一致的有界 F/B 配对，仍有衣缘青蓝杂点。可确定原 `background-after-fill` 随滑杆改变，固定源底图是必要方向；不能据此认定当前固定底图正确。

曝光截断反例也已检查：源通道为 255 且四份 ZIM 均标为人物时，允许该源通道的编码前景值超过 255，不修改 alpha。冻结其余输入后，仅 28 个背景通道被释放，±30 分别改变 15/20 个输出像素，视觉主缺陷未改善。该编码颜色假设不是物理 HDR 重建，不继续沿此方向调阈值。

进一步沿源 alpha 的法线读取真实像素，确认左右原因不同：左暗衣缘 `C=26/52/39, a=.569974, B=49/119/153` 导致负蓝前景，外侧可见蓝值为 153/185/163/171，背景先验有局部依据，而 alpha 或混合测量模型不相容。右海浪边 `C=92/142/141, a=.027988, B=132/171/190`，外侧实际为 `75/131/132`、`95/139/152`，底图已抹平可见海浪纹理。不同 trimap 的既有 MEMatte 在左暗边仍给出 .486–.591，不能用其中一个版本宣称真值恢复。

固定同一 alpha、背景先验和 ±30 形变，取消有界投影并直接运输带符号源残差也未通过：−30 浮点 RGB 最大 273.415（20 通道越界），+30 最大 263.213（10 通道显著越界），主要在低 alpha 海浪残差。结果保存为未裁剪数组，没有把越界裁成照片。因此既不能继续调 alpha 遮盖错误，也不能直接搬运这份不一致底图产生的残差。

随后复用已有背景空间约束 QP，在完整源图的 53,064 个非零 alpha 像素上联合求解背景；使用与逐点版本相同的量化可行区间、同一先验和同一形变，可见 alpha0 背景硬保持。耗时 2.36 秒，无新模型推理。零值及冻结位置精确，双向输出无裁色；−30/+30 相对逐点版本改变 685/847 px。主要失败位置仍被原可行区间限制：左暗边蓝底图仍被压到 91.855，右海浪边结果也未改变。空间求解不能补救不相容的源覆盖与颜色模型；实拍收益尚未获得独立验收。

## 下一步与禁止误报

为去掉人工源背景的依赖，对这张既有瑜伽照片的自动 Pose→ZIM→MEMatte trimap 真正运行了一次 ObjectClear：53,002 px 源请求，原 20 步、seed42、guidance1、短边512、AGF，使用预先指定的 strict 输出。模型加载 6.58 秒、推理 229.50 秒；前期导入和权重校验另有耗时。没有复用旧人工背景改写出处。背景请求外、保护区及 alpha 变化均为 0。

新自动背景沿相同权威 alpha、连续衣料形变场、源颜色配对回放 0/±30：零值和冻结像素精确，无最终裁色。独立审查实际查看 1000 px 原尺寸全图，确认腰线轻微双向变化、衣料连续、海平线未见明显弯折，没有导致照片不可用的裂口或脏块。只接受这 1 张裸臂单人图的初步可用；模型准备耗时尚不满足快速重处理，不能称为交互实时算法。

下一步转到既有宽袖/遮腰照片的独立袖衣前层与连续衣身后层，解决目前同一光学层的适用域限制。不同姿态的五张既有源图目前因袖子交叠或 arm source evidence 不足而未通过，不能通过放宽准入或仅报告拒绝代替实现。局部源颜色可解释性诊断保留，但不升级为新 alpha 估计器；不靠抬 alpha、输出裁色或缩小强度宣布成功。

代码：`experiments/body-source-matte-20261116/`。本地源图、生成数据和二进制：`test/results/body-waist-20261116/`，均不推送。最终自动单图证据为 `automatic-objectclear-request/`、`automatic-objectclear-scene/`、`automatic-source-replay/`；历史诊断另存，不混同最终来源。

本批只修改隔离算法及记录，**生产 `body.rs` 未改，浏览器运行效果尚未变化**。

## 2026-11-17：自动袖子遮挡与独立后衬衫

已继续实现既有 `fashion-standing` 宽袖/遮腰图，未停在准入拒绝。原 Pose 的手臂骨段分数点自动提示 ZIM，官方候选选择袖子身份；MEMatte 将其转为独立前景覆盖。首次使用四候选全图未知区产生衣领/衣摆错误孤岛，保留失败后，将抠图观测域限定为已选源身份及原有 3 px 不确定带。此处没有根据输出涂 mask、人工点或新增阈值搜索。

袖子后源内容由一次既有 LaMa 补全，所有 alpha0 的已知源像素精确保留；仅以原照片仍可见的 Pose 躯干点选择补全后的连续衬衫，再进行一次 MEMatte 与固定场景补全。后衬衫和隐藏场景均为估计，不将它们当作真实服装结构。右侧垂袖的肩部身份覆盖仍不完整，位于本次有效腰部区域外，不能宣称已恢复整件袖子的真实接缝。

合成器保持前袖不动，对后衬衫独立变形，禁止把含旧袖子的原图变形后再贴一次袖子。有界源颜色配对全程浮点；首次下游严格检查因 56 个源通道的 −1.42e−14 浮点舍入失败，现仅规范化这类数学活跃零边界，最大源重建误差 2.84e−14，没有最终 RGB 裁剪。原 waist 图的选区、骨架和保护保持，未使用历史人工袖子解锁或场。

新增 3 项图层行为单测通过。原尺寸 0/±30 已生成：零值、冻结处和不透明袖子像素均精确，约 2 万个可见后衬衫像素实际移动，最大位移 7.25 px。独立审查已查看 540×768 全图和一次 2× 局部：接受这一张有前袖遮挡照片的轻度 ±30 离线结果，未确认新裂口、双袖边、旧衫鬼条或腰带断连；图右袖腰间的暗隙在原图已有，本次露出区域视觉可接受。停止此图微像素打磨，不升级为任意袖衣、交叉臂、搭腰、大强度或高分辨率的通用验收。

## 统一源角色协议与缓存重放入口

现有三条实拍路径已收束到 `experiments/body-layer-protocol-20261117/replay.py`，统一输入为 `request.schema.json` 定义的 `body-source-roles/1`。角色为 `moving-material`、`stationary-scene` 和可选 `stationary-front`；根据输入角色布局组合，不按照片名称或成片评分选算法。自动单层须有源手臂不进入腰部及逆采样支持的准入证据；自动前后层须有绑定原图 SHA 的源 Pose 身份报告和负提示一致性。也可显式声明编辑部件，但入口不凭空检测缺失角色或生成其隐藏源层。

源 alpha、源底图、原图、原图形变参数及逆场缓存均有哈希引用；配对先于读取强度专属逆场。已有单层 byte-interval 配对和前后层 exact-RGB 有界配对作为明确源测量参数保留，不是根据输出画质回退。支持 source/cache 输入，不推理、不构建、不重新拟合场，当前只提供已绑定强度的重放能力。

以相同缓存重放三图各 0/±30，共 9 个 PNG，**像素及 PNG 文件字节与独立验收结果全部完全一致**。比较在输出后独立执行，算法未读取参考成片。记录为 `test/results/body-layer-protocol-20261117/parity.json`。4 项入口行为/输入约束测试通过；没有 Web/Go/WASM 构建。

接口对每个袖身份输出 hard-FG 数量、源正提示落域异常和保护可测状态。实际上两张袖例的一侧都无一致 hard-FG，均报告 `unknown-no-opaque-source-core`；总体 opaque 像素不变只能证明该子集，不能冒充这条袖子的完整保护。当前统一入口仍依赖已有有效源角色与缓存，不是任意照片的全自动角色识别器。
