# FUNC-073：普通 Rust 构建中的源层算法入口

目标：已审查的照片结果必须能由普通 `image_core` 库直接重现，不能只存在于 `cfg(test)` 分支或复制源码的实验程序里。本项仅涉及算法库，不涉及 Web、Go、MCP 或部署。

## 入口

- `adjust_face_with_source_layers(source, params, layers)`：连续源材料运动域、正权重速度场、同源光学覆盖与冻结背景合成。
- `adjust_body_with_source_layers(source, params, layers)`：解剖部位驱动与光学材料分离，沿用 FUNC-072 的残差合成。

两个入口都使用现有操作参数校验。公共 JSON 参数不能携带 `experimental*` 或 `__*` 研究开关；文件读取、模型推理及缓存加载在调用方执行。旧 `apply_graph` 继续使用已有兼容路径，因此增加这两个接口不代表页面效果已经改变。

## 人脸合同

`FaceSourceLayers` 显式接收：准备证据时的完整 RGBA 原图、原尺寸 `[0,1]` f32 alpha、整数观察矩形、原尺寸 scene、可选源运动界面及可选附件运动许可。原图逐字节绑定、维度、透明画布、非有限 alpha、非法观察区域、错误权限格式均在零值返回前校验。

运动界面沿用已有栅格加轮廓合同，并校验轮廓与 0.5 等值线一致。附件许可只表示可以随同一运动场移动，不表示刚性保证，不改变光学 alpha，也不能覆盖用户保护、五官、衣物或独立前景发丝。额头/相邻头发的递归处理必须传递同一份源上下文。

scene 是同源背景估计，不能把它称为真实隐藏背景或已经严格配对的 B。本实现保留已审实验的顺序：源估计与初次配对 → 在观察域内采用冻结 scene → 在必要处提升与该 scene 相容的 alpha 下界 → 使用同一 scene 进行残差采样和目标合成。下界是有条件的编辑先验，不是模型测得的透明度。观察域外维持原估计；源材料保护继续生效。内存输入与其引用的 scene 不会被修改。

当前仅接受完整连接的人脸/颈部源资料，缺失时返回错误，不静默退回局部脸片算法。对称操作会先改变源图，因此不能与冻结源层同时使用；需要先完成对称处理并重新准备源层。

## 验证

`tests/source_layer_api.rs` 链接普通 rlib，检查跨源误用、非法 alpha/ROI、私有算法开关、错误运动许可、零值恒等及身体显式背景不可静默修改。

`examples/face-source-replay.rs` 只调用公开内存 API，读取已有冻结源准备结果，保留完整输入约束。照片、模型、缓存与输出均留在 Git 忽略目录。

## 普通 rlib 成片回放（2026-11-18）

`examples/face-source-replay.rs` 通过公开 `adjust_face_with_source_layers` 入口，使用冻结的 source、physical alpha、scene、观察域和已审源权限，对 4 张独立源图、20 组控件操作共 48 张既有输出完成迁移核对。输入规格为 `/tmp/face-replay-20261117/ordinary-rlib-48-photo-replay-spec.json`，输出目录及机器可复核指纹在 `/tmp/face-replay-20261117/ordinary-rlib-48-photo-replay/`。

- 48/48 档位回放成功，尺寸保持不变，无模型或检测重新运行。
- 33 张与冻结候选逐 RGBA 字节一致；15 张只有单通道 1 级差异；没有超过 1 的通道差异。
- 额头、额头宽度、太阳穴三项在 user/dark 的正负档位共 12 张全部逐像素一致，说明递归进入上脸路径时仍传递同一份源层上下文。
- 对这 15 张量化差异的代表性消融表明，旧测试入口把 full-canvas alpha 通过归一化 pixel-center 做双线性采样是已确认原因；对 woman +60 和 Lupita ±60 的单变量内存回放已将差异归零。普通 API 保留原始 f32 alpha 语义，不为字节复现而重新引入旧插值。

该回放验证的是入口迁移和冻结输入合同，不是任意输入的审美验收。普通 rlib 的单次算法耗时受当前机器负载、图片尺寸和控件路径影响；本批中位数约 9.56 秒，不能外推浏览器/WASM实时性，也不代表完整应用已达到可用或 8 分。
