## 问题与算法变更

dark 原照的脸宽 −60 在眼外侧产生严重横向拖纹。原算法将一处仅约 −2.64 px 的可行请求除以 0.0735 的支持权重，再经四次残差更新，形成约 −67.23 px 的控制速度；RBF 内部速度约 −81.8 px，邻近皮肤实际移动约 45 px。仅拓宽眼睛保护过渡没有解决过冲，已否决。

默认联合脸颈路径现采用非负紧支撑插值。对控制点的无量纲距离 `r = distance / radius`，使用 `q = (1-r)^4 (4r+1) / r²`，半径外为零；速度为 `Σ(q_i v_i) / (1 + Σq_i)`。常数 1 是零速度背景权重，使最后一个支持点消失时连续回零。唯一控制点按极限精确插值，结果位于控制值及零的凸包内。

控制值直接使用可行位移，残差直接反馈，不再除以接近零的支持权重。显式保护、附件、五官和输出权限仍生效。实际固定材质与可动前景相邻的位置，按轮廓采样的物理间距加入零速度控制，提前分配周围皮肤运动，减少颈缘/衣领处仅靠窄带乘权造成的急停。

固定边界仅与已有零控制去重；接近非零控制的边界点不能丢弃。精确坐标冲突时固定材质优先。边界采样仍是离散近似，不据此声称所有连续界面严格无应变。

这是一项确定性数值与材质约束修复，不是新训练模型或 SOTA 论文复现。凸包界不约束残差更新后的所有控制量，也不保证最终图像无折叠或自然；仍须查看实际照片、最终场和目标响应。

## 照片验收范围

最终 32 组相同源图/请求的历史 RBF 与新默认路径对照：6 个已有数据集脸宽 ±60（roll 是 makeup 的旋转派生）；其余 8 个脸型滑杆在 user 或 dark 上各 ±60；user、dark 脸宽各 ±100。最终 PNG 与此前已目视审查的候选逐 RGBA 一致，选区外变化均为 0。不是独立盲测。

dark −60 的眼侧横拖纹消失，实际轮廓移动约保留 98.5%；加入固定边界后，初版正核新增的红白领口突片与 user 下颈台阶也消失。下颌和下巴相关控制在本批图上可见真实变化。额头高度、额头宽度、太阳穴仍未证明有效，颧侧响应偏弱；这些子项继续标为未通过效果验收。
