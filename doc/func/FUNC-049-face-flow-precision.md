# FUNC-049 大图人像速度场的亚像素精度

日期：2026-11-06。状态：Rust 算法修复，未构建 Web/WASM，未部署、未推送。它修复数值误差，不代表瘦脸已可用或达到 8 分。

## 已复现问题

`face_flow::VelocityGrid` 原先每个 RK4 子步都在绝对 `f32` 图像坐标上累加。图像坐标越大，可表示的最小间隔越大；总运动可表示，但分成 16–128 步后，每步可能被舍入成零。远处不经过的速度尖峰提高全局积分步数，也会错误改变本地响应。

- 坐标约 4020，恒定请求 0.001 px：旧实现最终没有移动。
- 坐标约 2020，恒定请求 0.005 px，远处梯度触发 128 步：旧实现最终没有移动。
- 坐标约 8020，恒定请求 0.1 px，128 步：旧实现移动 0.125 px。
- 同一个非恒定旋转场，只平移网格原点，旧逆位移从 `(-0.02695465, 0.030038834)` 变为 `(-0.0234375, 0.03125)`。

这些反例直接调用真实 Rust 核心；修复前新增的 3 项测试均失败。

## 实现

网格仍存 `f32`，不扩大图像或场的存储。轨迹状态改成局部 `f64` 坐标与累计位移，每个 RK4 阶段也在局部坐标进行双线性采样。正向绝对坐标只在返回时转为 `f32`；逆采样直接返回累计位移，避免两个已舍入绝对坐标相减再次损失精度。

速度、控制点、曲线请求、保护区和积分步数规则不变。源前景/背景分层也未因此改变。共同使用该积分器的人脸、内部发际线和上脸宽度路径都会得到此修复；五官的另一套积分器和身体算法不在本次范围。

## 验证

新增 3 项真实核心回归通过，覆盖大坐标小运动、远处梯度不影响本地恒定运动、非恒定场平移不变性及直接逆位移。连同已有解析仿射解、双向固定点和曲线测试，共 8 项通过。另有 3 项脸颈纹理/保护、15 项内部发际线/上脸宽度、1 项零值与全保护检查通过，共 27 项定向测试。

独立审查使用实际积分器验证硬零点、零边框、网格外、趋零速度边界，以及旋转逆解；未发现新增数值错误。

实拍使用当前源码重新编译并冻结基线，只有 `face_flow.rs` 的积分修改参与对比。缓存 woman（512×768）与 makeup（768×677）各做 `-60/-30/+30/+60`：八组成功渲染，相对当前基线每图只有 4–8 个像素变化，最大 RGBA 差 1，alpha 无变化。强档脸颈对照未见新增明显接缝，但宏观瘦脸效果仍弱，没有因此提高审美评分。

本机证据目录 `/tmp/face-flow-precision-20261106/` 保存基线/候选源码与二进制哈希、输入图/graph 哈希、原尺寸输出、对照裁切和 `pixel-comparison.json`。照片、graph、二进制和 trace 不提交。这个目录是本地复查证据，不是可在其他机器直接执行的数据集。
