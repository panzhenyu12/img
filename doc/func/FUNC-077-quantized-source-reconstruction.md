# FUNC-077：分层形变的显式字节量化重建合同

状态：2026-11-19 普通 Rust 实现、21项定向回归与独立代码复核通过；yoga 冻结源的普通入口回放完成，±30 经独立审图为该既有样片有限可用。仅涉及算法库和离线照片回放，不涉及系统接入，不构成身形通用验收。

## 问题

照片中的整数 RGB 是存储后的观测值，不能要求所有合法的浮点颜色分解在取整之前也精确等于它。既有 yoga 源层的连续重建与整数观测最多差约 0.5，但取整后每字节相同。把整数观测强行代回前景残差，会造成 950 像素、2,192 通道的负值或超过覆盖上界；这不是应该通过增大浮点误差容限解决的问题。

## 两种明确的合同

保留 `BodyLayeredSource` 数据结构及原有入口的 Exact 默认行为。新增 `SourceReconstruction::{Exact, NearestByte}`，调用者通过独立的 `*_with_reconstruction` 接口声明约定。

设前层覆盖及颜色为 `a_f, F_f`，后层的连续源颜色为 `S_r`，后层覆盖为 `a_r`，固定场景为 `B`，原图的整数观测为 `C`：

```text
S = a_f * F_f + (1 - a_f) * S_r
P_r = S_r - (1 - a_r) * B
0 <= P_r <= 255 * a_r

Exact:       S = C（仅允许既有 IEEE 运算误差）
NearestByte: floor(S + 0.5) = C
```

NearestByte 校验完整的前后层重合结果；不能在有前层时只检查 `S_r`。它规定半开量化区间：内部字节允许 `C−0.5`，拒绝 `C+0.5`，同时颜色始终受 `[0,255]` 域约束。它不是任意的 `abs(S−C)<=0.5` 容差，也不解释 JPEG 压缩、线性光照或错误材质归属。

残差始终从实际连续后层 `S_r` 求得。原观测差 `e=C−S` 只用于核对输入，不当作前景纹理运输，也不加回目标图。固定的 alpha、背景和前景颜色均不因此合同修改。

## 渲染与拒绝条件

沿原运动场双线性采样有界的预乘前景 `P_r` 和覆盖 `a_r`，与目的位置固定场景、静止前层合成，再按同一个量化规则输出字节。全零运动、未移动像素和不透明前层保持原图字节；即使请求为零也要完成输入校验。

错误源图、越界/非有限数组、坏背景导致的无界前景、非法尺寸继续拒绝。前景残差的误差界只涵盖既有浮点运算误差，不能扩到半个 RGB 色阶。输入格式兼容不证明源层的语义或补全质量。

旧源层仅为局部裁剪时，还必须验证每个受影响目的位置与逆场双线性采样邻点都落在已准备的范围内；不能在未知区域填一份恒等层，再把跨出裁剪范围的运动当作有效照片验证。

## 回归与实拍

新增6项公共行为回归，连同既有测试共21项通过（14项 compositor、7项普通 adjust）；两个公共入口均先在旧 Exact 委托中复现拒绝，再通过显式新约定。覆盖量化上下边界、混合前层、零值下的非法配对、alpha=0 的小数背景不搬运取整误差、双向非零运动及旧 Exact 合同保持。独立 reviewer 核对了完整调用链，没有重复运行测试。

`body-layered-replay --source-reconstruction nearest-byte` 显式调用新入口，默认仍为 exact。新增 `--field-only --graph … --save-field …` 在任何源层读取前输出普通几何场，用于检查旧裁剪范围是否够用。缺少保存路径、同时提供 field/graph、将渲染参数与 field-only 混用，以及错误操作/schema 均在写场前拒绝。仅构建了这个算法回放 example。

旧原型中对背景投影、提高 alpha 的探索分支未引入核心，新合同只消费已经冻结且有界的源层。

## yoga 固定源回放

`experiments/body-internal-aperture-20261117/yoga_visible_rear_holdout.py` 固定源图、图谱以及旧裁剪 P/alpha/B 的 SHA256，直接重建 `S_r=P+(1−alpha)B`，没有重新估计或改变它们。原先命名为 `target-alpha.f32` 的缓存，经生产代码与正负档对照确认是形变前的源覆盖；真正形变后覆盖另存 `warped-alpha`。这里仍只是旧 part/subject 经保留处理得到的覆盖估计，不冒称新的物理 matting 输出。

原几何与冻结 V2 几何各执行 0/±30，共6场。每场先通过普通 field-only 取得完整运动场，核对运动目的点与四个双线性邻点全部落入已准备的202×176源裁剪范围，之后才建立全幅内存数组。裁剪之外的恒等占位层没有被任何非零运动读取。6项不依赖照片的支持范围反例另在 `test_yoga_holdout_support.py` 通过。

两项零值逐RGBA恒等，所有场的静止位置及裁剪之外改动为0，P/alpha/B哈希在回放后保持。V2补充188个原几何像素；固定源亮度/色彩测量线上的衣腰宽约77.09px，−30为82.41px、+30为71.13px，中央行与原几何幅度一致。

独立审查全幅、左右整段躯干、衣褶、黄色侧线和腰臀接界，接受该既有瑜伽姿态 ±30 的轻度收放腰有限可用；未见新增硬裂缝、双轮廓或海平线弯折。源边本来偏软，这不是陌生照片的自动源准备验收，也不扩展到其他身体部位或8分。普通API耗时约0.35–0.38秒，不含旧模型源准备，不等同于60fps。
