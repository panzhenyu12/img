# 用户图连续下颌目标：独立成片与曲线复核

日期：2026-10-22。结论：**连续采样修复了右下颌长边内部响应不足和左右响应不一致；满档目标的局部凹感、颈部外缘被牵引仍未解决。此项不构成审美8分或整体瘦脸通过。**

## 原来的长边内部缺陷

原63点中的33→34边为 **49.6821px**，端点分别为`[556.5,584.8462]`与`[594.5,552.8413]`，跨越右下颌连续请求的强作用区。旧版只约束已有源行，两端gain为约0.793和0.565，内部峰值没有对应控制点；左侧却有gain约0.999的源行。这是控制采样密度不同，不能当成左右脸本身的差异。

旧+100在源位置`[576.1152,568.3256]`请求内收8.90383px，实际只有5.73617px；已有源行误差却仅约0.01037px。新增连续检查揭示的是过去没有测到的边内部缺陷，不是放宽阈值。

连续版+100两侧峰值的源位置变为左`[436.0370,567.3855]`、右`[579.9203,565.1209]`；旧右侧峰在`[591.8882,555.0410]`，作用过于靠上且偏弱。成片也呈现右下颌收窄／外扩位置更接近左侧的改善。这里只说编辑响应更一致，不要求原本不完全对称的人脸变成镜像。

本次弧上检查间距约0.072px，比runner的约0.5px检查更密，所以最大误差稍大；两者仍都低于既定0.25px阈值。更密的测量没有替代目视。

## beta目标本身的局部凹感仍在

为区分已有检测毛刺和新增弯曲，在同一原折线与其实际映射上，使用源弧长±8px的弦估计切线，再比较中心相隔约16px的切线转角。符号统一为原下颌凸向为正。它是有限尺度的几何描述，不是皮肤真实微分曲率或审美评分；没有平滑、重排原源点。

- 旧+100左侧在源`[443.8830,573.6570]`，对应原弧凸向转角为 **+3.685°**，实际变成 **−3.548°**。该处原弧并非反向毛刺，新增局部反向转弯有独立证据。
- 连续+100左侧在源`[436.0370,567.3855]`，对应原弧为 **+1.961°**，实际变成 **−4.898°**。两个位置分别是各版本转角损失较大处，不是同点前后差值。连续采样没有消除这一凹感，而是更忠实执行原beta目标。
- 理想连续beta目标在左侧同样会把原凸向变成局部反向。`64[t(1−t)]³`是单峰局部意图，端点C2并不保证中段轮廓仍凸或好看。
- 右侧原边长近50px且是折线直段，不能把在这段代理直线上算出的新负曲率直接称为真实皮肤新增凹槽。它可以证明目标公式会弯曲该代理边，真实轮廓仍需结合成片判断。
- −100左侧嘴下附近，原弧已经有反向转角；外扩会加重它，但不能把它全部记作算法新产生的毛刺。原本的缺陷、增强的缺陷与新产生的反向弯曲分别保留。

目视上，连续+100的下颌两侧更一致，但嘴以下到下巴的收窄仍集中；下巴中部保留较宽的圆弧，附近转折显得更刻意。−100两侧外扩更均衡，但满档的饱满度也不自动等于美观。当前显示尺度没有看到新增裂口或拼接缝；这不消除曲线与比例问题。

## 颈部与功能边界

两版+100的颈外缘都受到带动，尤其源图约`x405/615、y545–605`附近；连续采样使目标执行更完整，却没有提供独立颈部形状约束。因此，颈部被收紧的观感不能仅归因于beta下颌目标，也不能用固定上脸、耳饰不动来抵消。下一步固定已审查的颈外缘，保持下颌目标与其他参数相同，是有价值的隔离实验；该实验尚不属于本记录的通过结论。

这仍是嘴平面以下的局部下颌功能。上脸、颧颊宽度和整体脸部比例没有按整体瘦脸意图联动。后续需先比较颈部隔离结果，再决定是否需要更宽缓的下脸收缩目标；不能把准确执行局部beta请求当成完整脸型美化已经完成。
