# 新原图自动收腰：遮挡衣物身份失败

2026-11-19。**当前自动收腰在 fullbody-side-fashion 的 ±30 未达到可用**。右侧垂挂外套的部分区域被当作躯干运动，上端与固定衣物之间出现新增突出黑角或内凹。前景粉色袖子也进入腰部运动域。已发现源材料归属错误，不能通过继续调腰部曲线掩盖。

## 本次输入与普通入口

- 原图：`test/images/fullbody-side-fashion.jpg`，1280×853，SHA-256 `1082f17c1c0b572b604f80d403858128bfd4687548568de911cbf9c4932af999`。画面是含腰、裙装及膝部的三分之二身，脚不在画面，不能称为完整腿部验收。

- 检测耗时 15.12 秒，其中模型加载 2.76 秒、解析推理 10.60 秒；本次实际为单线程 ORT Wasm。检测返回腰部可用，右大腿、小腿不可独立重塑并拒绝，不以补造骨点开放它们。
- 同次解码的 `source.png` SHA-256 为 `f53c0889dc4e7e5ebe39192ad99a48375b6bbd26c2626750a1fb5e1f99a92ca2`。后续 native 使用这个 PNG，避免把浏览器与 Rust 的 JPEG 解码差异计作算法效果。
- 当前 source graph SHA-256 为 `9bcd97980c6bfd5d7ca28f40aed08bebb193e38709268e1743cf860f40411799`；只把 `adjustments.waist` 分别设为 `0/-30/+30`，保留同一原图、观测、选区、part mask、保护及强度。

初次已有二进制输出只记为 probe。随后定向 `cargo build --release --bin image-render` 用时 5.31 秒，再对同一冻结源/graph 输出 `current-native/`。三个当前结果与 probe **逐 RGBA 相同**；构建日志、二进制哈希及 body 相关源码哈希都保存在 `binary-and-parity.json`。没有 Web/Go/WASM 构建，没有重跑检测。

## 实际成片与源输入诊断

零值与源图逐 RGBA 一致。−30/+30 分别改变 10,946/10,480 个像素；48,382 个原保护像素均未改变，画布 alpha 保持。这只能验证已给保护的执行，**不能证明保护和运动材料分类正确**。

直接看原图及源 mask，腰部 `partMask` 错收了前景弯曲粉袖下半和画面右侧垂挂外套（约 x680–727、y350–500）。保护包含手、包和卷衣摆，未把这些外套和袖子独立隔离。Pose 的躯干轴落在前景袖子上，基于隐藏躯干骨轴播种的二维区域生长会把可见遮挡物分给躯干；同为 `top` 的两件衣服也没有独立实例身份。不能将语义类别或骨点位置当作层次关系真值。

原尺寸腰部三档及右外套 3× 最近邻裁图显示：−30 外套上端附近出现横向突出黑角，+30 同处反向内凹；部分内部纹理也改变。实际右外套诊断 ROI `[642,315,733,505]` 中，两档变化 1,386/1,305 像素，最大 RGB 差 113/122。这是帮助定位的混合矩形，不能当成精确材料真值。粉袖诊断 ROI 同样发生明显像素变化。两个诊断 ROI 在成片后依据原图材料选择，不冒充预注册验收窗口。

独立 reviewer 逐张查看原图、两向全幅、原尺寸腰部三联及 3× 局部，确认牛仔裙腰有可见响应，但外套上端新增台阶/凸黑角，不满足独立腰编辑，**两向拒绝**。其预先选定的外套下方内部 ROI `[691,387,705,445]` 两档均不变，故不能泛称整件外套都被拉动；粉袖内部 ROI `[601,350,629,374]` 两档变化 183/185 像素，手/包核心保持。源角色错误与衔接缺陷相符，但尚未完成源角色单变量修正对照，不称唯一或完整根因已实验证实。

这轮没有修改形变公式，也没有给该样本加放宽保护、调骨点、降强度或删除困难区域的特判。下一步应建立可见材料身份和遮挡关系，区分“躯干衣物、前景袖子、垂挂外套、手、包”；缺少依据的隐藏腰线保持未知。人工分类校正可作为单独的可复现输入，但不能计作自动解析成功。

## 人工源角色因果对照（同日，自动路径仍失败）

在上述失败已被观察后，另建 `manual-role-control-v3/`。这是公开的人工源图输入，不是自动结果，也没有声称恢复本次未保存的类别后验。`source-materials.json` 把同一件毛衣的弯袖和躯干分成不同运动片区；袖、手及包放在固定前层，躯干衣物与牛仔裙放在运动后层，两片可见外套保持同一 `coat-1` 实例并作为固定场景。右侧袖/手遮外套的 T 结点按源观察记录；左侧牛仔裙与外套暗缝的局部先后、完整隐藏层次只记为本对照假设。没有把外套身份直接转换成新的几何硬保护。

人工提案经两名 reviewer 看原图复核，在新推理前补上手腕/袖口窄连接带。仅左侧牛仔裙可见侧缘有独立测量弧；右腰被袖、手和外套遮挡，不补造右侧腰线或声称双侧轮廓通过。前层多边形采用 4 px 光学不确定带；后层粗多边形在 y430/450/470 比原图颜色过渡边偏 3–5 px，原 4 px 带会把部分暗缝硬设为前景。此问题在**首次后层推理前**被源图审查发现，单独 `rear-trimap-source-review.json` 公开将后层不确定带扩大到 8 px，保留原合同及多边形，实际 trimap 与修订 SHA 被协议冻结。三处实际可见过渡都位于未知带内。这不把颜色过渡等同于物理 alpha 真值。

固定源准备依次运行一次前层 MEMatte、一次前层 LaMa underlay、一次后层 MEMatte、一次场景 LaMa，再复用既有 `prepare_layers` 对接五个 f64 源数组。隐藏 RGB、完整后层支持及光学 alpha 全部是估计；后层 MEMatte 仍会把左侧部分暗带归入后层，必须由实际成片检验，不能以源重合成成立替代自然度。前后层 source、trimap、身份、underlay、scene、模型及阶段输入的 SHA 闭合。

普通 `body-layered-replay` 经公共 `adjust_body_with_layered_source` 回放原 graph `0/±30`。**保留原解剖轴、region、partMask、subjectMask、protectMask、强度与场公式，没有用后层光学 alpha 替换几何身份。** 源配对最大浮点误差 `2.84e-14`；零值与源图逐 RGBA 相同。−30/+30 分别改变 8,105/7,787 个像素，最大场位移 6.839/6.852 px；两档不透明前层、原保护域、零位移点均为 0 个变化像素，画布 alpha 不变。这些是约束检查，成片观感另审。

当前人工对照全幅及固定裁图位于 `manual-role-control-v3/ordinary/`。源和输出已冻结；不得据成片再调源 alpha 或隐藏内容以追求过关。原自动失败结果继续保留，人工源修正不计入自动泛化。

独立 reviewer 对上述**同一人工样本 `0/±30` 给出有限接受**：原自动失败的右外套诊断矩形 `[642,315,733,505]` 从 −30/+30 的 1,386/1,305 个变化像素降为两向 0；前袖内部从 183/185 降为 0，手包保持。原尺寸全幅、腰部及 3× 局部未见新硬裂缝、外套折角或袖移动，左侧原有暗缝未呈现明确新增黑假边。原图本来存在的细黑边仍在，不把它误记为新伪影，也不继续按结果修改 alpha。

预先在原图冻结的 RGB 侧缘截面 y430/450/470 给出左轮廓水平位移：−30 为 `−4.065/−3.911/−2.284 px`，+30 为 `+3.989/+3.911/+2.100 px`，零值均为 0。y450/470 的响应与自动失败对照相同，未通过削弱腰部变化来稳定外套；y430 的自动 +30 存在多交点而人工结果为唯一交点。该颜色过渡测量只作可见衣边响应佐证，不是物理 alpha/骨骼/右侧隐藏腰宽的真值。明细在 `ordinary/visible-edge-*.json`。

因此本实验支持“保持几何不变、修正源材料归属与层组合能消除这张图的已知外套/袖误动，同时保留可见裙腰响应”。它没有证明原始错误 partMask 已修好，也没有把身份层、完整遮挡序与隐藏纹理自动恢复。**自动身形路线仍未通过这张原图；有限通过属于人工源分层输入，不是整体身形可用或 8 分评分。** 当前结果冻结，下一项应是新独立照片和自动材料关系入口的验证，不在这张图继续微调。
