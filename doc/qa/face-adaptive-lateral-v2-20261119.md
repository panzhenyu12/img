# Adaptive lateral contour v2（2026-11-19）

本轮实现了脸型目标候选 `adaptive-lateral-v2`。它在输入有足够轮廓和五官证据时进入受保护的默认路径；证据不足会回退旧路径，没有改变 Web/WASM 公共协议。

候选的目标曲线仍按眼睛、鼻子、嘴唇和下颌的特征高度分区，但做了三项改变：

1. 每个横截面从源轮廓估计局部半宽，位移基准为 `2 × local_half_width`，并限制在源脸宽的 `0.55..1.10` 范围；窄下颌不会继续使用脸颊的固定像素位移。
2. 位移沿源轮廓外法线运输，并在下巴接近竖直的切线处平滑衰减，宽度滑杆不会直接缩短下巴长度。
3. 多滑杆合成使用 `tanh` 平滑饱和替代硬 `clamp`，避免强档附近的一阶导数跳变。
4. 输出目标检查相邻边方向、最小边长和面积方向；强档发生折返时逐级回退到最近的安全目标。

## 验证

新增 5 项几何回归：零值恒等、正负对称、局部半宽/下巴长度约束、强档保持轮廓 winding、折返目标安全回退；另有饱和曲线连续性测试。运行：

```bash
cargo test --manifest-path core/image-core/Cargo.toml --lib face_profile::tests -- --nocapture
```

结果：12 项通过。
