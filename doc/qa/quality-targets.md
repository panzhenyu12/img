# 逐功能 8 分验收目标

日期：2026-10-13。目标是每一个修图功能至少 8/10；不能以平均分、像素发生变化、单测通过或某一张照片表现好替代验收。

## 评分与必须满足的条件

每个功能分别评价实际效果（35%）、自然度及原有细节（35%）、作用部位及邻近区域保护（20%）、运行效率（10%）。每项维度至少 7 分、总分至少 8 分，才可以记为达到目标。模型检测和编辑分别计时；初始化、首次运行、热运行分别报告。分数是照片评审结论，不是自动指标换算的客观事实。

下列条件不满足时，无论分数多少都不通过：

- 参数零值、禁用图层和空蒙版严格保持原图；方向、强度递进和撤销正确。
- 瘦脸、腰、腿、胳膊等改变真实轮廓，固定背景、头发、饰物、邻近肢体不得跟随整片拉伸。收缩露出的背景或身体底层只能在实际露出的窄带补全。
- 五官调整定位到相应结构；妆容跟随形状且保护眼球、牙齿及暗口腔。
- 磨皮保留正常明暗、毛孔及肤色层次，不能用全脸模糊冒充精修；衣物不能用平滑冒充大褶皱重建。
- 去人结果不能残留人形、重复纹理、明显边缘接缝；选区外、保护区和 alpha 保持原样。
- 传统功能的 native/WASM 输出一致。模型路径使用相同 Rust 蒙版和合成，不因模型或 Agent 不可用而阻塞其他功能。
- 失败、拒绝和无可测效果必须保留；不修改检测阈值来让报告变绿。

## 样片和效率验收

一项人像功能至少覆盖正常正面、倾斜、侧面、深肤色/暗光、头发或眼镜遮挡及复杂背景。身形覆盖裸露与有衣物、手贴腰、弯曲肢体、斜姿、裙装和肢体交叉。去人覆盖小杂物、单人、多人、结构线及复杂纹理。每个失败姿态都单独标记，不推断成已覆盖。

保留原图、结果、差分、100% 局部裁切、参数和模型/引擎版本。正常强度与极值分别评价；不拿微弱变化换取“没有伪影”。轮廓测量以已知映射及图像实际边缘为主，重跑检测只能作为辅助。

1024px 图像上，简单调色/滤镜目标热运行不超过 200ms，局部传统重塑目标不超过 1s；更大图像另报分辨率、总耗时及峰值内存。大型补全模型走明确的异步计算，Demo CPU 目标 10s 内；达不到就记效率未达标，不能称实时。性能目标用于后续优化，不代表当前全部满足。
