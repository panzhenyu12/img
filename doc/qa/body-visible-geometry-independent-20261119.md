# 可见衣边与计算支撑独立复核（2026-11-19）

最新结论：PCHIP v2 在既有 `fashion-standing` 样本的 ±30 收放腰可判 **有限可用**；±60 效果更强，独立审查未见新增结构破损。该结论仅覆盖本样本、冻结源层及这些档位，不等于身形全场景可用或达到 8 分。+100 的既有拒绝没有在本轮解决。

## 为什么拒绝 v1

v1 只修复可见行的原 part 几何，遮挡行保留旧偏内轮廓，把左袖下平台搬到了更高的位置。测得可见衣边本身没有错，错误是把两套不连续的几何直接拼接。因此没有继续扫描羽化宽度。

## v2 的概念约束

源可见衣边作为观测证据；前袖和保护处仍记 unknown。计算支撑另用现成 `scipy.interpolate.PchipInterpolator` 续接，可见测点原位，未知端使用原 part 的明确先验锚点；先验不标为可见真值，不读取隐藏 rear 内容，不允许无界外推。修改范围仍是源 part 几何，光学层、原选区与保护不变。

PCHIP 区间保形不等于最终轮廓处处光滑：与旧 part 取并及 subject/protect 裁剪仍可能生成接点，必须看实际场和成片。缺少手臂归属线索时，同色连通袖子仍不可仅靠 rear alpha 与连通性区分为躯干。

## 独立成片审查

使用 `test/results/body-visible-rear-geometry-20261119/pchip-v2/` 的 0、±30、±60 普通 API 成片；检查原尺寸全幅、整段左右腰侧、袖下交界、衣褶和下摆，另作 2–3 倍裁图定位。没有仅用原折角附近的数值窗口作为接受依据。

- +30、-30 的腰身变化清楚，原左袖下平台消失，没有在袖口上方、下摆或另一侧发现搬移出的新尖角。
- +60、-60 形变更强，轮廓仍连续；未见新的黑白裂缝、衣褶断接或悬浮碎条。
- -60 的右腰靠近前袖，冻结测量窗内缺少独立 crossing，不能补算一个宽度来宣称测量通过。
- 报告中 y470 原衣腰宽 175.99px，+30 为 163.99px，-30 为 188.23px。前袖不透明像素和远背景保持逐 RGBA 一致。

独立图在 `/tmp/face-independent-20261119/body-pchip-v2/`，包括 `whole.png`、`waist.png`、`left.png`、`right.png`。未构建系统、未运行模型或修改核心。

## 代码准入边界

审核发现：若未知域端没有 coarse 先验锚点，初版代码仍可创建局部 PCHIP domain，再与剩余旧几何拼接。这违反“端部支撑不足就保留该侧原几何”的协议，存在重现 v1 台阶的风险。修复后明确记录 `insufficient-endpoint-support`，保留缺端侧原几何，另一侧仍可独立修正；双方都缺端则候选逐值不变。独立测试 agent 报告最终 8 项测试通过，包含端部缺边、缺种子以及原 `128.4` 数值保持的负例；本 reviewer 再次只读核对了守卫分支和相应断言，没有重复运行测试。当前实拍两侧 domain 都是 `[0,1]`、锚点齐全，因此没有重复渲染已审核的五张成片。

后续准入保留两类最小负例：不均匀观测点不能让计算曲线过冲；改变完全遮挡的 rear 内容而源 RGB 不变时，观测与计算支撑都应不变。保护袖接触躯干仍必须保持 unknown，另一侧可见漏边必须能修复，避免“全部不操作”通过安全测试。

## 固定 yoga holdout 的状态

下一张 yoga 未进入本轮成片评估：既有源层只满足 8bit 舍入后重构一致，连续值误差最大约 .5；严格源层接口检查发现 950 像素、2,192 通道的精确 residual 越界。哈希、alpha 转换及源 RGBA 均已核对，记录在 `test/results/body-visible-rear-geometry-20261119/body-yoga/source-contract.json`。没有改 alpha/B、放宽合同或生成新成片。这是源层数值合同不兼容，**既不是 v2 几何失败，也不是第二张阳性通过**；不能用旧 yoga 成片替代本轮固定协议验收。

## 既有 fullbody-skirt 的功能证据

独立检查 `test/results/body-visible-rear-geometry-20261119/fullbody-skirt/` 的全幅及腰部原图/±30 对照：轻度收放腰可见，裙腰与裙褶连续，没有观察到袖后白裂、孤立色块或背景直线变化。该既有样本的轻度收腰可判有限可用；两侧腰缘部分贴着前袖，对隐藏衣边的正确性仍只有有限证据。

候选没有新增几何像素，结果与原 graph 相同，因而这是 **v2 不新增纠边的负控**。但非零收腰实际分别改变 4,947/4,859 像素，并非功能不生效。它可补充既有 body 调整功能的可用样本，**不能算作 v2 新增纠错阳性，也不是未知图片 holdout**（源报告 `newHoldout=false`）。

## yoga 合同阻断后的固定回放与独立验收

上述 yoga 阻断历史保留。后续以显式 `SourceReconstruction::NearestByte` 接口解决了数值合同不兼容：冻结的浮点源合成 `S` 必须满足 `floor(S+0.5)=C`，旧 `Exact` 默认接口仍保持原有要求。没有改 alpha、背景或冻结颜色，没有把 `C-S` 当成材料搬运或回加；材料本身仍须满足原有有界颜色条件。该变化是源观察合同补充，不是画质改善算法。

独立只读复核了核心、普通 body API、CLI 及定向测试：新模式完整传递到合成器，舍入检查作用于前景与下层的完整合成，半开区间不加宽；零场与不透明前景保持原字节。实现 agent 报告 21 项 body 分层定向测试通过；本 reviewer 没有重复执行测试或构建系统。

最终成片位于 `test/results/body-visible-rear-geometry-20261119/body-yoga-quantized/`。固定原图/原 graph 与 v2 均执行 0、±30，共六次普通 API 回放。先独立计算完整画布运动场，所有非零目的位置及四个双线性采样邻点都在已有源层裁剪内，才使用裁剪外 identity 占位层；没有使用裁剪边界 clamp，也没有让运动读取未知占位内容。零请求、静止场像素与裁剪外像素均无变化，源层哈希保持不变。

独立检查了 `full-+30.png`、`full--30.png`、两张腰部三列对照，并另作左右整条躯干 4 倍对照（`/tmp/face-independent-20261119/yoga/left-torso.png`、`right-torso.png`）。本既有 yoga 样片的轻度 ±30 收放腰可判 **有限可用**：腰形实际双向改变，黄色侧线、衣褶及腰臀衔接连续，未见新增硬裂缝、双轮廓或海平线弯折。没有仅以像素有变化或合同通过替代视觉判断。

v2 新增 188 个几何支撑像素；左侧有 29 个可见测点并以原 part 端点先验续接，右侧 97 点均为可见测量。candidate 相对原几何的成片差异在 y440–469 下腰区域，+30/-30 分别影响 1,043/1,032 像素，整段审查未发现缺口迁到胸部或髋部。这个局部改动并不构成全面重塑能力提升。

此样片在此前实验中已使用，本轮是冻结旧源层的新接口回放与 v2 追加检查，**不是未见图片的泛化验收**。其源 alpha 仍来自既有 part/subject coverage 估计，源边缘本来偏软；数值可行性不证明材料分解是真值。最新结论扩展为：fashion-standing、fullbody-skirt、body-yoga 的已检查轻度腰部调整各有有限可用证据，仍不能宣称整个身形算法或全功能达到 8 分。
