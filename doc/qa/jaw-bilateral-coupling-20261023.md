# 双侧同高度收缩：实现与四组成片对照

日期：2026-10-23。结论：双侧平均运动差异下降，但两张照片的正负满档目视变化都很小，尚无明确自然度提升证据，不能据此上调美学评分。新项保持可选，默认权重为0。

## 实现

`jaw_bilateral.py` 在原始左右弧的共同源高度上构造软耦合。令原始半径为左侧 −a、右侧 b，运动为 uL、uR，目标项为：

`λ ∫ [2(b uL + a uR)/(a+b)]² dh`。

这是半径加权的相对收缩差，不强制源脸左右镜像，也不要求绝对位移峰同高。Hessian 为正权外积之和。每个高度先统计全部原始边交点，再要求两侧各有唯一正向交点、半径位于正确侧；多交点与回折段不参与耦合。共同高度只是几何对应，不是解剖对应。

保留原连续 beta 请求的总有向面积、原始轮廓、端点、编辑方向和源凸窗口连续约束。有理权重积分按源边、控制节点、半径零点分段，8→16阶起逐次检查Hessian收敛；不称为多项式精确积分。CLI增加 `--bilateral-weight` 并保存helper源码快照。

## 固定对照

在成片前固定权重为 **1**，user平滑长度12px、man为4px，连续目标间距2px、场stride1。没有混入界面fairing；man保留既有共享高清保护。探测输入、同一照片和原始固定像素均核对一致。

此前λ100的目标探针虽然显著减少RMS，却把user左峰下移约18.18px；没有因此选用λ100。参数选择和美学判断不能由单个指标决定。

## 不能省略的退化

- user −100：实际右侧已知凸窗口由0增加到1个负分子样本，最小转角约−0.003862°。原严格分子容差确实失败，没有改阈值。
- user +100：左侧8个微小反向窗口仍在，最小角约−0.01750°→−0.01628°。
- man +100：实际左侧反向窗口46→43，右侧225→369；最小角分别−0.09015°→−0.09537°、−0.08758°→−0.09231°。目标连续约束通过，不能冒充最终像素场也严格通过。
- 比例最大差对接近中线的小半径很敏感。补查合法源段的单侧端点极限后，user +100最大差约0.03289460→0.03289343，基本不变；−100则0.01203080→0.01495161，反而增大。只看内部两档网格会误报max改善。没有外推未知尾段。

## 实际看图与下一步

主代理与独立视觉代理实际查看完整脸及2–3倍下颌裁剪。相对原图，正向收窄和负向加宽清楚可见；相对旧QP，两侧协调项的外观收益很小。user和man正向仍表现为下巴两翼收窄、偏V形，负向宽圆观感基本不变。所查尺度未见明确新增黑缝、局部折角、眼镜扭曲或笑容异常。

user原图有“AI创作”标识；man下缘检测经过胡须纹理，不是已知物理alpha边界。两张照片不足以证明泛化或8分水准。

下一项单独验证**同总面积下更宽的收缩偏好分布**，观察是否减少中段过度集中的V化，同时检查嘴高起点与未知尾。它是可证伪的目标形状实验，不预设更宽就更美，也不继续只加大双侧权重。
