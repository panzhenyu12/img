# 下颌修改与可见颈侧界面的联动诊断

日期：2026-10-22。结论：**无颈侧项时，连续场把下颌运动扩散到可见颈侧；硬固定或当前零位移软项减少颈侧移动，却把回位集中到上端，产生新的短段折转。应联合控制整条可见外界面的位移分布与沿弧变化，不能只在y565开始要求回零。**

## 原图证据与未知角色

源仍为1024×1024用户图，带“AI创作”标识。已在源图实际目视确认两段y565–610颈侧/黑背景界面，并记录左右各10点。随后单独查看左右原图6倍裁剪，确认y515–610外侧前景/黑背景界面连续可见，无头发、耳坠遮挡，提取每行一个对比边位置，共左右各96点。

**界面可见与解剖归属分开。** y530–555的脸/颈角色仍未知；可见对比边不是下颌骨、精确alpha或3D曲面。原图y530–540本来已有斜向转到近竖直的轮廓变化，不能把整条外界面强制为凸下颌弧。原jaw63、语义mask及旧冻结证据均未改。旧颈侧每侧10点在新测量中精确重现。

主要源证据为本地忽略目录 `user-jaw-source-v1/visible-interface-review-v1/source-interface.json` 及 `visual-source-review.json`。2px检查边带共830像素，仅是评审者选择的图像边界余量，不是统计置信区间或硬冻结区域；所有记录保留自动可见性未知和自动编辑未授权。

## 测量方法

直接求逆各候选最终保存的f32逆场，得到同一组源点的实际输出位置；通过局部逆场Jacobian的逆计算沿源折线切向的位移梯度。源折线保持原样，测量的是图像对比界面，不称为解剖学曲率。左右宽度使用同源y材料点变形后的横轴距离，不是严格同输出y轮廓宽度。

`user-neck-flow-diagnosis-v1/report.json` 保存原y565–610段的逐点位移、切向梯度、到下颌目标的距离；`interface-report.json` 保存新y515–610连续可见界面的测量。前者另列的25px数学切向外推仅用于场诊断，不是新增保护证据；后者已经用实际目视确认的对比边替代外推进行分析。两个报告均绑定输入哈希。

在原已审查y565–610段，+100左/右切向位移梯度峰从QP4的0.101/0.086px/px增至soft的0.252/0.153px/px。中下段接近零，并没有自动得到自然的上端连接。

新完整外界面进一步定位到：soft +100左侧源y564附近梯度约−0.268px/px；同目标连续beta加硬固定的左侧源y559附近约−0.365px/px。按前后各8源图行弦计算转角，在y540–575窗口内，左侧相对原图的最大转角变化量为QP4 +6.48°、soft +10.93°、旧硬边−16.12°。QP12约+4.56°。这是指定尺度的图像界面诊断，不是微分曲率保证或审美阈值，但与实际看到的浅肩/台阶位置相符。

上端连接空间较短：源y565左点距最近密采样下颌源点约17.65px，右约23.82px；对应QP4下颌请求横向位移约+6.91/−7.07px。无颈侧项时，颈点分别同向移动约+4.94/−3.65px，场不需要在这段距离里立即回零。soft把它们压到+1.32/−0.83px，两点间位移差/源距离的诊断值左从0.111升至0.317、右从0.143升至0.261。硬零约束会进一步集中差异。最近距离使用≤0.5px间隔下颌探针，属于采样近似。

因此不能把问题归因于“颈侧源边界找错”或仅靠固定像素数量解决。当前权重在端点做平滑渐入，也不保证求解后的位移导数平滑：位置惩罚、近处活动下颌和保护域共同决定实际回位长度。

## 建议的下一项独立候选

保持已有下颌等面积profile、请求强度、原保护区域和最终几何门禁，利用新确认的整条外界面建立独立线积分项，而非在565单点开始把位移压到零：

`E_interface = λp ∫ w(s) |u(s)|² ds + λ1 ∫ |du/ds|² ds + λ2 ∫ |d²u/ds²|² ds`。

其中s沿原图可见外界面的弧长，u是同一形变场在该源界面的位移。第一项的位置偏好随到活动下颌源目标的距离逐渐加强，近下颌只作为弱偏好；后两项控制运动分配和回位的局部变化。它约束位移的变化，不把原图外界面改成一条全局凸曲线，也不标注未知脸/颈角色。所有项必须进入同一次求解，不能事后乘mask修场。

这是待验证候选，不是已经实现或保证成功。首先冻结一组尺度与权重，在同档±100对照中同时检查实际下颌面积/连续目标响应、可见外界面移动、沿弧梯度及照片转折。允许上端保留少量连续联动是明确的候选取舍；若更远处的位移降低仍伴随浅肩，就应拒绝，不能继续以固定成功或更小位移替代审美判断。
