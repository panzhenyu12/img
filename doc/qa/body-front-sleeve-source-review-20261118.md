# 交叉宽袖：源分层与收腰动作验证

范围为既有 `tilted-shirt` 512×768 原图，源 SHA `c10d5c84643c857d1476d2954b026bb09eb6020122e94c90502c8c5ed78a2575`。本轮仍是算法隔离验证，未接入系统，**尚未完成全档可用验收**。

## 身份准备的失败和改进

完整人物单层已经消除旧白衣断层，但 +60 收腰带动前袖，因此动作范围不通过。原自动 Pose 袖流程的后臂 14/16 可见度仅 .4247/.4596；前臂腕15虽然 .918，落在宽袖中段 `(219,462)`，手指17/19/21也落在衣料内。不能把这些“手点”作负袖提示。

原图复核确认可见落肩缝约 `(252,319)→(350,342)`，可以定义独立前袖。五个正点、胸前衣片/衣结/上肩等九个负点固定后，ZIM 官方 argmax 仍将胸衣、衣结、上肩纳入，负提示 alpha 分别 .9886/.9876/.9948，一致 hard-FG 为 0。结果拒绝。

同组提示用已有 SAM2Matting Tiny checkpoint 的 SAM2 **分割头**一次对照，官方 argmax2 满足所有提示，但独立源图检查仍发现肩部和门襟大片误纳。提示点合规不等于部件身份正确；未将该输出送进后续模型，未修改神经掩码假装成功，也未继续换分割模型。

转为明确手工源多边形，沿落肩缝、内袖折边及袖口描绘，保留既有 3 px 未知带。独立源审核接受该输入的大方向。该路径是用户手工指定编辑部件的能力，不计为全自动识别成功。轮廓先冻结，再运行一次 MEMatte：318 tensor 严格载入无缺失，源图/trimap未改。手工身份不是精确光学真值。

## 源隐藏内容和固定场回放

前袖 alpha>0 的 32,343 px 一次 LaMa source-only 补全，不扩大mask、不缩放、无seam blend；mask外源RGB精确保持。补全后的后层以原whole-person提示中仍可见的点估计，删除被袖遮住的两个正点，不从生成纹理增加新提示。后层身份为SAM2官方argmax，接一次MEMatte；隐藏衣身仍是估计。

复用 FUNC-067 的浮点 source F/lower 配对和独立图层合成：原图含旧袖的像素不作为可动后层，前袖保持，后衣残差在固定场景上搬运，再合成前袖。场景先验取此前同源0档配对B，在源准备中为后层可行性重新投影一次，之后冻结；这不是悄悄修改调用者的固定已配对B合同。

`0/±30/±60` 全部使用 FUNC-072 已有逆位移场，f32字段未改。±60最大位移仍19.11 px；0逐RGB字节保持；27,598个alpha1前袖像素全部精确保持；约1万个可见后衣像素确实改变。源重构误差最大2.84e−14，无输出裁色。此轮仍为Python研究合成器，不能写成普通Rust入口已经实现独立前袖。

独立原尺寸检查认可前袖主轮廓、袖口针织纹及肘部衣纹保持；左后衣腰有双向响应，旧衣料断层未重现，衣裙接缝未见新增裂口。但−30/−60在袖口上外缘 `(86..96,469..479)` 露出新棕色楔块，整批暂不接受。

## 已证实的剩余原因

−30 的 `(89,474)` 原RGB `[217,213,198]`，变为 `[134,102,70]`。目标前袖alpha=0，反采样位置 `(94.022846,474.179966)` 的四个采样点全部位于源前袖隐藏区，其中主样本 `(94,474)` 的LaMa underlay为 `[137,104,72]`、原图为 `[236,229,211]`。这份棕色假纹理被真实搬到可见区域；不是前袖移动或把手工alpha硬截断造成。

保留前袖、后层alpha和几何场，已仅替换隐藏RGB先验作因果对照：同一个冻结source mask执行已有ObjectClear固定20步/seed42/guidance1/AGF严格输出。推理207.72秒，请求外、保护区、alpha变化均为0。−30的同一 `(89,474)` 变为 `[218,210,198]`，棕楔明显消除；0、冻结像素和不透明前袖仍精确保持，同场的19.11 px强档未降幅。此对照证明隐藏颜色先验对该缺陷有直接作用，未因一处楔块回调手工轮廓或降低强度。

但ObjectClear的完整underlay又补出较窄的袖子/手，不是真实隐藏躯干；固定旧rear alpha的结果只能作为因果对照，不能把生成后的另一条袖子叫作正确后衣。现有通用去物模型不自动满足同件衣服的amodal部件补全要求。

独立复核实际查看±30/±60原尺寸及袖口一次3×对照，确认深棕楔块消失、前袖主轮廓和衣纹保持；未见新增大裂口、双袖边或明显生成脏块。仍有极小淡黄边点，接近原图浅边，未再构成显眼棕块。只接受“前袖固定与棕楔局部改善”，不继续围绕此点微像素调参。

还需纠正动作语义：原图左侧 `x90..130/y340..440` 的外缘大部分为后垂袖。该区域变化不能当“真实腰线响应”证据。当前可确定的是前侧横袖固定和可见后材料独立运动；完整收腰需要进一步区分后垂袖与躯干/裙子，两侧真正腰线在此源图部分被遮挡。不得用袖形变化替代腰形验收。
