# 妆容材质 v1 复核

日期：2026-10-14。当前生产候选只改眉色和唇色的局部调色边界，先在 3 张独立人像（`portrait-makeup`、`portrait-woman`、`portrait-hair`）的原尺寸缓存上回放眉色/唇色 `-100/-60/0/+60/+100`，共 30 项。

候选二进制 SHA、图像 SHA、参数和保护统计见 [report.json](report.json)。30 项全部完成；零值 6 项逐像素不变，选区外和 alpha 保护均为 0。候选唇色对 `teeth` polygon 使用硬排除，避免羽化牙齿边缘被唇色染红；原 baseline 在 `portrait-hair` 有内嘴变化，候选为 0。

唇色在固定原图亮度附近改变色度，保留唇部明暗起伏和高光；高亮近中性色像素降低染色强度。眉色用有效皮肤低频估计区分眉毛深色发丝和眉间皮肤，减少矩形/多边形把皮肤一起压暗。两者仍是确定性颜色场，不是口红材质、反射或眉毛生成模型。

原尺寸裁切见本目录各 PNG。三张图中唇色/眉色尚未达到商业修图的自然材质表现，暂评约 **7.2/10**，不记为 8 分。native 总进程包含 PNG I/O、进程启动和首次初始化；首例有冷启动离群，不能当作浏览器端实时性能验收。

新增两个 Rust 回归：眉毛发丝与眉间皮肤分离、牙齿 polygon 逐像素保持。自动腮红、眼影、修容、真实口红材质、眉毛毛发生成和侧脸遮挡仍未实现。
