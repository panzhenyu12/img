# 胶片响应 v1 真实样片复核

日期：2026-10-14。四张独立人像（浅肤、深肤、长发、自然光）与城市彩色夜景、黑白街景，共 42 个原片/预设回放。最长边 1024px，强度 100，额外颗粒/辉光/暗角为零。每次调用前后核对同一 executable SHA256，源文件与输出 hash、first/hot core 时间见 [report.json](report.json)。评分只对应这些样片，不外推相机标定。

新增 `provia`、`astia`、`velvia`、`classicNegative`、`eterna`、`acros` 六种手调风格。它们借用富士风格名称作为审美方向，**没有测量富士相机响应，不能称为官方复刻或校准 profile**。旧 warm/cool/classic 等预设保留兼容。

## 实现与实拍

新配置先把 sRGB 解码到线性光，用 18% 灰固定点的 odds-power 单调曲线控制反差，增加温和黑位和高光肩部。色度随新亮度缩放，阴影/高光色调做零亮度校正，越界色度统一压缩，减少逐通道截断造成的偏色。sRGB 编解码和曲线使用软件 `libm` 生成的查表，热像素循环不做 `powf`。Acros 色度为零，使用同一亮度响应。逐级灰阶的严格单调性与 alpha/强度合同均有 Rust 单测。

- Provia/Astia：人像肤色和颈部明暗保持，Astia 深肤暗部较柔和；细节没有被空间平滑。
- Velvia：黄色背景、红色夹克更鲜艳，深肤反差更强，适合风景而非所有人像。深色头发层次仍在。
- Classic Negative/Eterna：压低色度和高光，城市灯线、窗格保持，Eterna 黑位更软；与真实负片染料响应仍有差距。
- Acros：灰阶连续，四张人像和建筑细节保留；尚无彩色滤光片、真实银盐颗粒大小等完整模拟。

## 效率和限制

并行 Rust 编译/其他算法回放期间 native 热运行 median 为 142–909ms（neutral 39–150ms），时延波动明显。这个证据保留真实耗时，不能据最快一项宣称全部满足 200ms；需在构建/推理结束后复核空闲机器和浏览器热运行。计时含 graph 解析、验证、算子与合成，不含文件编解码，也不含浏览器/WASM 初始化。

当前仍是 8bit sRGB 输入/输出；没有 RAW、16bit、ICC、广色域或胶片扫描标定。42 次包含原片与同源派生结果，**只有六张独立源照片**，黑白街景不能验证彩色风格的色彩准确性。
