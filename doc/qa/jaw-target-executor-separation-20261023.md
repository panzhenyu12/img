# 下颌目标与执行器分离对照

范围：用户原图 +100 的离线算法实验，不构建或修改 Web/Go，不调整现有滑杆强度。照片、数组及模型不提交。

## 原因

连续曲率方差减轻局部尖峰后，整脸仍没有明确改善。原未求解 Plateau 请求也不是可直接采用的自然脸型：它在原已知凸窗口存在反向转弯。与此同时，联合场的左 12–28px 收缩仅达到该请求约 31%，运动被转移到更下方。因此需要区分目标本身、起始限制和空间场耦合的影响。

不能把“整体脸宽”直接替换成“局部下颌”：同下颌面积的仿射宽度收缩需要嘴高起点约 ±6.5px 位移，违反局部下颌原有的零位移边界；全脸面积也不同。

## 源脸型弯曲参考：未见有效收益

`source_affine_bending_reference.py` 只把原 D2 平滑项改为相对于源脸型的仿射收缩参考。仿射系数由原连续下颌面积计算，约 5.81254%；参考自身的非零端点不夹成零。实际目标仍保留原零端点、Plateau 位置偏好、符号、面积和保弯约束。Hessian 不变，仅添加 `−H_bend * reference` 线性项，传给 `P=2H` 求解器时系数为两倍。没有新增权重。

`probe_source_affine_bending.py` 的唯一小规模目标实验用时 1.509s，原 1D 保弯门槛通过。左 s18.75／r2 目标转角从 0.551° 变为 0.515°，s20.875／r6 从 1.145° 变为 1.106°；原图叠线几乎无法区分，未形成有意义的形状改善。

更重要的是，原 1D 基准和新候选都不满足后来联合场使用的六个起始能量预算。新候选不能直接作为联合场的合格输入；没有进行整张照片求解或接入。5 项数学回归验证系数、非零参考端点、物理尺度和两侧共用面积系数；测试通过不改变失败结论。

本地证据：`test/results/semantic-deformation-20261022/jaw-source-affine-bending-v1/`。

## 将相同起始预算单独加入目标控制器

`jaw_prefix_budget_1d.py` 对原分段线性位移精确计算三段前缀的一阶导数平方积分。原节点跨越窗口终点时只缩短积分长度，斜率仍除以完整原节点间距；外尺度始终为 12px。固定端点和原总面积先消元，白化只改变数值坐标。

原 1D 保弯目标加入与联合场一致的左右 2／6／12px 六个独立预算后，首次物理检查均通过，但求解器为 `AlmostSolved`，状态保留为拒绝，未导出合格 profile。该试步的左 12–28px 收缩／原 Plateau 约 75.65%，明显高于联合场的 31%；右约 56.22%，接近联合场的 59.55%。这支持“左侧还有空间场耦合因素”的判断，也说明不能将两侧全部问题归为同一个原因。

首次试步不构成实际照片改善。后续同题数值修正和成片结论需单独记录，不能把 1D 目标约束通过当成最终像素曲线或美观验收。

## 同题数值检查与诊断导出

仅将六个完整 SOC 各除以其原 `sqrt(cap)`，不改目标或可行域；两次试验共约 3.455s，仍为 `AlmostSolved`。原坐标复核面积误差约 2.27e−13px²，硬零和符号误差为零；连续保弯余量和六个实际能量余量均为正。没有继续抛光或升级求解状态。

`export_diagnostic_prefix_profile.py` 只为离线成片比较导出失败优化器的有限候选。`accepted_target_constraints=false`、`executable=false`、`image_approval=false` 原样保留。原节点和值逐 bit 保留；加入原轮廓节点后的分段线性插值，精确有理数误差界小于 4.22e−16px，导出后的面积、保弯和六个预算独立重算均通过。这些证据只允许进行诊断，不批准优化收敛或图像质量。

## 相同执行器的实际成片

沿用原 portable 执行器、2px collocation、stride 1、固定支持域、目标权重 4、弯曲权重 .05 和膜权重 .001。没有界面运动目标、软颈部目标或额外保护区域。既有冻结 Rust 程序没有重新编译。

一次离线成片约 4.35s，原轮廓最大目标误差 0.020634px，活动点最小响应 0.99547；152006 个保护像素零变化。最终 f32 场对称特征值范围约 [0.83223, 1.23760]，最大剪切 0.11991，无折叠或原几何界限超限。成片仍为目标优化拒绝状态下的诊断图，执行通过不覆盖目标或审美状态。

对保存的 f32 场直接反解相同原点，未使用旧结果曲线插值：

| 原位置／半径 | joint v13 实际转角 | 分层候选实际转角 |
|---|---:|---:|
| 左 s18.75／r2 | +1.577° | +0.340° |
| 左 s20.875／r6 | +6.944° | +0.216° |

左 12–28px 实际收缩／原 Plateau 从 v13 的 39.76% 变为 75.62%；右从 63.11% 变为 56.22%。之前更复杂的方差联合候选左侧仅约 31%，这里明确区分两个比较基线。

但源目标预算没有自动传给实际输出。六个前缀的实际能量／原 cap，左为 3.086／1.168／0.717，右为 3.363／1.180／0.620：左右前两档均失败。首 2px 的增量主要已由 portable 源拟合引入；右 6px 又被最终逆场重建增加约 4.78%。这是两档积分步长的数值检查，不是连续域证书。目标位置误差小仍不能代替导数检查。

独立查看整脸、两侧连接、颈部及下巴后，候选与旧 retained 基线较接近，没有明确的整脸自然度提升；左上颈肩角仍在，右侧略圆但转折仍突兀，未见新增黑缝或双轮廓。因此继续拒绝美观验收，不评 8 分。

本地证据：`jaw-original-prefix-caps-portable-photo-v1-plus100/`、`jaw-layered-actual-f32-audit-v1/`。照片、字段数组和结果报告均留在忽略目录。

## 下一项针对真实肩折的实验

沿原图可见外缘直接反解，左源 y545／r12 转角 −11.37°→−20.18°，y550／r12 −1.79°→−9.78°，存在真实新增弯曲；原图 y535 已有较强转折，不能把原有脸颈分叉误当算法裂缝。当前 portable 没有读取外缘硬符号约束，不能将这次肩折归因于未启用的旧联合约束。

下一项只验证界面运动分配：保留当前下颌 profile 和固定域，复用小型界面曲线求解器，移除颈部回零偏好，沿原整条外缘平滑运动。源曲线位置不改，不把细微转向符号当精确解剖先验。目标检查与执行成片分别记录；肩折不减、向下转移或原下颌响应失败均不采用。

### 外缘仅平滑运动的结果：拒绝，未执行整图

`boundary_curve_qp.py` 新增显式 `transport_only_motion_fairing`，仅此模式要求 `neck_weight=0`，旧模式仍要求正权重。目标为 `∫(u−preferred)² ds + 16⁴∫u''² ds`；沿用节点间距 8px、y515–535 上段保持、末端 8px 保持、原有位移及梯度范围，源位置完全不改。`export_boundary_curve.py` 保留输入下颌 profile 的诊断和失败状态。

## 执行损失的独立小模块

`low_rank_energy_projection.py` 实现约束空间中的最小原能量修正：最小化 `(z−z0)ᵀH(z−z0)`，满足既有能量球与 `E(z−z0)=0`。它保留的是输入场的线性测量，不冒称重新满足原请求面积。只读维度检查表明，六个起始条件共 156 行，实际仅触及 42 个自由节点，未来可避免再次求解整张图的巨大联合锥问题。

当前模块仅完成四个解析测试，没有用于真实图像。独立审查发现缩放很小的等价约束可能被绝对特征值截断删除，已先复现失败，再在 Gram 构造前规范化整球及等式行，删除绝对尺度地板；实际原算子/原 cap 仍独立复核。数值截秩仍是该实验的局限，后续可用节点选择器的正定 Schur 矩阵避免此假设。此模块没有与上节肩折实验混用。

`make quality-jaw-target` 共 18 项聚焦检查通过，包含目标参考、精确前缀积分、源图角色绑定和上述投影；没有运行整个项目构建。
