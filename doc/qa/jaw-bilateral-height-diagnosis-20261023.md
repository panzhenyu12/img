# 下颌目标四分弧与双侧收缩层位诊断

日期：2026-10-23。只读分析既有 user QP12、man QP4 的 ±100 输出；没有修改轮廓、目标控制器、保护区或算法代码。

## 结论

**撤回“下巴末端 25% 运动过强，应压低尾段”的初步建议。** 标回原图后，该段已是下巴底部小圆帽；实际只占每侧正向面积变化的约 0.9%–3.0%。主要运动在弧中间 50%，直接再压末段缺乏证据。

更具体的可疑点是 user 正向目标的左右主收缩层位错开：冻结请求中两侧峰的源坐标纵向层差约 **21.70 px**，实际场为 **21.22 px**。差异已经存在于目标控制器输出，不能归咎于像素场执行。它是否导致“不自然”仍须同强度外观对照，不能仅凭左右不同判定错误。

## 数据与方法

本地忽略目录：`test/results/semantic-deformation-20261022/jaw-arc-quarter-motion-20261023-v1/`。

- `report.json`：四个候选各双侧的四分弧位移、面积份额、峰位置和输入哈希。
- `requested-peak-comparison.json`：冻结目标与实际场的峰位置归因比较。
- `user-QP12+100-source-markers-detail2x.png`、`man-QP4+100-source-markers-detail2x.png`：已实际打开的源图标点。红/绿/蓝分别为 t=.25/.50/.75，黄为嘴高边界与下巴代理端点。
- `analyze.py` 和每侧 `.npz`：可复核脚本、源点和实际目的点。图片、数组均不提交。

t 是既有源折线从嘴高边界到下巴代理端点的归一化弧长，并非纵向高度或新解剖标注。采样包含原折线顶点和四分点，最大间隔 .25 源像素。实际位置通过反解已保存的 f32 逆场获取。

位移均值按源弧长加权。面积份额是每段源弧与实际弧之间的带状有符号面积，包含端点连接边，按原轮廓方向统一符号；不是每段真实解剖面积，也不包括弧外小位移。份额在单侧归一化。

## 正向 +100 四分段结果

各列依次为 t=0–.25、.25–.50、.50–.75、.75–1。

| 候选/侧 | 四段平均实际位移（px） | 四段面积份额 |
|---|---|---|
| user QP12 左 | 2.51 / 7.08 / 5.40 / **0.93** | 20.62% / 47.26% / 29.50% / **2.61%** |
| user QP12 右 | 2.42 / 5.83 / 6.01 / **1.25** | 18.87% / 41.48% / 36.71% / **2.95%** |
| man QP4 左 | 1.50 / 6.31 / 4.85 / **0.46** | 12.80% / 51.66% / 33.03% / **2.51%** |
| man QP4 右 | 1.65 / 5.98 / 4.96 / **0.37** | 14.85% / 49.54% / 34.72% / **0.89%** |

负向末段面积份额同样很低：user 左/右约 1.99%/1.66%，man 2.51%/0.90%。所以没有证据支持将尾段作为主要整改对象。

源图标点显示，中间两段覆盖下颌侧翼至下巴两翼，末段为底部圆帽。此前目视的“更呈 V 形”与中段收缩有关的假设仍可验证，但尚未证明是唯一原因。

## 双侧峰的源层位

纵向层位使用既有脸部坐标系的 `down` 方向，避免把图像轻微转头/倾斜简单当成高度差。下表层差为右减左。

| 候选 | 实际左峰 t / 位移 | 实际右峰 t / 位移 | 请求峰层差 | 实际峰层差 |
|---|---|---|---:|---:|
| user +100 | .381 / 7.42 px | .617 / 6.79 px | **+21.70 px** | **+21.22 px** |
| user −100 | .449 / 7.98 px | .444 / 8.03 px | +0.04 px | −1.13 px |
| man +100 | .433 / 7.60 px | .421 / 6.78 px | +3.68 px | +3.36 px |
| man −100 | .454 / 7.61 px | .439 / 7.54 px | +3.68 px | +3.17 px |

峰附近可能平坦，微小执行误差会移动离散最大点，因此不放大解释约一像素的差异；user 正向约 21 像素的层位差同时出现在请求与实际场，值得直接做目标对照。

## 下一项可证伪对照

保留原图的左右宽度差、总面积变化、端点和执行门禁，单独比较“双侧沿同一源纵向层位协同分配收缩”与现有各弧独立目标。验证重点是 user 正向的主收缩是否回到相近层位、下颌两翼是否更协调，同时检查 man 不被强行对称化。不预设左右源轮廓应该镜像，不改变已冻结的解剖角色未知状态，也不把峰层差变小直接算作审美通过。
