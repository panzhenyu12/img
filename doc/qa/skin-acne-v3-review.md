# 真实痤疮样片：局部色素候选 v3

日期：2026-10-13。此轮在多尺度皮肤处理之后增加了局部相对红色色度场：以皮肤选区内的局部 35 分位色度作为参考，只修正超过阈值的红色色差，并保留当前亮度和高频明暗纹理。它是传统颜色统计，不是痘痘医学分类器，也不重建凹陷疤痕。

验证使用三张 Wikimedia Commons 原图，原图和许可证元数据归档在 `test/images/acne/`，每张图固定手工皮肤 polygon，不调用人脸检测。每张图以 natural、strong 和 texture 三组相同参数分别运行 v2 与 v3；二进制、输入、graph 和 alpha/选区外变化均有 SHA 与像素合同检查。候选二进制 `.run/skin-chroma-v3-image-render` SHA256 为 `8aacc21470c2262fb9dfbe1f716bd1f30197fcfcc19c1cb8e569df8cd00751db`，报告见 [skin-acne-v3.json](skin-acne-v3.json)。

## 观察

- 青少年面颊的两处红色丘疹在 v3 仍可见，但相对红色色差比 v2 进一步下降；纹理档没有抹掉周围皮肤纹理。
- 油性额头的大片红色区域在 strong 档下降，白头基本保持，说明颜色统计不能替代局部修复或内容重建。
- 囊肿性痤疮的选中面颊在三档只有小幅改善；选区外的下颊控制点三档均保持不变。
- 与 v2 的 48 项既有肖像回放中，v3 只在皮肤选区的稀疏色素点产生变化，平均 RGB 差异很小；深肤色、牙齿、眼睛、头发和选区外像素未出现合同性变化。100% 裁切仍需人工判断，像素统计不等于美感分数。

## 验收结论

v3 可以作为当前传统皮肤算法的增量候选，解决 v2 对宽泛红斑过于保守的问题，但真实痤疮、白头和囊肿仍未达到逐功能 8 分。暂评：效果 7.5、自然度/细节 7.5、区域保护 8.0、效率 5.0，综合约 7.3；本轮 48 项既有肖像 native 总进程时间为 311.78–2949.68ms，包含启动、解码、graph、编辑和编码，不能称实时。后续需要专门的瑕疵检测和 patch/exemplar 修复，并继续保护痣、雀斑、腮红等正常红色色素。
