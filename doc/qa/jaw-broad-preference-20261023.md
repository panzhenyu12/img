# 同面积、宽分布下颌偏好对照

2026-10-23。四组成片均已生成并实际看图。运动确实分布得更宽，user图的实际已知窗口反转清零，但**尚无明确的照片自然度提升证据**。保留为独立目标实验，不替换默认控制器。

## 单变量目标

基线为[双侧λ1](jaw-bilateral-coupling-20261023.md)。保持源轮廓、λ1、user平滑12px/man4px、固定区、网格、所有硬约束和原连续beta³总面积；只改优化器的偏好形状：

`f(t)=smoothstep5(clamp(t/.30)) × smoothstep5(clamp((1−t)/.30))`。

中段平台为[.3,.7]，同一个正比例因子使两侧连续偏好的有向总面积等于旧beta³请求。该因子不是逐侧镜像。C²仅描述标量包络；原始半径和执行profile仍为分段线性，不能声称完整曲线C²。

实现为隔离的 `probe_jaw_plateau.py`。原面积来自独立原Problem实例，不能随覆盖后的偏好一起变化。连续面积按原边和包络分段精确积分，四个目标独立闭合polygon验证最大误差2.27e−13px²。未改现有core/export入口。

## 实际场结果

| 案例 | 旧→新反向窗口采样数（左/右） | 旧→新双侧峰高差 | 实际 / 原请求面积 |
|---|---|---:|---:|
| user +100 | 8/0 → 0/0 | 18.201 → 1.125px | 99.966183% |
| user −100 | 0/1 → 0/0 | 1.147 → 1.326px | 99.970110% |
| man +100 | 43/369 → **42/109** | 1.459 → .437px | 99.963894% |
| man −100 | 0/0 → 0/0 | 2.085 → 1.719px | 99.963360% |

反转使用既有源凸窗口及原严格分子容差。man正向仍失败，不因反转数量减少就认证通过。四组原执行、最终几何和固定成片像素检查均通过，固定像素变化0。

`audit_jaw_motion_distribution.py` 按原弧长固定四等分，独立反解实际f32场，确认面积没有消失，而是更多落在第一段。两侧合计第一段份额依次从19.750%、18.971%、14.401%、11.867%变为24.392%、27.518%、25.171%、24.336%。各段不是解剖真值；没有随候选峰重新选择分段。

代价必须记录：user正向目标右峰上移24.39px，左峰上移6.26px；嘴高起点附近前15%最大运动左2.86→3.76px、右3.03→3.44px。user左侧非单调尾的最大目标运动正向.170→.330px、负向.077→.266px，未知源段没有自动变成已知解剖。更宽分布不意味着所有位置更好。

## 目视与决定

主代理和独立代理实际查看完整脸与2–3倍下颌裁剪。四例对比λ1基线的外观差异仍小；user正向下巴翼略饱满的感觉不足以构成确定收益，整体V形观感仍在。man两向也未表现出明确外观收益。所看尺度未见新增明显黑缝或断层。

保留“等面积分布控制有效、部分实际曲线残差改善”的技术结论，不提升美学评分，不继续只在两张图上追逐峰高差。下一步用不同脸型的源照片找具体适用问题，避免将有限样本上的细微变化泛化。

本轮没有系统构建、接入或部署。新增的分布审计只运行双向扫掠矩形解析检查、实际四段面积可加性和两档采样对照，没有重复无关测试。所有结果位于本地忽略目录 `test/results/semantic-deformation-20261022/`：`jaw-plateau-preference-probe-v1/`、`{user,man}-jaw-plateau1-render-v1-{plus100,minus100}/`、相应 `plateau1-profile-field-audit-v1/` 与 `plateau1-motion-distribution-v1/`。图片与数组不提交。
