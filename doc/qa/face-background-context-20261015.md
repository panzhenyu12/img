# 独立背景材质上下文：V36 瘦脸补全消融

日期：2026-10-15。`portrait-woman` 1280×1920、`faceWidth=+100`，固定原 V36 源分割、几何、前景、透明度。生产未修改。

旧补全会把脸颈作为 RGB 上下文而生成肤色。新实验先排除原前景，只保留高置信头发或头发加场景，在独立下层生成补全，再仅向真正新露出的侧脸条带合成。精确 f32 重合成原 V36 像素差异 0；未知 RGB 随机改色后实际模型补全差异 0。

| 对照 | 修改像素 | 圈外/冻结/alpha | 视觉结论 |
|---|---:|---|---|
| 整块头发上下文，缩到 512 | 8,890 | 0 / 0 / 0 | 无纹理黑条，拒绝 |
| 整块头发+场景，缩到 512 | 8,848 | 0 / 0 / 0 | 无纹理黑条，拒绝 |
| 局部原分辨率 128 | 8,778 | 0 / 0 / 0 | 暗色碎纹，拒绝 |
| 局部原分辨率 256 | 8,805 | 0 / 0 / 0 | 发丝改善，仍有旧亮线/边缘阶梯，整体拒绝 |
| 局部原分辨率 512 | 8,857 | 0 / 0 / 0 | 发丝改善但偏浅，仍有旧亮线/边缘阶梯，整体拒绝 |

9,482 像素最终目标由 `oldAlpha>transportedMembership`、holes、changed、非冻结和保守侧脸材质距离条件共同确定。这个材质目标是明确的可见上下文假设，不是隐藏层真值；未经验证的颈部露出不被改成头发。

发现 `subjectMask` 在原图 y=1698 截断，直接按其反集作场景会误用下方衬衫。实际模型输入已限定调试 crop `[0,158,1233,1583]`。

本轮证明了正确上下文对材质的作用，未证明完整瘦脸达到 8 分。局部 256 仅作为下一轮源边缘分解与纹理的独立组合候选。LaMa 是已有校验权重，不是新模型或 SOTA。CPU 推理为秒级，本轮没有实时承诺。
