# 分部位曲线：原尺寸独立复核

2026-10-14，用户指出正式 v19 瘦脸不自然，要求人脸、五官与身体分别处理。本页记录 root 对隔离候选的独立判断；测试通过不转换为美观评分，失败候选不覆盖正式服务。

## 已确认的原因

v19 的真实网页导出中，强瘦脸把下颌侧边拉直、上颈收成过深的凹弧。逐阶段诊断证明 RBF 正确执行了不合适的目标，并非单纯采样精度问题。见 [v19 诊断](../face-v19-anatomical-diagnosis-20261014/review.md)。

源图语义叠图进一步显示，嘴侧上方的悬垂耳环被和耳根、头发一起纳入人体连接点距离约束。饰品像素应保留，但饰品的前景遮挡关系与皮肤连接不同；约 43px 的连接点衰减阻止旁边脸颊正常内收。这个判断来自源图/既有解析，不是重新检测编辑后的照片。

![原图与既有语义](source-boundary-semantics.png)

外缘另有独立的旧皮肤碎点问题：x407–408、y547–552 共 12px 的 face/skin/neck/hair/ears/accessories 全为零，person 约 .24/.72，物理 alpha 也为零。它们被当成已知背景保留，不是被 frozen 保护。相邻 x409.5、y550.5 的 skin=.25、物理 alpha=.251。见 [逐点数据](skin-island-diagnosis.json)。该问题需要物理边缘不确定区验证，不能通过抹掉像素或扩大整个蒙版掩盖。

## 首轮候选判定

| 候选 | 实际收益 | 拒绝替换正式算法的原因 |
| --- | --- | --- |
| 脸型 v20：原曲线相对目标、非均匀采样 QP、外颈控制 | 强档下颌直段稍缓；源曲线重采样测试通过 | +100 请求约20px，实际仅12.64px；上颈仍夹窄。+30 同实际幅度没有明确颈侧收益，部分低颈更窄。不能把削弱幅度记为自然度提升 |
| 五官 v5 首版：整眼 SE(2) 轨迹核心 | 眼缘/虹膜几何代理的平移旋转一致，避免眼内各处运动幅度不同 | 强眼距鼻梁两侧出现三角亮块，强倾斜眼睑有局部捏痕。硬阻挡阈值导致滑杆微变时映射跳6.368px、RGBA最大跳245；眼眉组合也回归失败 |
| 大腿 v1/v2：依据源半径与远端参考生成目标 | 站立右腿在相近平均移动幅度下，避免旧算法中段新增的浅凹；v2修正一侧半径小于远端参考时被正部截断关闭 | 整体作用仍受远端参考限制；±30的自然度提升不明显，瑜伽图扩张主要鼓起短裤，裤脚与皮肤接续仍有风险。膝位/衣物形状不能简单当作裸腿骨骼真值 |

Root 实际查看了用户原图瘦脸 +30/+100 的整脸、下颌和颈部 1:1 裁切；眼距/眼倾斜 +100 的眉至眼下皮肤；站立大腿、弓步双腿的同参和匹配平均位移对照。没有把派生裁切、左右腿或四档强度算作新的独立原照。

身体第二张独立原图为 MediaPipe 官方姿态示例，来源记录在 `test/images/body-yoga-mediapipe.provenance.json`。通过现有浏览器原图检测捕获定位，双大腿与膝位在叠图中可用；这不构成人工标注真值。完整 body 92 项来自旧五原照60项与新原照32项；其中76项非大腿输出不变，不能把它们记成76项新算法效果改善。

## 后继验证

- 脸部：以 v19 为冻结基线，独立验证饰品遮挡与人体连接点分离；最终饰品像素和显式保护继续检查，饰品颜色不得借入脸部。
- 五官：保留整眼轨迹，扩大眼睑相关域，重建外部皮肤延拓并处理连续的可行姿态；保留首版失败证据和原有组合回归。
- 物理边缘：独立研究连通脸颈的不确定边缘漏像素，保持几何与请求数值不变。

### 组合物理支持回放（2026-10-14）

对已缓存的源图 ZIM face alpha 和两个饰品连通件进行了五档原尺寸回放，输出保存在 [`full-replay`](../../../test/results/accessory-matting-zim-v1-20261014/full-replay)。ZIM 物理支持去掉了大部分耳环旁竖直肤色条，上颊也恢复了实际运动；这只说明源支持层有收益，不能说明目标曲线已经自然。`+100` 仍呈窄 V 形下颌和漏斗状上颈，`-100` 的轮廓也有强形变，因此三种模式均未接入正式核心。

候选中 `+100` 有 337 个、`+30` 有 340 个原 `personMask<.01` 的改动。原尺寸连通域复核见 [`low-person-audit/report.json`](../../../test/results/accessory-matting-zim-v1-20261014/full-replay/low-person-audit/report.json)：最大连通域为左耳外缘 131 像素，而不是可确认的场景背景。这个证据限制了“低 person confidence 就是背景”的规则；耳朵、饰品和脸部 soft alpha 必须保持独立的 source ownership。

额外的原图耳朵正/负点探针见 [`ears-probe`](../../../test/results/accessory-matting-zim-v1-20261014/ears-probe)。官方候选仍保留耳朵下缘的一条细长不确定区域，不能把 raw ZIM alpha 直接当 production ear matte。

候选只有在原尺寸效果改善、默认回归通过后才进入正式核心。`scripts/audit_anatomical_curve_ui.mjs` 已准备原图上传→操作→保存→导出→Go API/native/WASM 的复核，尚未对未通过效果评审的候选宣称部署或通过。

### v22 源弧比例候选（2026-10-15）

v22–v24 都未接入生产。2026-10-15 的独立源图/流场审计纠正了早期仅凭成图的因果判断，完整数据见 [源图审计](../../../experiments/face-source-audit-20261015/README.md)。

- v22 把“不是 face 类”误当颈证据，定位到 y419/426 的耳下区域，neck confidence 均为0。外颈 y510–600 几乎不动，而内部下颌控制点内收约5.6–9.9px；不能统称外颈被夹窄。
- v23/v24 又把全场运动停止区提前到 y498–582，并在 `weight>.05` 处关闭控制点。v24 的一个非零可行目标4.40px实际只动.24px。QP后仍覆盖目标、再乘衰减，QP约束不能代表最终轮廓。
- v23 的黑色凹口是错误运输轮廓外露出的暗背景。采样流场没有发现翻折或映射断开，不能据此断定补全漏填，更不能用供体颜色覆盖错误形状。
- v23b 的旧 bridge 在完全相同流场和 alpha 下另改了2198px，增加棕色色块；上侧折线在 bridge 前已存在。v24 也未通过。后续应同时约束真实外缘、内部下颌与颈部运动，避免相互矛盾的目标。

### 物理边缘复核修正（2026-10-15）

旧悬空肤色点 x407–408/y547–552 在 `+100` 的新轮廓外，新左边缘已在 x429–431。因此这些旧肤色点变为周边暗背景是应有的移除，先前把它直接判为“新黑洞”的判断不成立。V1移除9/12px，剩余3px来自颜色残差硬阈值的不连续；V2正在保持几何不变的条件下，验证连通颜色恢复及已知alpha真值。未完成验证前不宣称整体轮廓修复。

## 饰品分解的独立模型对照

Root 复用已缓存的官方 ICCV2025 ZIM，对原 parser 的两个饰品连通件自动生成框和内部正点。两侧各四个 raw alpha 全部保留，未做语义裁剪；官方 score argmax 都为2。与此前“用ZIM取整张可动脸”的失败尝试不同，这次只检验可见饰品的边缘分解。
