# 衣物源身份与几何目标一致性：独立审查

2026-11-19。`side-fashion` 在明确人工源角色和四点提示袖候选下，`geometry-corrected-replay-v3` 的普通 Rust waist `0/−30/+30` 通过本轮有限视觉审查。此前同一光学源层的 `+30` 翻折失败，根因不应继续归咎于变形公式：静止外套虽然已从光学前后层分离，仍被原几何 `partMask` 当成可动躯干。

这只证明**该图经过人工源身份修正后的可见衣物轮廓调整**。无提示候选库仍不能自动区分粉色袖与胸衣；四点提示、旧源角色多边形、源边界处理均须明确为人工介入。本轮不声称自动收腰通用可用，也不推断手、包、外套后面的真实解剖腰线。

## 不变的原图与源事实

源图：`test/results/body-material-candidates-20261119/side-fashion-source/source.png`，1280×853，SHA256 `f53c0889dc4e7e5ebe39192ad99a48375b6bbd26c2626750a1fb5e1f99a92ca2`。本次 canonical RGBA 与先前源一致。

独立候选审查及核心标签冻结见 [body-action-candidate-independent-20261119.md](body-action-candidate-independent-20261119.md)。对全部 87 个无对比提示候选的成员向量检查，已证明这批 masks 本身无法分离部分粉色前袖和衣身。不能把后续四点人工提示的成功记成原自动路径通过。

四点对比提示在原图上标记袖正点 `(588,315),(637,370)` 与衣身负点 `(535,335),(559,393)`。审查者查看全部六个正反候选，只有 `sleeve-m1` 是可继续源处理的袖—衣身 proposal；肩根仍有遗漏，不能作光学 alpha 真值。MEMatte 的源前层在绿/暗底审图中保留主体袖形，肩部有半透明尾端，位置在本次腰编辑域上方，不由此次 waist 验收推广至肩部编辑。

## 光学分层没有自动修复几何归属

在源前袖、手包、独立外套层已经准备后，旧 `partMask` 仍含静止外套。缺轴时独立侧轮廓扫描可以因中心保护证据而跨到错误外套段，使目标半径发生跳变。`source-layers/ordinary/+30` 在约 `(703,395)` 被合法翻折校验拒绝。

独立审查要求先从已经冻结的原图角色构造可见几何目标：移动的粉色衣身/丹宁材料，减去明确静止的袖、手、包和外套，且须有原人物可见覆盖；袖候选的封闭遗漏只能作为未决身份排除量测，不通过补孔改变光学 alpha。隐藏后层的人工工作范围不能穿过前景遮挡而变成可见目标。

整个修正没有改变 Rust 变形数学、翻折校验、原 Pose、原保护或 `±30` 请求。源身份、几何支持、光学 alpha 和遮挡顺序仍是不同变量。

## 三版源几何及独立判定

| 版本 | 实际变化 | 判定 |
|---|---|---|
| `visible-source-geometry` / v1 | 原角色的可见移动支持减去固定身份及袖候选；保留左侧可见丹宁边，排除垂落外套 | 允许本次 waist 同参数回放；不是全图每个身份边缘的真值 |
| `visible-source-geometry-v2` | 又与 FASHN 衣物类别硬相交，从 74472 像素减至 70662 像素 | **源判定拒绝**。除了裙开口皮肤，还删掉真实粉色针织翻折边 `x530–605,y382–406` 与丹宁字带内若干像素；不能称只修正下摆，更不能让分类器覆盖明确原图身份 |
| 恢复 v1 的 v3 / v4 | 撤掉全局衣物分类硬交集；同次分类只作源矛盾诊断；v4另取消样本专属角色名依赖 | v3 成片接受下述有限验收。实现方报告 v1/v3/v4 的 moving mask SHA 相同，因此不为仅去除样本名重复出图 |

v2 成片没有明显裂缝，也不能替它的错误源判定背书。不同源目标可偶然得到相近图像；审查必须同时检查目标身份和最终效果。

## v3 的完整有限视觉结果

结果目录：`test/results/body-material-contrastive-20261119/source-layers/geometry-corrected-replay-v3/`。独立查看两张非零全图、腰部、右外套、前袖三组原尺寸对照，并另外截取 `[490,340,650,440]` 的针织翻折—前袖—腰带接界作原像素三倍 nearest 复核；诊断在 `/tmp/body-independent-20261119/side-fashion/source-geometry-v3-knit.png`。独立直接比较 `+0.png` RGBA 与原图，精确相同。

- 左侧实际可见丹宁外缘有双向变化，内部布纹随之响应，没有把整件衣服固定来换取通过。
- 恢复的针织折边及腰带接界未见新增裂缝、暗线、双纹或硬拼贴；前袖下端没有出现新的断口。
- 前袖、手、包和独立外套外形保持稳定；右边被遮住的腰轮廓不作为宽度成功指标。
- 整图没有本轮可见的新接缝或背景扯裂。肩部源 matte 尾端在本次编辑范围外，不是已解决的通用肩袖分层。

实现方报告 `−30/+30` 分别改变 6739/6374 个像素，确定不透明前景、显式保护及零场位置的 RGB 变化均为零；沿用合法翻折检查。审查者没有重复执行算法或模型；像素数量不是视觉自然度评分。

## 对整体路线的约束

该结果支持先修复“哪个材料应当移动”的源合同，再改形变引擎。在可动衣身里残留固定外套时，继续平滑场或放宽翻折条件，会把身份错误扩散成新的纹理问题。反过来，正确的源角色也不能保证任意强度自然；[同源西装 ±60 压力审查](body-independent-sides-20261119.md) 已留下不自然曲线和背景残迹反例。

现在仍缺少可跨照片稳定提供衣袖—衣身身份的自动证据。源身份修正后的手工路径取得有限可用结果，与无标注自动算法仍有缺口可以同时成立。
