# 人脸连续速度场 v13：真实效果拒绝

隔离实验，生产/public WASM 未接入。单一 f32 RK4 场正反积分，同一 inverse flow 采样源 physical alpha。新增解析仿射 exp 与精确固定点两个单测均通过。

+100 / -100 的 stride2 112320 探针无局部 Jacobian 翻折，最小 determinant 分别 0.268831 / 0.393412，最大正反误差 0.000488281 / 0.000371262px。仅是数值证据，不是效果验收。

真实用户照片 +100 下颌侧边出现严重凹槽；-100 出现鼓包，颈部暗影与材料衔接仍失败。因此拒绝。初始速度仍来自 legacy 近段/MLS 混合场，且 frozen 语义约束在多处轮廓旁形成零速度区域，实际侧轮廓移动时停时动。将旧逆位移指数化不能获得正确的解剖目标。

下一次使用独立的光滑紧支 RBF 速度表示、固定耳根/五官/保护域约束、可行的光滑边界目标，迭代拟合实际 advected contour。不能把 no-fold 当成 8 分，也不能把请求幅度整体降小代替修复。
