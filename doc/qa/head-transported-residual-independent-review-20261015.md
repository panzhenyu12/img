# 头部残差运输实验独立复核

日期：2026-10-15。对象：`experiments/head-transported-residual-v1-20261015/`。结论：**因果实验实现与保存结果可复核，能够支持继续调查，但不构成可接入的前景恢复方案。** 本次没有修改实验候选、生产代码或原输出。

## 已复核内容

独立验证脚本为 `experiments/head-transported-residual-v1-20261015/independent-review/verify.py`，结果在同目录 `verification.json`。执行：

```sh
services/background-worker/.venv/bin/python experiments/head-transported-residual-v1-20261015/independent-review/verify.py
```

1. 原图、`probe.py` 及 ±30 的所有 trace 文件均匹配原报告 SHA-256。
2. 保存的 crop RGB 与原图对应区域一致。使用实际预乘采样、target alpha、最终背景重组时，可写域与 public renderer 均为 **0 byte 差异**。
3. 从保存层重新计算 stationary/transported 输出，逐字节等于保存图；两者冻结域与原图相同，可写域外与 V2 相同，图像 alpha 通道未改变。
4. 使用 **SciPy 的独立双线性采样器**复核残差运输，没有调用实验的 `sample_f32`。最大浮点差 +30 为 `1.5259e-5`、−30 为 `7.6294e-6`。
5. 原 native 合成含归一化分母，残差分支未使用该分母。本组可写像素分母偏离 1 的最大值仅 `5.96e-8`，没有 `>1e-6` 的像素，因此本组比较没有实质性的归一化混杂；其他输入仍应保持同一合成契约。
6. 重新执行两个已知层反例单测，均通过。它们证明给定真值层前提下的行为，不证明真实人像已正确分层。

| 检查 | +30 | −30 |
|---|---:|---:|
| 运输版相对 V2 变化像素 | 5,794 | 5,071 |
| 原位残差版相对 V2 变化像素 | 4,623 | 4,627 |
| 冻结域 / 可写域外额外变化 | 0 / 0 | 0 / 0 |
| 正 alpha 源重组合最大 byte 差 | 0 | 0 |
| 零 alpha 源重组合最大 byte 差 | 237 | 237 |
| 违反预乘颜色物理范围的像素 | 2,169 | 2,175 |
| 其中不透明 alpha=1 像素 | 0 | 0 |

两个方向的预乘范围失败全部来自 `0 < alpha < 1`。因此把不透明像素颜色固定为原 RGB 是合理的独立修复目标，但它本身不会解决这组不确定边缘的可行性问题。

## 因果解释与限制

原尺寸左耳对比中，运输版明显减弱 V2 的亮/暗双边，原位残差更容易留下旧耳边。这与“前景估色误差留在旧坐标会产生残影”的已知层反例一致。发际和耳饰的恢复也体现同一现象。

但真实 `R = C - aF - (1-a)B` 同时可能包含前景估色误差、背景估色误差与 alpha 误差。只有归属于前景的部分才应该与前景一起运输。将全部 R 运输不能识别这些原因，也不证明恢复出的耳饰、头发或皮肤属于正确材料。当前存在的 2,169/2,175 个不可行像素正是明确反证；最终 RGB 截断不能替代物理一致性验证。

正 alpha 区源重组合为 0 byte 差是该残差定义的代数结果，不能当成低强度滑杆通过。alpha=0 区主动拒绝运输残差，所以整体源误差 237 不代表程序错误，但同样没有证明实际近零连续性。

目前仅一张用户提供图像的 ±30，尚无 ±100、近零强度、多照片、真实相邻人物、WASM 与性能验证。实例归属还受到 [whole-face V2 独立审查](whole-face-v2-instance-owner-review-20261015.md) 中的连通跨人缺陷限制。本实验应保留为因果证据，不能将它直接部署或据此给出 8 分评价。
