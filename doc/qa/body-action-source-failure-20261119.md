# Action-suit 新原图：衣侧轮廓不响应

2026-11-19。最初自动收腰 `±30` 未实现此照片的可见衣侧重塑；下面保留完整失败证据。后续同源自动材料归属与左右独立轮廓修复，已在此图 `0/±30` 产生连续衣侧响应，并保留电脑、手与离身袖核心；最终证据见文末。这是单图、有范围的改善，不能宣称所有身形算法可用。

## 冻结输入与同次后验

原图 `test/images/action-suit.jpg` 为 1280×1013，SHA-256 `70bfac21aa227629e24ae91ebc6b65e47177b84e0f000d5a14415cc467d8ff94`。它检验电脑/手/袖前景遮挡和敞开西装衣摆，不检验不可见的真实解剖腰宽。检测与编辑前，用原图冻结左右可见西装侧缘、电脑/双手/双袖和背景线探针；这些只用于评价，没有作为模型 prompt 或几何控制输入。

当前 `detectPeople(canvas, 'body')` 从原 JPEG 运行一次 MediaPipe Pose/FASHN，耗时 11.20 秒，FASHN 加载 2.22 秒、推理 7.44 秒，实际 ORT Wasm 单线程。同次浏览器 PNG SHA-256 为 `354a014d99018a68219f2223376fd889492b85417bedaf044fd7a75f924b25d4`。一个只读 Worker 消息监听器保存这一次 FASHN 的原始 logits（`1×18×144×96` f32）和当前 `decodeBodyLogits` 使用的 18 类量化后验（`18×304×384` u8）。没有第二次推理、旧 prepared 输入、模型下载或整体构建；不将量化类别概率称为物理 alpha。

普通 `image-render` 的二进制 SHA 和七个 body 相关源码 SHA 与上一轮已构建的 `current-native` 完全一致。回放只改 `adjustments.waist=0/-30/+30`，其余原图/姿态/掩码/保护保持。

## 功能效果与原因

零值逐 RGBA 不变。−30/+30 分别改变 12,498/12,117 像素；原 92,885 个保护像素、源图先定的电脑/双手/双袖核心与背景线探针都未变。两向进程耗时约 1.13/1.07 秒（包含 PNG 编解码与进程启动，不是浏览器实时性能）。

原尺寸全图及侧缘裁图显示外轮廓没有可见收放。为诊断，在**原已冻结可见折线**周围取约 ±4 px 带（带宽是成片后诊断设置，不冒充预注册），再调用公共 `prepare_body_inverse_displacement` 读取当前普通几何场：

图内最大位移却达两向约 11.49 px，说明并非请求没有执行，而是驱动落在内部材料。右侧衣内源点 `(634,654)/(646,701)/(654,752)` 的同次 `top` 后验约 `.914/.945/.929`，最终 subject coverage 都为 1、保护为 0，但 torso `partMask` 都为 0；更下方 `(656,787)` 的 `top≈.933`、subject=1，torso part 突然为 1。源图中的西装还在，当前骨轴竞争的材料分配却把上段衣摆排出躯干。派生的支撑多边形进一步停在真实右衣侧内，随后普通几何场在那里被固定为零。

这支持**源部位归属及其派生几何支持不足**的定位，不能泛称 FASHN 没识别西装，也不是已经证实的合成裂缝问题。由于未保留原始 Pose 实例 alpha 及所有竞争 owner，本轮不臆造究竟是哪一条手臂 owner 独占了每个像素。保留的同次类别后验与最终 subject/part/protect 已足以证明这些具体点不是语义衣物缺失或已有保护导致。

## 下一具体改动与边界

下一候选应以原图自动材料提案和关节兼容性校正运动片区归属，保留电脑、手和离身袖的独立身份；不能把整件敞开西装当成上一张应固定的垂挂外套。通过源审后，必须用修正后的**几何 partMask**重新执行 `measuredTorsoSupport` 并重建选择多边形和 region，再跑相同普通入口/强度/测量规则。只换 partMask、保留旧蓝框会继续锁死右衣边；仅放大蓝框也不能解决错归属。光学 matting 不作为几何身份输入。

若修正后的可见材料仍不足以支撑原测量函数，应明确不可观测或暴露几何测量问题，不能手工填隐藏腰部、扩大蓝框或用内部白衬衣移动冒充成功。

证据目录：`test/results/body-action-source-20261119/`。`source-scope.json` 是原图评价合同；`action-suit/` 保存新检测、同次 logits/classes、源 graph；`ordinary/` 为普通原尺寸成片；`diagnosis/` 为公共场与源后验定位。照片、数组、模型和生成结果不提交 Git。

## 同源自动归属揭示并修复轮廓断续

固定 4×8 源图采样的 SAM2 候选库加 Pose/FASHN 关节兼容分配，产生自动 torso 候选；没有追加手工 prompt 或从成片画 mask。V3 用整个人候选约束躯干、减去两个独立袖提案后，经公共 `bodyParts`/`measuredTorsoSupport` 重建支持。它让右衣边真正动起来，却在双向成片产生两处明显隆起/折角，因此直接判失败。

公开逆向场显示这两处响应在支持内部变成零，又恢复到约 ±10 px。源骨轴穿过电脑混合边界时，中心 part 低于 .5 且被保护。旧 `ContourProfile` 需要中心有材料才测量两侧；中心遮挡因此冻结了整行，包括无遮挡的远侧衣边。源轴低值、公开场突变和成片折角一致，支持该因果定位。

核心修复改成左右分别测量可见材料区间，并限制只有明确受保护的骨轴中心或内部孔洞才能跨过缺失中心寻找材料，避免把普通背景或错误骨轴解释成遮挡。保护仍约束实际遮挡像素。随后 V4 仅保留连到源 torso 观察点的组件；3,324 个无关孤立像素被标为未解析/固定，而非宣称背景。V3/V4 支持多边形、region 完全相同，不能将变化归因于缩小 ROI。
