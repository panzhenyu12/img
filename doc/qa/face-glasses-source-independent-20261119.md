# 常见眼镜正脸：新源流程独立审查（2026-11-19）

## 当前结论

`portrait-man` 的普通 Rust `faceWidth=0/±30/±60` **有限通过**。先完成轻档，再复用同一源资料增加 `±60`，没有为强档重跑模型或改变输入策略；不是任意照片或整个人像编辑器达到可用、8 分的证据。照片在旧语料中存在，因此也不称作盲测。

本次独立审查逐张查看 683×1024 的原图和完整正负输出，以及不缩小的全脸对照、2 倍最近邻镜圈/双侧耳颊/胡须颈部对照。两方向有可见的脸宽响应；未见新增镜框弯曲或双影、镜圈下硬接缝、脸颊阶梯、胡须断裂或颈边色线。源侧链中的剧烈横坐标跳变，在这些成片中没有形成明确的新锯齿；不据此推断所有强度均安全。

## 输入与真实失败

- 原图：`test/images/portrait-man.jpg`，Pexels 220453。canonical 为 `test/results/face-new-frontal-20261119/canonical-source.png`，SHA256 `bdefa2af0a2d05b65991a4ca06017a657218653ee6aba491c529136d142c3e31`。
- 冻结输入和策略：同目录 `fixed-input.json`。原图一次 EXIF 归正、最长边限制为 1024，随后坐标不变。
- 初次 source-only 准备在附件阶段拒绝：合并的 accessories 同时含眼镜和耳饰，旧 planner 将所有组件授权随耳移动，与双眼保护冲突。没有把这个拒绝记作成片成功。
- 同源 class 6/9 后验分区后，整副眼镜支持域 15,821 像素明确固定，原 accessories 蒙版保持不变；未删除眼保护、剪掉眼区或清空眼镜。分类是后验估计，不是真实物理 alpha 或通用实例识别保证。
- 随后普通入口 `±30` 都返回 `PrimalInfeasible`。独立复算失败 QP：第 95 行只涉及三个固定点，源见证违反该曲率不等式约 `1.2348133396e-6`，固定等式残差为 0。f32 源差分与 f64 约束求值不一致，导致严格矛盾；不是必须解除镜框保护的证据。

失败 JSON、日志和首次普通入口 manifest 均保留在本地结果目录。

## 修复的独立代码审查

附件准备按完整 soft 连通域合并多个 hard core，再分为固定眼镜、可动耳饰和未决固定组件。混合组件不切碎，真正请求随动的耳饰若碰到独立保护仍拒绝。源、图、后验和支持域绑定在 partition 侧车中；重建与 geometry 使用同一验证合同。typed 路径保留显式零许可，不回退为全部附件解除固定。

轮廓 QP 改用 `d=target-source`，以一致的 f64 源差分构造约束。目标仍为目标位移拟合加位移二阶平滑；固定点仍为 `d=0`，区间与一阶/曲率约束保留，零位移成为明确可行见证。迭代上限、求解容差与间距下界未放松。这是修正原浮点边界错误，不能称为与原错误数值矩阵逐位等价。

父任务执行的四项定向曲线测试通过，包含真实两方向数值反例的红到绿、固定点逐位保持及自由控制点响应。独立 reviewer 未重复编译或运行这些测试。

## 适用边界

本次只接受该常见正脸已测的脸宽档位。整副眼镜及镜片投影区域固定，是本操作的几何保护策略；没有重建透明镜片、反射或镜片后的动态五官。眼部编辑、未测强度、侧脸、交叉遮挡、更多镜框和任意照片仍需各自验证。已有原图景深模糊与墙面阴影不因本次检查被宣称修复。

未进行 Web/Go/WASM 构建或部署。照片、模型、数值数组和输出留在本地忽略目录。
