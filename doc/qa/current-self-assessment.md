# 当前功能主观评分

日期：2026-10-13。评审算法版本：`27066d7`。目前对核心成片效果的整体印象约 **6/10**；这是主观判断，不是各功能的算术平均或验收通过率。没有逐功能达到 8 分的证据。

## 评分口径

本次重新查看脸型九参数正负矩阵、身体失败样片、皮肤多图、五官代表、衣物三个选区及双端去人结果。胶片另外用当前 native 核心在街景与城市两张图上生成八种 preset，强度70，其余特效0；没有与富士相机或真实胶片对照。

下面标“视觉暂评”的分数只评价已看样片的目标效果、自然度和部位保护；缺少对应参数独立计时，不伪造效率分，也不替代 [35/35/20/10完整验收](quality-targets.md)。基础工具分数为现有Demo范围内的正确性与可用性暂评，不能推断RAW、广色域、大图或所有浏览器已达标。8分以上的暂评同样不改变正式验收状态。

皮肤已有四维初评：自然磨皮7.00、强磨皮5.60、纹理保留7.35、美白/冷暖/红润均6.90。效率只依据1024px native 总进程229–662ms；身体依据768px总进程640–1188ms。初始化、识别和完整热运行性能缺口仍保留。表中保留一位小数，减少主观精度造成的误解。

## 未实现与优先改进

眼袋/泪沟结构、面中/双下巴、身高/腿长、体态和衣物版型重建尚未实现。按实现完成度为0；不将其记为0分的算法实拍评测，也不从目标清单删掉。

优先解决真实部位隔离与alpha边缘、强磨皮的瑕疵/毛孔区分，以及复杂补全的结构与纹理约束。其后逐子参数补多人物、正负方向、极值和效率证据。任何分数提高必须有对应新结果；本页不会把某项代表效果外推为全部滑杆达标。
