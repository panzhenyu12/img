# Direct joint skin matte 独立审计

结论：支持将 direct ZIM 作为“局部遗漏源皮肤条”的新证据继续试验；不接受 raw matte 整体替换，也不接受当前合成输出。几何 B 与新分层的组合仍未解决耳根接点。

## 源图支持证据

独立检查 `experiments/joint-skin-matting-v1-20261015/outputs` 四种调用的官方得分选择（均为 index 2），未根据好看程度挑候选。输入 source 与缓存 alpha 的 SHA-256 均匹配作者记录。

full-point 与 crop-point 在耳饰旁皮肤窄边均比旧冻结 physical alpha 更连贯；附件邻域 alpha 平均绝对差为 0.00356，差大于 0.2 的像素为 65。模型一致性不是材质真值，因此又从原图检查，排除全部观测耳朵支持下沿再加两个 parser pitch（本图 4px）：

| 耳侧 | 新增共同支持 | 未被 v2 pure/trusted 覆盖 | 旧 alpha 均值 | direct alpha 均值 | RGB 中位数 |
|---|---:|---:|---:|---:|---|
| 左 | 349 px | 166 px | 0.094 | 约 0.996 | 138, 106, 93 |
| 右 | 239 px | 121 px | 0.112 | 约 0.996 | 160, 125, 105 |

这 588px 的原尺寸图显示为与脸侧连续的皮肤窄边，opaque metal 重叠为 0。它提供了旧源像素归属存在缺漏的证据，其中 287px 是 v2 支持也未回收的部分。

raw matte 不能整体采用：full/crop 对旧耳核心 alpha 均值分别为 0.936/0.923，耳负点被模型忽略；它把耳朵与脸颈整体抠出。full/crop 在独立 opaque metal 域 alpha 最大分别 0.0673/0.0185，未超过 0.1，但这不能替代专门的耳/饰品分层。

## 新分层 × 几何 B 的组合消融

独立 `compose_geometry_b.py` 复用 root `composite-v1b/source-layers.npz`，只把采样 inverse 换成 B 的 clamp-0.08。root ±100 baseline 经独立重放 RGBA 逐字节一致；source-layers hash 未变。保留 ±30、±100 四个方向。

- B 完整 inverse 的实测位移保留 97.09%–97.78%。局部合成以 root 原完整域为准，域外继续是 V36；因此不把这个 inverse 指标当成整张输出的视觉验收。
- 耳/hair fixed 域与原图完全一致，图像 alpha 不变。
- +方向 opaque metal 无变化。-30/-100 继承 new-source baseline 对既定 opaque 域的 11/20 像素差异；B 分别又令其中 3/1 像素差 1 字节。根因是既定 opaque 阈值为 ≥0.95，而 root 合成只冻结 jewelry ≥0.98。已保留失败，没有在消融中偷改门禁。
- 原尺寸耳旁图中，+100 左耳圆盘形内侧接点、右耳根锯齿均未被 B 明显改善；-100 也无可判的改善。因此该组合 rejected。

## 耳根残差的材质判断

右耳根原图 x650–655、y430–432 的 13 个高 residual 像素是暖肤色；旧 ear alpha 几乎全为 0、direct skin alpha 0.005–0.212、jewelry alpha 0.009–0.118。源图重建在这里最多损失 97 字节，当前合成也把其变暗。这是有效 source 层之间的归属缺口，不能把它当作已知背景。

位置、颜色与耳垂下缘连接，支持下一轮“stationary ear fringe 缺失”的假设，但 RGB 与单图语义不能唯一证明耳垂/脸颊/饰品反光归属。应从源图补独立耳缘支持和混合边缘证据，不能直接把它加入 moving skin 来消掉 residual。

左耳圆盘区域在原图确实有耳垂组织；输出出现明显的圆形内侧边界，可能来自固定耳层与内移脸层的新遮挡关系。它不是凭空生成一整块皮肤，但“原本存在耳垂”也不意味着当前连接自然或合格。该侧检查窗口没有 >25 字节 source residual，说明 source residual 小不能证明目标合成自然。

## 下一轮产品合同与附着联动假设（尚未采用）

本节依据用户原话“不要统一形变，不要背景和人物一起拉伸，要真正的重塑”“裂缝、衔接断开肯定不能出现”区分产品意图与现实现。用户未要求耳朵、耳饰的绝对图像坐标永远不动。`FUNC-011` 的全耳/配饰冻结及其 bit-exact 测试是此前实现的保护策略，不足以把“不能移动耳饰”推导为用户需求。本轮实验保留这些历史结果，不修改生产测试或旧候选。

更合理的预期合同是：脸侧轮廓按瘦脸目标改变，五官身份与皮肤细节保留；耳根—耳垂—耳饰的连接连续、比例自然；耳饰保持自身形状与材质，可以随实际耳垂附着点作小范围刚性位移/旋转。明确的用户保护区、其他人物、未涉及的场景背景仍独立保护。新暴露背景需要局部重建，不能以“背景不拉伸”误推导为“原人物覆盖区域也一字节不能变”。

需要区分三类约束：

| 对象 | 应维护的性质 | 不应直接推导的性质 |
|---|---|---|
| 用户明确锁定区、其他人物 | 按当前编辑语义固定 | 自动识别耳朵也必然是用户锁定 |
| 耳根、耳垂、耳饰 | 附着关系、形状、尺度、纹理、合理遮挡 | 所有源像素只能留在原坐标 |
| 脸颊与下颌皮肤 | 连贯可逆变形、目标曲线、有效瘦脸幅度 | 和金属/背景共用同一个自由形变场 |

推荐下一轮只做独立三组因果对照：①现完整 source/domain + 固定耳附件；②耳/耳垂适度联动、耳饰仍固定（用于验证断开的中间反例）；③耳层与耳饰按附着关系联动。三组复用同一 source 分层和背景估计，不同时再优化颜色。脸宽实际位移继续至少保留现有的 80%，±30/±100 与零值全部保留。

可行的实验设计：从源图语义接触边与 RGB 边缘估计耳前根、耳垂及耳饰挂接点，记录置信度。用脸侧目标场对连接点的要求拟合耳层的二维刚性位姿（带尺度/姿态归一化的小角度先验）；耳垂作为软组织可在耳根到耳垂的连接域平滑联动，但不把整个耳朵同皮肤做自由拉伸。每个耳饰组件保持独立刚体，用耳垂挂接点的位置和局部方向驱动 SE(2) 位姿，避免不规则金属被挤压。各组件只逆向采样一次，在统一的目标坐标下按可见层次合成；原位置与新位置的并集决定显露/覆盖区，不能再把旧 ear binary 边界当作输出裁剪线。具体是否需要耳软组织联动、耳整体刚性或只动耳垂，应由原尺寸成像结果淘汰，不能凭“更物理”预先宣布获胜。

验收应从“耳像素坐标不变”改为对应实验中的“挂接点间隙、耳缘切线与曲率、金属形状/尺度误差、变换对齐后的材质误差、显露区双边/黑楔”。刚性移动发生重采样，不能要求旋转后的 RGBA 与原位置逐字节一致；未动的锁定区与编辑支撑域外仍可要求逐字节一致。耳饰可动也不授权凭空修改其金属高光或发明挂接点。置信度不足、耳部遮挡严重或背景重建失败时，应明确拒绝/保守退回，不声称完成自然重塑。

该方案比“自动耳类别绝对固定”更符合当前用户意图，也能解释圆盘接点为何可能来自错误约束；但它还没有实测，不能保证圆盘一定因此消失。当前 direct matte 缺失的右耳 fringe 必须同时有独立源层归属，刚性联动不能弥补不存在的源像素支持。
