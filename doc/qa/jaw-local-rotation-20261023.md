# 下颌局部旋转实验：数学复核（2026-10-23）

本文先记录算法、装配和小网格复核，末节追加主任务唯一一次真实照片实验及独立视觉复核。没有接入系统或质量评分；原 prefix 目标仍是 `AlmostSolved` 的诊断候选。

## 已排除：相似形变膜能

对位移 `d=(u,v)`，拟议能量为：

```text
E_sim = 0.5 ∫[(u_x−v_y)² + (u_y+v_x)²]
      = 0.5 ∫|∇d|² − ∫det(∇d)
```

当前完整 ROI 的外边界位移全为零，最后一项是边界项，积分为零。因此该方案全局上恰好等于半倍 Q1 膜能，交叉耦合抵消。虽然自由边界上的有限旋转、平移和统一缩放能量为零，这不代表当前锁边条件下获得了新的旋转能力。`similarity_field.py` 的解析测试确认这一点；不运行该方案的照片实验。

## SO(2)-ARAP 的作用与限制

真正的 ARAP 约束旋转，统一缩放仍有代价。令 `F=I+∇d`，局部能量为 `min_R∈SO(2) ||F−R||²`。其小变形二次项为对称应变：

```text
∫||sym ∇d||² = 0.5∫|∇d|² + 0.5∫div(d)²    （当前零边界）
```

因此可以改变二次阶应变分配；有限旋转相对线性应变的修正则从更高阶开始。冻结原 across 位移场的只读测量：

| 加权项 | 数值 |
|---|---:|
| 原边差分膜能，权重 0.001 | 0.3906102512 |
| Q1 线性对称应变，同权重 | 0.2785394413 |
| Q1 求积的 SO(2)-ARAP，同权重 | 0.2775518495 |
| 原 bending，权重 0.05 | 0.1017978161 |

其中 ARAP 的非线性修正只占线性应变的 **0.355%**，最大采样局部旋转约 **6.80°**。这组数字属于同一个冻结场上的 Q1 求积评价，**不是下面 graph 实验的求解结果**，也不能证明肩折会改善。ARAP 的 polar 项非多项式，2×2 Gauss 是求积近似，不能称其连续积分精确。

## 本次隔离实验：保持原矩阵的 graph ARAP

沿原 `Dx/Dy` 的无向网格边使用：

```text
E_edge = 0.5*w*[||q−R_i p||² + ||q−R_j p||²]
p = 原边向量；q = p + d_j − d_i；w = cell_area / edge_spacing²
```

`R=I` 时逐边精确恢复原膜能。目标、bending 0.05、膜系数 0.001、网格、保护区域和原 `H` 全部保持。局部步骤从每个节点全部相邻边求最近的 proper rotation；包括连接固定节点的边及固定节点自己的协方差。固定的是位移，不额外规定其旋转。

全局步骤仅更新右端：

```text
rhs_new = rhs_original
        + membrane_weight * cell_area
          * [Dxᵀ((R_avg−I)e_x) + Dyᵀ((R_avg−I)e_y)]
```

两分量共用原 SPD 矩阵和分解，最多 8 次局部/全局迭代。固定旋转后的平均端点矩阵未必是旋转，但它正是该二次子问题的正确线性项。能量审计必须计算上面的两端残差半和；若写成平均旋转残差，需保留 `0.25*w*||(R_i−R_j)p||²`，不可漏掉该常数。

核对重点为原膜能等价性、前向旋转符号、固定节点、完整目标加 bending 加 ARAP 的下降、有限旋转零能，以及原 source/最终 f32 二维几何、执行增益和固定像素门禁。局部/全局下降不等于全局最优或审美通过。真实照片实验由主任务在独立复核后决定。

## 实现复核结论

已独立复核 `arap_field.py` 与其 9 项小网格测试的代码。前向旋转符号、物理边权、全局右端系数、固定节点参与局部旋转、完整目标函数及局部/全局能量下降检查均无阻断。测试覆盖零位移、刚体运动、缩放代价、原膜能等价、固定区域、迭代上限和不支持的约束；测试通过不代表照片效果通过。

最后一次局部旋转更新后，代码另算固定旋转下的 stationarity，未把上一步线性方程残差当成非线性收敛。`inverse_evaluation_allowed` 仅表示源几何可进入逆场评价；若状态仍为 `ARAPIterationLimit`，调用方必须保留诊断身份并拒绝常规成图。

这组数值来自视觉复核代理对冻结逆场的只读反解，原计算未保存独立报告；这里只作测量记录，不冒充已归档可复现证书。此 `r=2` 定义不同于其他半径或最近点匹配的转角，不能直接混比。它支持“单纯再保局部角未必对症”，不能证明 ARAP 无收益。因此本候选检验的是局部应变如何分配，不能预先承诺去掉上段肩折，也不能把 ARAP 能量下降作为自然度提高的证据。

## 唯一一次真实照片实验：未证实可见收益

主任务使用同一原 prefix 目标、原强度、目标权重、保护区域、原 `H` 与 bending 运行 8 步 graph ARAP。完整 graph 目标函数由 `0.38069980806752257` 降到 `0.372937107093257`，下降 **2.0391%**。最终状态为 `ARAPIterationLimit`：最后节点步长 `7.07799e−5 px` 高于 `1e−7 px`，相对能量变化 `3.14873e−10` 也高于 `1e−10`。没有追加迭代或扫描权重。

源场与最终保存的 f32 逆场几何检查、原材质响应门禁均通过；全图 `1,006,927` 个固定像素变化数为零，鼻、唇、耳、附件、上脸和邻域外保护变化数均为零。源目标最大误差为 `0.007796 px`，实际原轮廓点最大误差为 `0.022313 px`，独立连续弧采样最大误差为 `0.027215 px`。这些数值不能覆盖非线性未收敛，因此 runner 正确返回 `rejected_nonlinear_convergence`，没有批准正常照片输出。

为评价算法方向，主任务另对几何检查通过的冻结场生成带 `REJECTED` 标记的诊断对比。独立查看完整脸部、左颈、右颈三图后：完整脸部没有可确认的整体自然度提升；两侧外轮廓上端的肩状折点仍存在，左侧下段只有轻微形状变化，右侧也没有消除同类折点。没有把小幅变化视为达到 8 分。

诊断报告按源图 `y` 行的 `±12` 行取样计算界面转角；该定义不同于此前源弧长半径 `12 px` 的转角：

同一候选中改善与退化并存，与三图视觉结果一致。结论仅限这次固定目标和支持域：换成局部旋转能量不足以证明解决当前肩折问题。不能推广为 ARAP 在其他编辑任务无效，也不能把能量下降转写成审美提升。
