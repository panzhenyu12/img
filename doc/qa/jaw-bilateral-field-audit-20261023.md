# 下颌双侧相对收缩：λ=1 实际场独立审计

日期：2026-10-23。本次仅做离线算法审计，比较相同源图、源几何、signed amount、crop 和解码后的固定像素，不涉及系统接入或美学打分。

产品研发决策与视觉检查见[本轮总评](jaw-bilateral-coupling-20261023.md)；本文保留独立数值定义和反例。

**双侧相对运动的平均不均衡在四个案例中降低，实际总编辑面积基本保留；但候选没有全面通过旧曲线判据。** 用户图 −100 新增 1 个已知窗口反转，男性图 +100 右侧反转采样数从 225 增至 369。用户图 −100 的配对域边界相对误差也增大。不能只根据 RMS 降低宣布改进成功或达到 8 分。

目录均相对 `test/results/semantic-deformation-20261022/`。

用户图保持 smoothing=12 px，男性图保持 smoothing=4 px；本实验只加入 λ=1 双侧目标耦合，默认 λ=0 保留。两类源图分别保持原 1024×1024、512×768 尺度，不能把它们的绝对像素指标直接当成等尺度排名。各方向保持原始源图、源几何、请求面积、stride 1、2 px collocation 与保护区域。

[独立审计器](../../experiments/semantic-deformation-20261022/audit_jaw_bilateral_field.py)不导入优化器的新 coupling helper。它从原始源折线逐段求同一 down 高度的交点，先统计**所有**交点，再仅接受左右各恰有一个、方向向下且半径符号正确的开高度区间。不会只挑其中正向的一个而忽略另一反向交点，也不会跨未知尾外推。源几何不平滑、不重标、未知解剖归属不升级。

冻结源有符号半径为 `r=(source−origin)·across−midline`，实际或目标横向位移为 `du`，相对收缩为 `q=−du/r`。比较 `q_left−q_right`，RMS 按共同源高度 `dh` 积分，目标与实际 f32 结果分开。相同收缩比例通常需要不同像素位移；该度量并不要求源脸天然对称。

用户图有效配对高度长度为 **77.961509 px**，下端止于 down≈228.421141；左弧回头且右弧无对应点的余段被排除。男性图有效长度 **84.816119 px**，止于 down≈189.765040；右弧回头且左弧无对应点的余段被排除。机器舍入产生的约 1e−14 px 不可配对顶端区间也原样记录。

实际源点目的坐标通过反解最终保存的 **f32 inverse field** 得到，未用目标坐标冒充结果。RMS 采用 0.125 / 0.0625 px 两档 midpoint 积分；另测全部合法原段的**单侧端点极限**，补足仅看 midpoint 会漏掉的尾端比值。单侧极限来自已存在的配对原段，未进入未知尾。

## 双侧相对运动：改善与边界反例

RMS 使用 0.0625 px 网格；max 取两档采样与合法单侧端点极限的并集。它们仍不是完整连续域极值证明。

| 案例 | 目标 RMS：基线 → λ1 | 实际 RMS：基线 → λ1 | 目标 max：基线 → λ1 | 实际 max：基线 → λ1 |
|---|---:|---:|---:|---:|
| 用户 +100 | 0.015032295 → 0.011112881 | 0.015043527 → 0.011127042 | 0.032941644 → 0.031761015 | 0.032894595 → 0.032893430 |
| 用户 −100 | 0.003677675 → 0.002437312 | 0.003686195 → 0.002444834 | **0.012889155 → 0.014806830** | **0.012030803 → 0.014951609** |
| 男性 +100 | 0.022487563 → 0.012593921 | 0.022491801 → 0.012599126 | 0.054828785 → 0.028195548 | 0.054740760 → 0.028380275 |
| 男性 −100 | 0.017416542 → 0.007890606 | 0.017420414 → 0.007890403 | 0.043009856 → 0.022149071 | 0.042810843 → 0.021970077 |

用户 −100 λ1 的 midpoint max 在 0.125 / 0.0625 px 网格分别为 0.007388231 / 0.008736555；直接据此判断 max 下降会遗漏合法域边界的恶化。该边界左右源半径为 **−6.530406 / +0.596528 px**，实际 λ1 `q_left/right=−0.014704543 / +0.000247065`，相对差为 0.014951609，超过基线 0.012030803。右端目标为零；很小的执行残差在小半径分母下会放大，但候选目标边界差本身也由 0.012889155 增至 0.014806830。两层原因均保留。

用户 +100 合并端点后实际 max 几乎没变，因此不能沿用仅 midpoint 的约 22% max 改善说法。RMS 降低与局部最坏点改善是不同结论。

## 换算到公共半径的像素量

为同时观察小分母的影响，补充声明公共半径 `r*=2|r_left r_right|/(|r_left|+|r_right|)`，并令 `m=r*|q_left−q_right|`，单位 px。这是两侧原半径的调和平均；不是两侧像素位移必须相等的约束。没有用该新指标替换原 q max 或改验收阈值。

| 案例 | 目标 m RMS：基线 → λ1（px） | 实际 m RMS：基线 → λ1（px） | 实际 m sampled max：基线 → λ1（px） |
|---|---:|---:|---:|
| 用户 +100 | 0.834762 → 0.604297 | 0.835038 → 0.605019 | 1.468468 → 1.127679 |
| 用户 −100 | 0.227807 → 0.150911 | 0.227702 → 0.150702 | 0.524321 → 0.374599 |
| 男性 +100 | 0.990611 → 0.579158 | 0.990859 → 0.579651 | 2.126916 → 1.170319 |

两档采样的各目标/实际 m RMS 最大差均低于 7.8e−6 px。该量支持“平均双侧编辑量更接近”的有限结论，不消除端点相对差与实际曲线反转问题。

## 证据保留与范围

每张图、每个方向对应以下四类目录，均含 `report.json` 与执行源码快照：

- `{user,man}-jaw-bilateral1-actual-audit-v1/{plus100,minus100}`：同高度目标/实际 q、双档采样、配对与排除区间、源点和峰层。
- `{user,man}-jaw-bilateral1-profile-field-audit-v1/{plus100,minus100}`：完整面积与原已知源凸窗口。
- `{user,man}-jaw-bilateral1-endpoint-audit-v1/{plus100,minus100}`：合法源段单侧极限补充；原 midpoint 报告没有覆盖。
- `{user,man}-jaw-bilateral1-radius-weighted-audit-v1/{plus100,minus100}`：明确换算公式、两档 m RMS/mean/max。

主审计核验各 profile 对其实际执行协议的历史摘要，并冻结原图声明、源 JSON、profile、f32 场、decision 与固定掩膜。四对 decoded fixed pixels 均相同；只有用户 +100 的固定 PNG 文件字节相同，另三对容器字节不同但像素相同。补充审计绑定已冻结主报告与数组摘要。

本轮没有重复已通过的测试套件、整体 build、前端/后端接入。原两项独立指标测试覆盖不等半径的相对收缩及多交点/逆向/未知尾拒绝，未重跑。新增的半径换算补充函数单独运行 1 项合成测试：已知半径、非均匀 dh 权重的解析 RMS 与 max 符合预期，零半径输入拒绝，测试通过。照片、数组和输出仅留本地忽略目录。用户图带“AI 创作”标记，不是独立真实相机纹理证据；仅两张源图仍不足以证明泛化或自然美观。
