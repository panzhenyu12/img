## 同面积机制及因果范围

旧操作从 mouth-center 平面开始；新操作从 upper-lip 代理点所在平面开始，沿每侧原始轮廓向上增加约 23.4 px 源弧长。新目标不是在旧目标曲线上重新配对材料，而是一个**新的目标曲线**。

`jaw_scope_transport.extend_profile_scope` 将旧分段线性位移在新弧长上展开：

`u_new(s) = k * u_old(s * L_old / L_new)`。

每侧的 `k` 分别由旧有符号面积除以新未缩放面积计算。积分节点是原始源折线顶点与映射后目标节点的并集，在每段上做精确分段线性积分；不是简单按弧长比猜缩放。保留每侧的面积请求、编辑方向、原始源轮廓和下巴端点，不能因此声称保留了旧目标曲线集合或旧优化器可行性。

同面积约束减少了“只是把瘦脸力度整体降低”的混淆，但**范围、目标位移分布和上部保护带三者一起发生了改变**。此次单次比较只能评估这个组合干预，不能孤立证明其中任何一个因素就是根因。

新 profile 保留旧 profile 的失败/未验收 provenance，且自身仍标记 `diagnostic_only=true`、`image_approval=false`、`aesthetic_approval=false`。数值执行检查应独立报告，不能继承成照片质量批准。
