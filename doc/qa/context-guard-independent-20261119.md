# 模型上下文保护环独立审查（2026-11-19）

结论：614810 的 4px 上下文保护明显减少瘦脸后露出的背景灰影，支持“轮廓附近的混色被作为背景输入并向孔内传播”这一原因。**完整瘦脸仍未验收**：原光学范围之外留有细暗轮廓，正向强档左右脸侧均可见；本次没有修正原 trimap 或 optical alpha。

## 比较与成片观察

固定源图、模型、256px tile、128px stride、32px 源内接受带。4px 保护只影响模型可读上下文，最终写入仍限原 mask。一个 tile 的 11 个已知像素在保护后全部变为未知，不能推理；独立核对其余 23 个 tile 仍完整覆盖 60,359 个内带像素，未覆盖数为 0。旧 0px 对照也使用同样 23 个 tile，避免权重集合混淆；执行 agent 另核对其五档成片与原 24 tile 结果完全一致。

## 剩余原轮廓与后续约束

在 `(302,571)`，trimap=0、input alpha=0，source、两份 B、4px 的 +30/+60 输出都为 `[106,126,132]`；向外 `(300,571)` 同样保留源暗色。原 raw MEMatte 在前者为 `.102461`，官方结果因 trimap 强制为 0。它支持质疑硬背景假设，不能证明 raw 是正确 alpha。细暗线属于本次明确没有改写的源外带，不能宣称 guard 已清除所有残影。

固定 4px 的 hardBG→unknown 是合理的下一次源诊断，需重新推理而非复制 raw alpha；原 FG、运动许可和请求应冻结。它仍可能纳入真实背景阴影，单张图的颜色不能排除这一解释。未来通用准入需要检验独立暗背景条保持，不能把所有近轮廓暗色一律搬走。

现有 guard tile 文件是最终写入结果，外环已恢复源 RGB，**不是模型原始预测**。新 alpha 若与外环 B=C 配对，会把旧暗线继续当背景，不能代替源范围纠正的验证。

本地独立数据：`/tmp/face-independent-20261119/guard-tile-admission.json`、`guard-source-observations.json`、`guard-left-old-edge.png`。未修改核心、未构建或推理模型。

## 后续光学边界配对实验独立复核

`optical-boundary-review-20261119` 将原非背景 trimap 支撑向外扩展 4 个源像素，仅把该带硬背景改为 unknown，重新运行 MEMatte；运动许可和几何仍固定。比较旧官方 alpha + guard B、新官方 alpha + guard B，以及新官方 alpha + 外环真实模型预测 B。原 paired alpha 的输出仅作另一个显示参照，不把它冒充完全同条件基线。

外环 B 来自同模型输入的扩写入目标捕获，采用有预测覆盖的 tile 权重；它是量化模型 RGB，并非浮点 raw tensor。内 32px 接受带保持先前 guard4 结果，未借本次实验重新调节该带。

独立逐项检查 ±30、±60 的原尺寸双耳、鬓发、两侧下颌、颈部及全幅结果：新配对在 +30/+60 下清除了此前明显分离的细暗轮廓，只更改 alpha 的对照仍有细线。未见新增开裂、白边或耳颈断接，脸宽变化保留。因此接受为 **614810 该样本旧轮廓污染的修复证据**，尚不等于通用瘦脸或全功能可用。

新旧 alpha 的最大差 `.601044` 出现在右下颈/衣领附近 `(659,798)`，不是脸颊细线位置。大于 `.1` 的主变化组件仅 23 像素，范围 `[656,789,664,804]`。独立核对更大的 `[650,778,669,822]` 区域，四个非零档位新配对成片都与源图逐 RGBA 一致；这说明当前运动许可没有将该处变化释放到成片，**不证明新 matte 在该处是真值**。

源 head 提议、trimap 及运动界面来自已冻结的自动源准备流程，没有人工描边。仍需验证该准备流程在不同照片和场景中的适配，单张柔和背景图上改善不证明不会把背景阴影误判为半透明前景。本轮没有根据这一结果授予额外运动许可。

另核对 `test/results/optical-boundary-static-line-20261119` 的冻结协议和对照：6px 原未知带完整包含真实软 alpha，外扩 4px 的 2,344 个像素真值均为背景，其中 190 像素落在独立静止暗线。两次固定推理中，扩展后暗线区域 alpha 最大 `4.71e-5`；采用真值背景和假设左移 8px 的场，静态背景最大误差 `0.00467` 个字节值，没有超过 1 个字节值的像素。该合成负对照没有触发背景误吸，但 alpha 总 MAE 从 `.001012` 小幅增到 `.001094`；它只支持这个简单构造下的局部安全，不能代替真实阴影的泛化验证或核心渲染验收。
