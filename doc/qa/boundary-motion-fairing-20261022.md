# 完整可见界面位移平滑实验

2026-10-22，离线算法候选。此记录覆盖目标生成、原 v3 的 ±100 实际 f32 场独立审计，以及 smooth12 +100 的同 profile 组合审计；照片观感仍需单独验收。没有美学评分，没有接入系统。

原来的颈部软零约束从 y565 附近开始，使回位集中在窄段，照片出现浅肩。新实验使用原图复核的 y515–610 完整可见前景 / 黑背景界面。界面可见与脸 / 颈解剖归属分开记录；未知归属保持未知。低段软零偏好的范围来自此前独立的颈部源复核，未扩展该语义。

## 保留的失败与路线区别

第一种控制器 `source_turn_preserving` 要求：冻结上段 preferred 运动、下端接回 preferred、整曲线平滑、低段软趋零，并保持源曲线有限弦转角的符号。左侧不可行：源弧长 s=12 px 的转角分子原为 −0.213818 px²，参考 +100 场已将其变为 +10.899146 px²，该窗口完整落在冻结上段。颈部修正无法改变此冲突。将上段改为积分与非零幅度锚点保留后，有限维候选仍未通过；未削弱请求或删约束后冒充原方案成功。

失败分别保存在 `test/results/semantic-deformation-20261022/user-jaw-whole-interface-qp-v3-plus100`、`user-jaw-whole-interface-qp-v4-plus100`、`user-jaw-whole-interface-qp-integral-v1-plus100` 与 `user-jaw-whole-interface-qp-integral-v2-plus100`。最早 v1/v2 因旋转坐标终点的浮点投影差提前拒绝；修复仅允许 1e−10 px 终点舍入并回贴源端点，失败记录也保留。

另立的新控制器为 **`gradient_bounded_motion_fairing`**，不声称保持源转角符号。其目标如下：

- 冻结 `user-jaw-equal-area-v1-plus100/plus100/inverse-field.npy` 的真实前向运动，沿 frame.across 提取 preferred；frame.down 方向位移固定为 0。被舍弃的参考 down 分量最大约 2.54e−9 px，仅数值量级。
- 对 preferred 的 PCHIP 位移叠加紧支撑三次样条修正，修正具备 C² 连续性。源折线、preferred 和最终 f32 场均不因此获得 C² 保证。
- 上段 y515–535 逐点保留，包含左侧最大 +1.492166 px、右侧最小 −1.287482 px 的真实非零运动；下端最后 8 px 弧长接回 preferred。
- 完整中间曲线共同最小化 preferred 偏离、位移二阶导能量和已复核低段的软零偏好。低段不硬固定。
- 位移限制在参考全局范围内；**一阶导数的有符号最小 / 最大值**也限制在 preferred 原范围内，避免把上段快速增长的幅度预算用作更快回位。连续分段多项式极值用于检查并增补约束。
- 源有限弦转角仅诊断。左侧已有 25 个违反源符号的被测极值，明确保留，不算作该新控制器的合格条件。

## 下一步直接约束上转折的建议

继续改变平滑权重不能保证上转折不恶化，因为当前全局一阶导区间只限制速度极值，不限制速度在局部怎样变化。可独立测试**相对已冻结参考的局部有限弦斜率差预算**，直接在完整可见界面上约束转折，保留 unknown 解剖归属。

设源弧长为 s，固定的 down 坐标为 V(s)，候选 across 坐标为 U(s)。在预先规定的多个窗口尺度 h（例如源弧长 8、16 px）定义：

`K_h(s) = [U(s+h)−U(s)]/[V(s+h)−V(s)] − [U(s)−U(s−h)]/[V(s)−V(s−h)]`。

由于 V 不变，K 对 spline 系数是线性的，可以加两侧硬界限。一个可审查的消融是令 `K_candidate−K_source` 限于 `0` 与 `K_reference−K_source` 之间：允许回到源几何，同时禁止在同一位置、同一尺度上放大参考已有的转折改变量。它保留 reference 本身为可行解，不会再出现“冻结了已有编辑，却要求其符号回到源曲线”的逻辑冲突；也没有宣称参考曲线或源代理一定美观。

这应作为独立的新控制器约束，不能暗中加入当前候选后改称旧结果成功。需在**最终 f32 实际前向界面**上复核相同预算，并保留原下颌强度 / 面积 / 执行门槛；目标层通过或点误差小不保证实际局部转角预算通过。若新约束迫使候选退回参考、或与其他请求冲突，应记录无改善 / 不可行，不能放宽强度换通过。本轮仅提出该约束，没有修改算法或运行此实验。
