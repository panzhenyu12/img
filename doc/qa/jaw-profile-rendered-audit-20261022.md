# 下颌曲线实际形变审计：等面积目标与颈部软约束

日期：2026-10-22。范围：离线算法实验；未接入 Web、Go、WASM 服务。

在相同原图、源轮廓、编辑量、固定掩膜、全像素求解基底与控制点间距下，v3 等面积曲线目标明显减少了 beta 目标在实际输出场中的反向弯折，同时保留约 99.97% 的请求面积变化。加入颈部软约束后，请求面积实现率仍超过 99.95%，但下颌曲线有小幅退化，+100 左侧新增 1 个低于 −0.1° 的窗口样本。因此本结果支持继续验证此路线，**不构成美观验收、严格凸性证明或 8 分评分依据**。

## 证据与方法

本次使用用户提供的 1024×1024 图片，图中带有“AI 创作”标记，不能作为独立相机照片的纹理真实性证据。源轮廓有 63 个点；规范化源几何 JSON 的 SHA-256 为 `283924cad7a18cd32e7b6c25c8d0824e1115bdb4b09b51fbe046d87ee67c91aa`。轮廓仍是源图代理标注，并非解剖学真值。

测量由 `experiments/semantic-deformation-20261022/audit_jaw_profile_field.py` 完成。每个目标位置通过反解**最终保存的 f32 逆映射**得到，避免只检查目标控制点而忽略求解与保存后的偏差。本次反解闭合误差约在 1e−10 px 量级，未使用坐标夹紧。

- 面积：沿原图闭合轮廓分别用最大 0.25 px 和 0.125 px 间距采样，保留原始顶点与 profile 的所有结点，再计算实际映射后的有向多边形面积。本文表格采用 0.125 px 结果，共 9757 个点。源多边形面积为负，因此 +100 的正面积增量表示绝对面积减小。
- 曲线：用源弧长 ±16 px 的弦窗口，每 0.03125 px 检查一次，仅统计冻结的“源图已知凸且纵向单调”的**开区间**。左侧 3213 个窗口，右侧 2584 个窗口。这些密集样本高度相关，不能当作独立统计观察。
- 小于 −1e−8 的有向分子用于计数反向弯折；−0.1° 是额外报告尺度，**不是美观合格线**。未知区间不被自动判为解剖异常，采样结果也不是连续域极值证明。

共同配置为 `field_reduction_stride=1`、`collocation_spacing=2 px`。两组比较均验证源几何、正负编辑量与固定掩膜字节相同。早期 `user-jaw-profile-field-audit-v1/plus100` 曾比较 stride 4 与 stride 1，存在混杂，保留作历史记录，**不作为本次正式改善证据**。

## 第一组：beta 目标与 v3 等面积目标

v3 控制器为 `equal-area-source-convex-window-qp-v3`。它保留连续 beta 的有向面积变化，重新分配沿下颌弧的位移；不要求与 beta 逐点位移相同。两种带符号 profile 的强度已经写入文件，运行时不再乘一次强度。

| 强度 | 侧别 | beta 实际最小转角 | v3 实际最小转角 | 反向窗口数 beta → v3 | 低于 −0.1° 的窗口 beta → v3 |
|---|---|---:|---:|---:|---:|
| +100 | 左 | −4.823334° | −0.089001° | 986 → 205 | 976 → 0 |
| +100 | 右 | −6.140357° | −0.033587° | 404 → 23 | 395 → 0 |
| −100 | 左 | −7.239202° | +0.032720° | 114 → 0 | 112 → 0 |
| −100 | 右 | −6.337135° | −0.042471° | 106 → 2 | 105 → 0 |

v3 的请求目标在这些已知窗口没有反向弯折，但实际 f32 场仍有小幅反向弯折。目标层约束并未精确传递为实际输出层的严格凸性。

| 强度 | v3 请求面积变化（px²） | beta 实际变化（px²） | v3 实际变化（px²） | v3 实际 / 请求 |
|---|---:|---:|---:|---:|
| +100 | +695.473233 | +695.240900 | +695.275544 | 99.971575% |
| −100 | −695.473233 | −695.267311 | −695.266737 | 99.970309% |

连续 beta 的采样请求为 ±695.473166 px²，与 v3 的请求相差约 0.000066 px²，来自面积积分离散化。此次弯折改善不是通过大幅削弱整体编辑面积取得的；但相同面积也不能证明所有局部形状自然。

正式输入与结果均位于 `test/results/semantic-deformation-20261022/`：

| 项目 | 路径 |
|---|---|
| beta 基线 | `user-jaw-continuous-fullbasis-v1/{plus100,minus100}` |
| v3 +100 | `user-jaw-equal-area-v1-plus100/plus100` |
| v3 −100 | `user-jaw-equal-area-v1-minus100/minus100` |
| signed profile | `jaw-equal-area-probe-v3/{plus100,minus100}-continuous-area-profile.json` |
| 正式独立审计 | `user-jaw-profile-field-audit-v2/{plus100,minus100}/report.json` |

## 第二组：同一 v3 目标，不加 / 加颈部软约束

这次比较额外验证两边 profile 字节完全相同。源控制来自 `user-jaw-source-v1/neck-boundary-review-v1/source-constraint.json`，只包含原图 y=565…610 的左右两条可见颈部 / 黑背景界面，分别采样。y≈530…555 的未知脸颈过渡未被擅自延伸成约束。

每条源边界的不确定带为 ±2 px。这是人工查看给出的检查范围，不是校准后的统计置信区间。当前软项只约束中心线，使用 2 px 间距、密度 0.05、端部淡入长度 16 px 的弧长积分权重；左右各 35 个样本，总权重 3.086828346。源目标保持原位，权重为软惩罚，因此并不保证中心线完全不动。

| 强度 | 同一请求变化（px²） | 无软项实际（px²） | 加软项实际（px²） | 加软项实际 / 请求 |
|---|---:|---:|---:|---:|
| +100 | +695.473233 | +695.275544 | +695.207853 | 99.961842% |
| −100 | −695.473233 | −695.266737 | −695.162546 | 99.955327% |

软项使编辑面积幅度额外减少 0.067692 / 0.104191 px²，分别约占请求编辑量的 0.0097% / 0.0150%。这是小而可测的代价，不能表述为零损失。

面积采样从 0.25 px 加密到 0.125 px 的变化如下，用于说明近似敏感度：

| 强度 | 无软项（px²） | 加软项（px²） |
|---|---:|---:|
| +100 | 695.276707 → 695.275544 | 695.208854 → 695.207853 |
| −100 | −695.266508 → −695.266737 | −695.162313 → −695.162546 |

| 强度 | 侧别 | 无软项实际最小转角 | 加软项实际最小转角 | 反向窗口 无 → 有 | 低于 −0.1° 的窗口 无 → 有 |
|---|---|---:|---:|---:|---:|
| +100 | 左 | −0.089001° | −0.100746° | 205 → 224 | 0 → 1 |
| +100 | 右 | −0.033587° | −0.042188° | 23 → 26 | 0 → 0 |
| −100 | 左 | +0.032720° | +0.017901° | 0 → 0 | 0 → 0 |
| −100 | 右 | −0.042471° | −0.051860° | 2 → 2 | 0 → 0 |

**+100 左侧的退化必须保留。** 密集窗口位置的实际 / 目标最大距离依次为：+100 左 0.029132 → 0.029984 px、右 0.068186 → 0.069203 px；−100 左 0.020031 → 0.022327 px、右 0.019947 → 0.019100 px。

runner 自身的独立 0.5 px 弧长探针使用另一组采样位置，得到 +100 最大误差 0.059538 px、最小有效增益 0.984920；−100 最大误差 0.021745 px、最小有效增益 0.971322。这些数值不能与上面的密集窗口最大距离混为同一个指标。两个方向的固定保护区域变更像素数均为 0。

70 个颈部软控制样本的实际位移：+100 最大 1.316735 px、平均 0.076647 px；−100 最大 1.163184 px、平均 0.071251 px。它们说明软中心线仍会运动，**没有测量整个 ±2 px 不确定带，也不能证明肩颈完全固定或视觉接缝消失**。本审计没有另算无软项的颈部残差，因而不据此声称颈部改善幅度。

## runner 与源绑定复核

本次对 `run_portable_jaw.py` 的独立检查确认：

1. profile 请求、求解控制点和独立探针都使用同一带符号 profile；源图、检测缓存、源证明与源复核必须匹配 profile 冻结的源协议。
2. 软边界要求 `reviewed-source-neck-boundary-candidate-v1` schema、匹配的源图 SHA 与尺寸、明确的离线复核状态和 `automatic_edit_authorized=false`，并验证全部输入文件哈希。源图 SHA 为 `5f15e92b14c44a468d924af5ac985a7cc7dc1c87d8ab235f2c94b2e88b173c73`。
3. 软边界源点、原位目标与权重在 `build_problem` 之前加入联合求解。原下颌源点、目标、权重、编辑量与既有数值门槛保持一致；没有对求解后的位移场另做 taper，也没有输出像素补丁。
4. 源可见性仍为 `unknown`，没有因离线人工检查而升级为自动编辑授权。profile 保留源图及 JSON 证据绑定，不把可变的历史 Python 源码哈希当成重放必要条件。实际执行代码由本地快照保存。

实现文件：`jaw_target_profile.py`、`source_boundary_soft_targets.py`、`audit_jaw_profile_field.py`，均在 `experiments/semantic-deformation-20261022/`。先前已完成的聚焦测试包括 profile 4 项（含源内容变更拒绝）、软边界采样 4 项、分辨率迁移 10 项及源边界支持 3 项；此次补写记录未重跑全系统构建。

## 尚不能宣称完成的部分

目前可以确认目标曲线导致的较大反向弯折得到显著压低，且没有靠大幅削弱请求面积获取指标改善。仍需根据原图与实际输出检查脸颈衔接、下颌局部曲率、纹理和不确定带；同时需要在其他脸型、真实照片及未参与调参的样本上验证。软项带来的微小曲线退化也应参与下一步取舍。

不能将“请求凸性满足”“f32 场数值检查通过”“固定区像素不变”分别等同于“脸型自然”“视觉无缝”“所有背景完全不受影响”。本报告不作美学评分，`beauty_approval=false`。

照片、数组、图像输出与本地冻结运行结果仅作离线证据，不纳入代码提交。
