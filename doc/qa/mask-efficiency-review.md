# 蒙版与图层合成的等价优化

日期：2026-10-13。该实验仅比较mask.rs优化；皮肤、脸部、身体其他模块在两个源码快照中完全相同，不混用后续算法改动。四项1024px实拍graph回放的输出RGBA逐字节相同，热运行总图处理时间下降约23%–64%。这支持优化的等价性和收益方向，不构成全功能效率达到8分。

改动把矩形/椭圆/渐变等JSON几何预编译一次；正常混合中原始/编辑RGBA完全相同的像素跳过蒙版求值；不在ROI或opacity为0的像素直接保持原图。非normal混合仍执行颜色公式，不能因输入相同就跳过multiply等效果。没有减少参数幅度、代理图尺寸或去掉保护。

|1024px图像/参数|旧热中值ms|新热中值ms|输出差异通道数|
|---|---:|---:|---:|
|带妆人像美白60|487.64|194.68|0|
|带妆人像强磨皮100/0|938.08|458.62|0|
|深肤色人像美白60|450.08|162.36|0|
|发丝遮挡人像强磨皮100/0|641.97|495.28|0|

计时排除PNG读写/模型检测，包含graph解析、验证、编辑、最终合成；每项记录首次和5次热运行，交替before/after进程顺序。机器仍存在并行编译/模型实验负载，不按最短一次时间打效率分。输出来自只读用途独立binary，每次子进程前后及全程末尾校SHA。原始采样及图/源码版本见 [JSON](mask-efficiency.json)，输出留在test/results/mask-efficiency。

编译蒙版与原标量参考的回归逐像素核对10种形状/格式，含默认矩形、kind别名、零宽高、凹多边形、raster软alpha、线性/径向、反选、羽化、画笔擦除与补画。新增回归验证透明图normal不变、multiply不能误跳过、ROI外和opacity0保持原图。6项mask单测通过；跨WASM/native和生产graph的统一核查另外记入current-validation。

复现：用相同其他模块的两份源码快照构建examples/graph_quality_bench，运行 `python scripts/check_mask_efficiency.py --before /绝对路径/before --after /绝对路径/after`。不要用不同skin版本的binary替代本实验。
