# 2026-10-15 核心算法推进与实际验收

**整体瘦脸仍未达到 8 分，尚不能恢复现行评分。** 本轮将几何、源像素归属、颜色分解、隐藏纹理和遮挡前后关系分别验证。正负方向任一出现明显黑线、阶梯或错接，都不以其他样片成功抵消。

## 已更新本地服务的改动

源物理 alpha 连通边缘漏点修复已进入 Rust native/WASM。用户原照旧轮廓的 12 个肤色残点得到修复；三原片十五档回放，以及九档真实网页/Go/native/WASM 逐像素对账通过。生产为 v19 + physical-fringe-v2，详见 [接入证据](physical-fringe-v2-integration-20261015/review.md)。这项修复没有解决整体脸型审美、饰品误分和颈部自然度。

唇明亮 V2 已接入 `color.rs` 并更新本地 native/WASM：黑唇纹不再被加白，原红/棕材料的通道比例更稳定，饱和红唇可压暗。五张独立原照55组、等亮度对照和独立审查完成；完整Rust 209+10+5通过、3忽略，浏览器/API五档逐RGBA一致，HTTP返回WASM与新产物哈希一致。强负向唇缘/牙齿边界仍失败，不提高整体妆容评分。见[图像评审](lip-lighting-v2-20261015/review.md)与[生产接入](lip-lighting-v2-integration-20261015/review.md)。首次误用同一二进制的A/B结论已明确撤回，保留无效证据以便追溯。

## 新完成的隔离算法

| 改动 | 可验证的收益 | 尚未解决的限制 |
| --- | --- | --- |
| 源轮廓约束与唇周附着 Geometry V2 | 嘴角暗线/尖角改善，四原照五档共20组；在同实际瘦脸位移下收益仍成立，新增回归旧算法消融失败 | 整体 V36 仍有白边、棕带、耳下旧皮肤岛；此嘴角问题未在生产路径复现，不直接移植 |
| ZIM 正确联合提示与组件选择 | 实际负点标签进入 ONNX；三开发原照30组、三额外原照50组对照；修正部分整脸被识别成头发的结果。组件选择改用被提示组件的源核心作分母后，深肤卷发全图核心覆盖由85.23%提升到96.36%（同一批原始推理） | 旧卷发损失部分来自错误拒绝小组件，不能全部归因于模型。检测概率不是物理 alpha；饰品参考存在缺失，不能宣称所有部位识别完毕 |
| 源 hair/skin 颜色分解 | 对源混色边缘分别估计颜色与 alpha，能减少原先固定在旧位置的肤色亮线 | 严格源重建通过不保证编辑后遮挡正确；用户短发样片本轮该项写入为0，不能冒称修复了其耳饰 |
| 独立背景层局部补全 | 在保留已运输皮肤的前提下，原尺寸256/512上下文比整块缩小推理接出更多发丝 | 仍有平暗条带、色差与边缘细线；仅该背景实验不能获得整图8分 |
| 显式遮挡 A/B 对照 | 相同几何/颜色下，让新皮肤遮住后方头发能消除部分外扩黑线，证明“固定所有头发可见性”也是缺陷来源 | 当前是已标明的前后层假设，自动识别未知；不能用人工选对假设冒充全自动修复 |

## 关键证据和归因

- [唇周几何审计](../../experiments/face-attachment-geometry-v1-20261015/qa/review.md)：208个单测、10个公共图操作合约；固定旧算法消融失败。woman 同幅度对照左侧峰值差0.000214px，不能将收益解释为简单降低滑块强度。此为隔离核心测试数量，与生产209+10分别记录。
- [ZIM 调用修正](../../experiments/zim-combined-prompts-20261015/README.md)：旧 mixed 六次原始 float alpha 完全复现；3项适配器feed合同通过。[额外原照复核](zim-semantic-holdout-20261015.md) 保存真实ONNX输入和软alpha幽影；[组件分母纠正](zim-component-aware-20261015.md) 保留旧拒绝结果与新对照，50组中18组由拒绝变为可选择，30组开发原照选择不变。合并alpha只作为审计图，不是已验收的物理matte。
- [独立背景上下文](face-background-context-20261015.md)：完整 V36 重合成0差异；所有候选圈外、固定区域与输出alpha0额外变化。高并发 CPU 推理时间不能宣传为浏览器实时性能。
- 颜色分解、遮挡与其测试/失败见 `experiments/hair-skin-decomposition-v1-20261015/`；实验用精确冻结逆映射，未对输出图片重检测。
- [遮挡独立审计](face-occlusion-independent-review-20261015.md) 复核9组18张输出。独立6像素反例发现并修正了unknown覆盖从边缘写入路径绕过拒绝的问题；修补后90张PNG逐字节不变。用户原照两向仍为零写入，耳饰不算已修复。
- [耳饰实际变形独立审计](user-accessory-independent-review-20261015.md)：首轮8组保持金属核心、1016个高光像素和内部皮肤，但+100新增碎边/双轮廓，拒绝；正在将源条清除、目的皮肤运输和背景证据放在同一合成域核对。
- [背景混色边与纹理留出](../../experiments/face-background-prior-v1-20261015/README.md)：固定前景/alpha下，让背景重建接管旧混色边能减少部分旧橙线，但反射虚拟上下文在3块已知原图纹理上全部劣于未知半面LaMa，拒绝上线。软耳/饰品写域缺口已修补，旧失败保留；不以少一条线替代纹理验收。
- [alpha 上限因果审计](alpha-cap-causal-20261015.md)：取消当前±0.15限制虽然把源拟合误差 .438 降至 .172，但旧橙线仍在；已知细发反例的真实 alpha 被错误降级，换背景误差 33.87→43.67 byte，因此拒绝取消上限，不能用较低 source residual 冒充质量提升。
- [耳饰局部高分辨率 ZIM](zim-accessory-crop-resolution-20261015.md)：自动组件框的2×/4×局部编码共4次 encoder、8次 decoder、32个候选。仅组件2的4× combined-point显示较稳定的候选变化（unknown 642→500、源皮肤支持81不变、金属尾部最小alpha .960→.980）；组件1的4×方案虽减少unknown，却把金属尾部最小alpha .953降到 .885，拒绝。两组件均未形成已验收最终图，待同一source/遮挡合成后再决定，当前不接生产。

联合提示接口修正**只影响相应 ZIM 实验路径**，不能用它解释尚未消费新 alpha 的 V36 输出已经修好。2026-10-14 最早的互斥 box/points 实验不受组合覆盖问题影响，其耳朵负例仍保留。

## 当前代码和产品状态

### 本轮追加实证

- direct skin原图提示已修正牙齿误作背景负点的问题，三原片各0、±30、±100完成native回放。耳侧漏皮肤有所改善，但woman有宽肤色带、hair和用户图有硬接缝；没有将raw包含的耳朵全部当成可动皮肤。详见[实验完整账](../../experiments/joint-skin-matting-v1-20261015/README.md)。
- [V37](../../experiments/face-direct-physical-v37-20261015/README.md)在相同几何下分离物理alpha和合成公式。残差合成消除了低alpha造成的远背景重涂，六组整个ROI变化上界通过；原图旧边和错误露底仍未通过。
- 精确native层追踪证明用户耳下灰银条主要来自背景B混入旧皮肤/饰品。固定F、alpha、原位移，只替换有原图依据的局部B，灰银条明显消失；下端矩形边界与细线仍未消失。[B-only及限制](alpha-feasibility-skin-20261015.md)保存0、±100两组对照，未部署。
- [V39生产副本](../../experiments/face-source-residual-v39-20261015/README.md)虽然解决微小滑杆导致7byte跳色的公开接口反例，三原片十五档实图仍暴露旧橙线；两名评审拒绝合入。209单测及10公共合同通过不是画质结论。
- [耳部V8](ear-accessory-attachment-v1-20261015.md)补齐了真实耳垂材料，释放旧全耳固定后实际位移恢复，但耳脸接缝仍约2–5px错位。整条非刚性界面不能靠单点刚体耳旋转匹配；停止堆mask门槛，转向[共享接缝设计](../research/ear-shared-interface-design-20261015.md)。
- [SAM2Matting Tiny实测](../../experiments/sam2matting-tiny-probe-20261015/README.md)在三张图出现高置信额头缺失/半透明孔洞，不接受直接替换。CPU约7.6–9.3秒/图、峰值约2.92GB是该环境测试，不能宣传为浏览器实时。
- 新用户需求加入[整体脸型与可选模式](../func/FUNC-024-whole-face-shape.md)。已核对像素蛋糕官方手册区分瘦脸、小脸、短脸、脸宽与七种组合预设；原型仅验证整体宽度曲线，仍受当前合成缺陷约束。
- 整体宽度V1虽通过几何/协议检查，实图上中脸实际位移近零，拒绝作为整体瘦脸交付。V2把本人头部及相连颈部放入同一速度场后，用户 +30 上脸实际约5.19/4.99px、中脸约4.83/4.80px，恢复了原本被固定规则抵消的目标；±30原尺寸仍见外耳双轮廓，未通过审美与边缘验收。
- 完整桌面手册92个URL、83份不同正文已核对，形成[84组功能—算法映射](../research/pixelcake-manual-functional-audit-20261015.md)；它是后续开发对账依据，不增加当前完成项。独立审查继续核对官方参数方向、实际蒙版范围及公共接口边界。
- V2独立实例审查构造同框两人头发相连反例，最终一致输入中另一头±100误改645/650px（早期输入644/649另存），单纯连通判别不足；±30耳环还有约8%的横向拉伸/压缩。以上均为阻止接入的失败项。
- [头部残差运输实验](../../experiments/head-transported-residual-v1-20261015/README.md)保持V2几何/alpha不变，原尺寸左耳双边明显减弱；但2000余源像素的预乘颜色超物理范围，不能无条件采用。该实验已用实际trace精确复现V2，并保存两个已知层反例；下一步核查源已知颜色和物理覆盖，未改生产。
