# 2026-10-15 物理边缘残点修复接入

**本地服务已更新，仅接入物理 alpha 漏点修复；整体瘦脸自然度尚未达到 8 分。** 共享 Rust 的 face.rs / face_matting.rs 已应用经过独立审查的最小补丁，没有接入未通过的 V31–V36 形状实验或眼部候选。

源图原轮廓上的肤色点在收缩后本应成为背景。旧语义 mask 将它们当作零 alpha，既在旧位置留下悬空肤色，也可能在新边缘产生暗点。新实现利用原人物观测、连通皮肤/颈部证据、邻近可观测前后景颜色恢复局部物理 alpha，并排除固定类、其他人物及显式保护。

用户原图 +100 的 12 个旧肤色点全部移除。零值、原图、滑杆数值与几何流场未改变。三张独立原图各 0/±30/±100 共 15 档已审阅；最终干净候选与审阅产物全 RGBA 一致。关闭颜色连续性恢复后，已知 alpha 真值测试在 `physical opacity at 12,9: 0 != 1` 明确失败，完整实现通过。
