# 保留源下颌弯转：目标与实际成片对照

2026-10-23。新增固定 `rho=0.5` 的隔离算法候选，三图双向均生成实际成片。一个明确被压平的位置恢复了弯转，但整脸目视差异仍小；实际场尚未严格满足全部新约束，**不替换默认、不提高美学评分**。

## 原因与单变量实验

第三图dark的右侧源弧 `s=65.041663px` 附近，原有限弦转角约7.538°，宽平台偏好约7.423°，约束求解后的目标约0°。上方两个窗口的偏好确实产生反向弯转；旧QP在消除它们时，把后方正常凸曲线压平。这里的源弯转不是近零，不能直接归咎于检测噪声。左右独立弧长造成的平台高度差约4.25px，也不能单独解释最终约15.80px的目标位移峰高差。

`probe_jaw_retained_bend.py` 在相同plateau偏好、双侧权重1、平滑长度（user12/man4/dark4）下，只增加已知源凸、下向单调窗口的限制：

`N_target >= 0.5 * N_source`，其中 `N = side * (dx_second*dy_first - dx_first*dy_second)`，单位px²。

这是有限弦分子下限，**不是保留一半转角或一半曲率**。0.5为预声明工程假设，不是论文认证的最优值。原总beta³有向面积、源轮廓、端点、符号、unknown域及全部旧阈值保留，禁止降低请求换取通过。连续检查对完整差值 `N_target−0.5*N_source` 的分段二次式求极小值，包含它自身的内部极值；不能只检查旧目标分子的极小点。

## 结果与限制

六个目标全部通过原数值门槛及新增连续margin检查，最大面积误差3.41e−13px²。四项聚焦行为测试通过：同偏好的旧反例、原面积和源弯转、unknown尾、刚体/插点一致性、零值；独立三点抛物线审计自检1项通过。只运行这些相关检查，没有重复系统构建或旧大套件。

沿用同一个源场求解器、固定支持、stride1、collocation2和双线性采样，六组成片均通过原执行与最终f32几何检查，全部固定像素变化0。独立审计使用原16px半弦、0.03125px中心采样和原−1e−8px²容差：

“反转”检查N本身，“margin”检查N−0.5*N_source；二者不同。目标曲线通过不能冒充实际场通过。审计重新计算源/目标分子，实际分子来自已冻结的独立f32场反解缓存，绑定照片、场、协议与profile哈希。它是密集采样，不是实际场连续极值证明。

dark原压平位置最近采样 `s=65.046875`：源角7.5408°，旧实际0.0875°，新实际3.7909°，新实际margin为+0.3388px²，确认改善不只存在于目标文件。该图另有11个实际反转样本：最差源角+0.0040°、目标+0.0072°、实际−0.1789°。反解closure不足1e−10px，不能将这个差异解释为反解迭代误差，也没有修改阈值使其通过。

约束会重新分配同一面积：user+左右**目标**位移峰高差从0.216增至22.952px；这不是自动的审美失败或成功。user左非单调尾最大目标运动从.3304增至.3609px，未冻结unknown。man+与dark+在嘴高前15%源弧中的面积分别增加12.2853/7.3768px²；unknown-center区域面积占比分别13.4762%→15.1552%、14.1964%→14.7533%。这些区域可能重叠，不能相加冒充独立分区。

## 实际目视与后续方向

主代理和独立代理均查看三图正负成片、整脸及放大下颌。没有看到明确新增裂口、双边、凹陷、左右突变或附件损坏。user正向下巴两翼稍少直线感的印象较弱，尚不足以判定稳定美观收益；其他对照大多难以可靠区分。外颈联动仍在，胡须细节也未因目标约束自动改善。

保留该候选用于源形状控制研究。下一问题是下颌目标与可见外颈界面的协调：已审查的两条源曲线没有共享端点，不能人为拼成解剖连接；研究让它们共同约束同一个源空间位移场，避免先冻结下颌、再把颈部拉回造成浅肩。源角色与未知区继续保留，不把这项后续方向写成已经修复。
