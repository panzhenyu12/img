# 区域脸型控制器的独立视觉复核

日期：2026-10-22。结论：**区域目标使嘴侧相对更饱满，变化在并排对照中可见；相对匹配面积的整体缩窄，尚无明确自然度胜出。** 本记录不作8分判断，也不把比例指标变好等同于更美观。

## 查看对象与限制

实际查看了以下成图，而非仅阅读指标：

- `test/results/semantic-deformation-20261022/regional-comparison-v1/hair-plus60/{face,full}.png`：原图、旧整体+60、匹配目标面积的整体缩窄、新区域+60四栏。
- 同目录 `woman-plus60/{face,full}.png`：相同四种对照。
- 同目录 `hair-minus60/{face,full}.png`：原图、旧整体−60、新区域−60三栏，没有匹配面积的负档对照。
- 另逐一查看了两个正档区域结果、匹配面积结果及旧强档结果的原有 `face.png`。

四栏脸部图使用相同源图坐标裁剪。完整hair正档面板在工具显示时从2352×796缩小至2048×693；细部判断以未缩小的脸部面板为主。未对任何图进行额外锐化或改变像素。

这是一个模型评审者在已知列标题情况下的定性观察，不是人类盲评、专家共识或独立新样本验证。两张正脸都已经参与前期调试，不能称为独立测试集；表情和遮挡范围也有限。

## 指标与视觉结论分开

随后核对四栏图的 `report.json`：

| 指标：区域减匹配面积整体 | hair +60 | woman +60 |
| --- | ---: | ---: |
| 实际嘴高度脸宽差 | +3.226像素 | +3.317像素 |
| 实际嘴/脸宽比例差 | −0.01408 | −0.01421 |
| 实际轮廓面积差 | +14.414像素² | +0.183像素² |

两者的请求轮廓面积在浮点误差内匹配，但求解后的实际面积并非严格相同；据当前报告，hair面积差约占实际面积0.045%，woman约0.0006%。这是较接近编辑量的对照，不应表述为实际输出面积完全一致。

上述比例来自既有二维源语义多边形与轮廓截面，不是解剖真值或审美标准。它们支持“新目标确实重新分配了脸宽”的结论，不能证明“嘴/脸比越低越好”。

## 建议

保留区域控制器作为明确的新形状选项及后续实验候选，暂不替换原整体脸宽。当前已经有可见、可量化的形状差异，但还没有足够证据认定区域版本在自然度上胜出。继续验证时应优先采用未参与调参的不同脸型/表情，并以相近实际编辑量作对照；若只在已调试样本上让某一比例更接近原图，仍不足以升级质量评分。
