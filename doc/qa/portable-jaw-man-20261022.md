# 第二张实拍下颌：可迁移源场视觉复核

日期：2026-10-22。结论：**带眼镜和胡须的第二张实拍中，局部下颌正反向与满档均产生可辨形状变化，当前显示尺度未见新增裂缝；移动区纹理仍有采样变柔。不能据此给整套人像算法8分。**

## 观察范围

实际查看 `test/results/semantic-deformation-20261022/man-jaw-portable-v1/` 与 `man-jaw-portable-stress100-v1/` 的 `face.png`、`full.png`，以及从各自原始成片裁剪、最近邻放大3倍的 `jaw-detail-3x.png`；另看±60的 `mouth-detail-3x.png`。图列为原图、内收、外扩。不是盲评，评审者是模型。

首轮源为512×768的浏览器解码／缩放复现。其历史保存裁剪已逐字节复现；没有凭空恢复一份未保存的完整历史源图。本轮保持原样133点源边界，使用该图自身嘴高与颏投影，未将其他照片的128点轮廓套入。此前此图已有其他算法试验，因此不是完全未见过的研究留出集。

## 固定几何后的采样对照

进一步实际查看 `man-jaw-sampling-v1/plus100` 与 `minus100` 的 `face.png`、`jaw.png`。三列依次为原图、同一逆场双线性、同一逆场有界Lanczos3。两方向中，有界Lanczos3保留了稍多的胡须颗粒、下唇下方与下颌皮肤细纹；放大的下颌图比完整脸部更容易看出差别。未见明显新增亮晕、彩边或局部硬接缝。

改善幅度有限，源细节没有完全复原，脸型自然度也没有因采样器改变而重新验收。这里仅支持在该图固定几何条件下继续验证该重采样候选，不能将高频看起来更清楚写成真实毛孔生成或全分辨率保真。

## 原始1280×1920成片复核

随后实际查看 `man-jaw-portable-fullres-v1/face.png`、`full.png` 和 `man-jaw-sampling-fullres-v1/{plus100,minus100}/face.png`、`jaw.png`。宽版对照显示时会缩小，因此另从原始成片生成 `plus100/minus100-jaw-native.png`（逐像素尺度）及 `plus100/minus100-left-detail.png`（最近邻2倍），重点看嘴侧、左下颌、胡须与颈部。

- +100的两侧弧明显内收，形状偏V；原图本身已有偏尖下颌，满档会进一步强化这一倾向。未看到突发折线、局部凹槽或中央尖刺，但不把强收窄认定为审美改进。
- −100下半脸更宽饱满，未见单独鼓包、裂口或胡须／颈皮肤之间的横向断层。嘴形、眼镜和上脸没有明显改变；墙面柔和阴影未见新硬折角。
- 原始像素尺度中，双线性仍稍弱化移动区细胡须和皮肤／噪声颗粒；有界Lanczos3稍清楚，2倍局部也未见明显新增彩边或亮晕。锐一些同时会保留噪声，不称为毛孔或毛发结构恢复。
- 将原生成片缩小到同显示尺寸，仅为对照形状而生成的 `plus100/minus100-scale-visual.png`，与512阶段的收窄／外扩方向和下颌轮廓观感接近，未见分辨率升高后突然变形范围扩大或脸颈分离。缩小图不用于细节评价，也不构成两个网格数值等价的证明。

这次原始分辨率验证仍是同一张照片，使用512检测结果的归一化坐标迁移，未重新检测。133边界下缘经过胡须纹理内部，而非直接可见的物理胡须／颈分界；连续场没有沿其切alpha，故当前“没看到接缝”不证明语义边界精确。报告中的固定像素和几何通过另行记录，不用微小残差代替美观判断。

## 后续算法重点

支持继续保留这一独立局部下颌候选及固定几何后的采样候选。原始分辨率本图检查已完成，下一步仍需不同脸型、角度与跨下颌遮挡核验目标弧和连接。整体瘦脸、其他五官及身形功能不能继承本项结论。

## 共享形变场后的补充复核

实际查看 `man-jaw-shared-resolution-v2/{plus100,minus100}/face.png`，及从原生成片裁出的两侧 `left-mouth-3x.png`、`right-mouth-3x.png`。图中比较原生源图、原生独立求解成片和共享预览场直接采样原生源图。两方向嘴高附近、胡须与下颌外侧均未见因保护区域并集而新增的窄带折角、硬接缝或局部鼓包；完整脸部曲线观感与此前接近。原生独立列用双线性，共享场列用有界Lanczos3，因此这些局部图不作为仅改变几何或仅改变采样器的单变量质量证明。

视觉复核后核对该v2报告：原生固定区域的逆场最大位移为0，相关固定像素合同与目视分开保留。该结论仅属于v2，不能用“看不出变化”替代早期共享场版本的固定区域数值失败，也不构成审美验收。
