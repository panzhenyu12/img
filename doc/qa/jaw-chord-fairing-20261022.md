# 下颌多尺度弦预算实验：实际场审计

实验批次 2026-10-22；本节为 2026-10-23 的独立实际场补审。实现说明与总体结论由主任务另行补充。

## 实际场审计结论

**+100 候选通过原有目标执行检查，但未严格满足新弦预算。** 在左右完整可见界面的 r=4 / 8 / 16 px 源弧长窗口上，最终 f32 场共有 4 个侧别 / 尺度组合出现预算超额，最大已测超额 0.0151443 px²。目标 spline 的预算通过不能替代最终渲染场的预算验证。

下颌整体编辑面积仍实现请求的 99.968007%，原已知下颌窗口仅有小幅几何变化。以下结果不含美学评分，也不声称照片无接缝、所有源转角保持或算法达到 8 分。

## 完整界面的实际 source-relative numerator

新增独立审计器为 `experiments/semantic-deformation-20261022/audit_interface_chord_field.py`。沿冻结源界面弧长，对每个中心 s 取 s−r、s、s+r 三点；r 分别为 4、8、16 px。将原始及实际三点投影到同一 across / down 坐标系，计算：

`N = (x₂−x₁)(y₁−y₀) − (x₁−x₀)(y₂−y₁)`；`D = N_actual − N_source`。

D 的单位为 px²，**不是转角角度或曲率**。当前目标预算为每个尺度的**全局有符号区间**，不限制每个源位置相对 reference 的增量，不能将它描述成逐点保形约束。

每个尺度使用两档最大中心间距 0.03125 / 0.015625 px，并纳入所有平移后的源折线 / spline 分段结点。表中为较密网格的实际范围。检测容差 1e−7 px² 仅用于排除浮点舍入，不是美学容差。

上述四个超额的最大值在两档采样中一致；较密网格对应超额样本数为 11、26、2、33。这些样本相关性很高，计数不能作为独立统计次数，也不应直接跨网格比较。

请求 spline 在相同采样中未出现大于 1e−7 px² 的超额（左 r8 有约 2.16e−9 px² 的舍入差）。因此本次观察明确区分了“目标预算通过”与“最终 f32 实际预算超出”。源 down 方向最大残余运动为 2.41e−9 px；用实际二维三点计算 D 与使用源高度、仅投影 across 运动的公式最大差为 2.84e−8 px²，远小于上述超额。超额不能归因于轴向舍入。

原 smooth12 基线实际场自身也不必落在 preferred PCHIP 预算内：右 r4 高端超出 0.001956162 px²、右 r8 高端超出 0.000319520 px²、右 r16 低端超出 0.020517089 px²。新候选减少了这三项中的超额幅度，但新增了左 r4 / r8 的超额。不能因为参考字段被用于生成预算，就假定其实际像素场天然严格满足该预算。

## 解释边界与后续验证

执行点误差小不等于有限弦预算严格通过：D 汇集三个点的误差，并乘以弦的高度差。当前目标预算有饱和位置，场拟合 / 重采样产生的小偏差仍能越界。应将此次实际场超额保留为未完成项，不能放宽描述或用目标报告替代。

本次是密集数值采样。已发现的超额足以否定严格满足预算；没有检出的两项仍不构成连续域全局证明。采样最大超额也是连续最大超额的下界。两个审计目录均保留执行源码快照，数组和图像留在本地，未写入功能代码或系统构建。

## 审计器历史输入校验修复

独立 `audit_interface_chord_field.py` 已改为同时检查每份 protocol 的 `inputs_sha256` 中记录的历史 profile 摘要、当前 profile 文件内容和 artifact 的 profile 摘要。仅“当前路径相同、当前文件摘要与 artifact 一致”不能证明与历史场使用同一目标。

新增 3 项轻量回归通过：原内容接受；同路径 profile 改写且 artifact 也换成新摘要时拒绝；缺失历史摘要时拒绝。既有 +100 的历史摘要也单独复核通过，未重跑其实际场审计。此次只修改独立审计器和测试，未修改核心算法。
