# 身形共享几何场独立复核（2026-11-19）

结论：可以收录本次确定的几何去裂修复，但不能据此判定身形整体可用或达到 8 分。原图 `fashion-standing` 的 ±30 已有明确收放腰响应，原右腋白色尖条消失；左前袖下方仍有局部轮廓台阶，+60 更明显，+100 因翻折被拒绝。

## 代码与行为

只读核对 `body.rs`、`body_source_layers.rs` 和 `tests/body_layered_adjust.rs`。单一径向场外尾使用随位移幅度增长的 Hermite 支撑，消除了在真实衣物内部直接返回零位移的旧硬截止。独立发现的 `legs=100`、`thighs=100` 同轴双场反例已通过求逆前合并目标修复；相反请求精确相消，组合收窄仍有预期幅度，没有把无翻折做成无效果。

共享场覆盖默认、单层和双层渲染路径。固定边界采用局部位移预算，未保留曾抹掉窄腿响应的全局选区淡出。双线性单元的 Jacobian 行列式在单元内为仿射函数，四角检查可检出该单元内部的翻折；这不等于全局美观、低纹理失真或所有组合可执行。不同轴与约束组合仍可能返回拒绝。

本轮没有重复构建；实现 agent 报告 41 项既有 body 单元、6 项新 API 和 9 项合成测试通过，视觉复核使用实际 API 成片。

## 剩余折角的因果定位

原 graph 的 +30 左侧约 `(172,437)`、+60 约 `(174,431)` 出现短平台。源 rear-alpha 在相应高度是平滑斜边，相关位置 front-alpha=0；运输后的 rear-alpha 已有平台，因此不能归因于固定前袖显露了一个原有隐藏尖角。

在 +30 的可见边缘，y435/x171 的位移为零，y437/x172 为 `(-.162,.009)`，y440/x178 为 `(-5.108,.294)`。这些位于真实衬衫外缘的点，原 `subjectMask=1`、`partMask=0`、`protectMask=0`：几何部位范围漏掉了可见材料，使材料边缘穿过几何外尾退场段。

已有的独立 `manual-rear` 源几何对照保持算法及所有源光学层不变，+30 的该平台消失，y470 主腰宽与原 graph 只差约 .03px。这支持 **几何语义轮廓与真实材料边界不一致** 的解释，不能把问题只归于局部 cap，也不能靠继续增加尾宽作为最终方案。

下一步应修正可见衣物边缘的几何证据与支撑，保持运动许可独立。人工源多边形只能作诊断对照，不能当作自动流程已通过。当前收录建议是“确定性去裂修复”，而不是“原 graph 所有轮廓已自然”。
