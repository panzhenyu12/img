# 像素蛋糕面部重塑：公开行为与本项目实现方向

检索日期：2026-10-15。主要来源为[桌面版官方手册：面部重塑](https://www.pixcakeai.com/guide/32466)，页面标注更新于2026-09-17。已通过浏览器实际展开目录阅读正文，并保存公开HTTP页面至 `.run/pixelcake-face-research/guide-32466.html`（SHA-256 `a35be22fcd7b0f66e4ea596236fdfe1f81ae3b6a0978841c57aada2914475711`）。这次没有操作像素蛋糕桌面软件、没有上传用户照片，不能声称完成同图竞品画质比较。

## 已确认的产品行为

| 官方功能 | 手册定义 | 对本项目的启发 |
| --- | --- | --- |
| 瘦脸 | 向内收缩太阳穴以下的脸部区域；左右可解除联动 | 不应把所有轮廓控制统称为瘦脸 |
| 小脸 | 脸部整体放大或缩小 | 需要独立的整体尺寸意图，不能拿横向收窄冒充 |
| 脸宽 | 调整脸部两侧线条、改变宽度；左右可拆开 | 区别于中下脸局部内收 |
| V脸 | 调整颧骨至下巴间的线条 | 需要不同的纵向作用曲线 |
| 短脸 | 耳朵以下长、宽同时调整 | 需要纵横比例协调，不只是下巴端点移动 |
| 脸型预设 | 七种预设包含脸型、眉毛、眼睛、鼻子、嘴巴的多个滑杆，另有程度控制 | 应设计成可解释、可再编辑的组合意图 |
| AI面部流畅 | 针对凸颧骨、凸下颌、太阳穴/脸颊/下巴凹陷、方下巴等 | 轮廓平顺与宽度是独立目标，收窄并不自动变美 |

七种预设的官方说明：经典（瘦脸加大眼）、幼态（五官排布）、英气（缩小脸盘）、少年（轮廓流畅）、圆脸适用（缩脸颊、塑下巴）、长脸适用（缩中庭与下庭）、方脸适用（缩下颌角、流畅棱角）。上述是官方产品描述，不是实测效果承诺。本项目不将性别、年龄当成必须套用的审美规则。

[官网首页](https://www.pixcakeai.com/)宣传“像素级脸部骨骼点”和“3D骨骼定位点”，但未披露具体模型、损失函数、采样或合成实现。因此不能据此断言其使用FLAME、神经流场或某种网格求解器。也不能从官网宣传图推断全部样片都无裂缝。

## 与当前实现的差别

当前 `core/image-core/src/face.rs::target_contour` 的 `faceWidth` 使用脸宽比例乘以中下脸作用带，额头/太阳穴基本由单独参数负责；内部眉眼鼻嘴以锚点保护。它更接近局部瘦脸，不等于“整脸大小”或七种组合预设。现有前端把它标为“脸宽 / 瘦脸”，后续应拆清语义，同时保持旧工程数值回放兼容。

目前缺陷包含两个独立问题：目标轮廓是否好看，以及原材料/露底/耳颈连接能否正确渲染。预设只能改变目标，不会自动修复分层合成；修好分层也不保证目标曲线美观。

## 采用方案

1. 保留现有局部调节，新增整体宽度曲线原型。相对于原脸中轴按不同高度协调收放，保留原脸的不对称与倾角；不把背景一起缩放。
2. 首轮 `natural / oval / soft / angular` 仅表示宽度曲线的实验模式，不能宣称等价于竞品完整预设。初始系数是工程假设，不是学习得到的审美标准。
3. 后续单独实现整体大小、下脸长宽、脸长及五官布局。在这些基础能力通过实图后，再组成自然修整、圆脸修整、长脸修整、下颌柔化等用户可修改的预设。
4. 参数组合先在原始解剖坐标中计算联合目标，再求一致形变并从原图采样，避免在多张中间图上重复液化。预设切换替换预设意图；用户局部修正作为独立增量保存。
5. 脸耳共享接缝、真实材料覆盖及露底重建继续单独推进。见[共享接缝设计](ear-shared-interface-design-20261015.md)与[FUNC-023](../func/FUNC-023-portrait-layer-matting.md)。

## 验证边界

固定原图、原检测与引擎哈希，比较原图、旧局部瘦脸、新整体模式；不能把降低位移当作曲线改进。报告各解剖高度的目标/实际位移，以及零值、保护区、透明度、旧工程兼容、采样折叠与原尺寸耳颈细节。用户提供的图属于开发样片，另需侧脸、笑脸、眼镜、遮挡和不同肤色持出图；现阶段不宣称达到8分。
