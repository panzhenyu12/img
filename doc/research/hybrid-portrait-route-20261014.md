# 人像重塑混合路线：Gemini 方案评审与实施决策

日期：2026-10-14。依据最新用户附件、当前源码、用户照片冻结回放、几何消融与官方项目资料。用户已取消 FLAME；本路线不再开发或下载 FLAME/DECA。

## 决策

采用“交互形变与异步精修分开”的架构，核心改为 **分层前景的连续可逆形变 + 物理覆盖率传输 + 材质条件局部补全**。原有背景保留原坐标，耳朵、头发、饰品与用户冻结区保持保护合同。整张图一起变形的保直网格不是默认路线。

用户要求优先采用前沿优秀算法。对新论文/模型以真实照片、任务适配、可复现实现和同输入对照选择；不将经典网格、LaMa 或泊松融合重新命名为最新 SOTA，也不把动画/三维资产生成的论文数字当修图质量。新版连续场候选与近期学习式模型均需验收后才能成为生产路线，当前不声称已经达到 8 分或世界一流水平。

## Gemini 数学解释的正确部分和错误部分

1. **共享三角形能建立连续映射，但不能承诺零裂缝。** 重心线性插值通常在共享边上 C0 连续，每个三角形内部为仿射映射，导数跨边一般不连续。所谓“分块 C1 刚性”不等于全图 C1 或局部刚体。翻转、自交、退化、错误 alpha 与合成都仍能制造不可用输出，必须检查正有向面积/Jacobian、连接、采样和覆盖。
2. **给出的平滑项不是 ARAP。** `||v'_i - avg(v'_j)||²` 是趋向调和平滑的拉普拉斯残差；没有保存原差分坐标或局部旋转，不保证局部刚性，也可能使形状收缩。真实 ARAP 的 local/global 迭代不能假定只有固定 RHS 的一次回代。
3. **固定法向的保直项可为二次项，但不是硬保证。** 关联点、法向和权重固定时，该项可进入线性最小二乘。任意线段通常不穿过网格顶点，应约束重心插值出的线段采样。有限权重会与瘦身目标竞争；即使严格保直，也未保证门框不平移、线距不变或非直线纹理不变。要精确保持某条背景线，应固定相应原坐标或明确硬约束。
4. **预分解复用有条件。** 拓扑、约束集合与权重不变时可以复用；活动遮挡、自动重网格、变化权重、非线性无翻折约束或 ARAP 更新会改变问题。SPD 还需要有效锚定与去除自由度。回代代价取决于 `nnz(L)` 及 fill-in，不是所有稀疏系统通用 O(N)。
5. **3–8ms、100–200ms 没有本工程依据。** 求解约 1000 个顶点不等于完成一百万像素的 matting、RGB/alpha 采样、合成和模型推理。24px 网格约 1800–1900 个顶点，32px 网格约 1089 个，也不能仅按 N 推断浏览器帧率。当前约 208MB 的客户端 LaMa 仍需加载和推理，神经阶段有内存成本。
6. **mask 差集只是露底候选。** 要用形变后的物理覆盖率、其他可见层和遮挡顺序决定最终未知区域；不能只做两个二值 face mask 的差集。收缩/扩张的错误机制不同，耳根连接断裂也不能当应当补掉的背景洞。
7. **crop 和 Poisson 有用，但没有必胜性。** 裁剪可能丢失结构上下文，大框仍会降采样；狭长弧形带的 bounding box 不一定很小。Poisson 引入的是梯度场，不只是高频；它能匹配边界但也可能改变内部色调，不能修正错误内容或身份。
8. **不能删除材质分层来解决采样错误。** 脖子、发丝与场景露底的语义不同，网格并不决定隐藏层是什么。`clip_supported_jaw_opacity` 应在可靠 coverage 传输替代后删除；当前耳侧主要裂缝位于它的作用区域之外，直接删掉不是该裂缝的因果修复。
9. **商业产品内部架构不能据此认证。** 附件没有提供 Photoshop、美图或 Facetune 内部采用该完整管线的可核验来源。因此这里只评估方案，不把品牌当技术正确性的证据。

## 已做的输出对照

用户原照的 frozen replay 与几何消融见 [几何专项](../qa/gemini-geometry-ablation-20261014/report.md)。全 exact、平滑 cache 切换、3px→8px 均未修复两处主要耳根黑裂。问题不是简单替换某个插值带宽。

本轮还以隔离的瘦脸 +100 候选为输入，使用记录的 source/new physical alpha、holes 与 frozen 生成露底目标。只允许 `old_alpha > 0 && new_alpha <= 1/255 && holes && !frozen` 的区域被模型修改，测试 crop64、crop128、crop128+Poisson、full 四种 LaMa 条件。模型与输入哈希、输出、耗时和合同数据在 `test/results/user-face-contour-20261014/local-refinement-ablation-20261014/report.json`；重放脚本为 `scripts/review_face_disocclusion.py`。

四个输出的未选区、冻区、alpha 改变均为 0，但都有把露底重新生成脸皮、削弱轮廓内收或留下细边的问题。这是拒绝直接自动启用 LaMa 的依据，不能当作新方案已达标。这里测试的是一个已有缺陷的单张 +100 候选，不代表所有照片或所有神经补全模型。此消融仅修改合成图中的近空 coverage 区，没有做完整的半透明 underlayer 重合成；详细边界与持久图像见 [露底实验](../qa/face-local-refinement-20261014/review.md)。

当前 CPU 上该次实验模型推理约 3.15–6.87s；初次总时间包含加载，约 6.90s，后续总时间约 3.86–6.96s。模型输入最长边 512。线程竞争、crop 范围和冷/热状态不同，不能仅凭这四次给速度排名；至少足以反驳未经测量的“本工程 100–200ms”。

## 近期方法的任务适配

对 DragGAN/DragDiffusion/FreeDrag、FlashAvatar/LGM、LivePortrait 的输入、训练、硬件、浏览器算子和精确冻结已检查官方来源，见 [专项核验](drag-avatar-liveportrait-applicability-20261014.md)。LivePortrait 的官方滑块是表情/姿态，没有瘦脸/腰腿美容控制；5D GridSample 也不能直接假定 ORT WebGPU 支持。FlashAvatar 是视频训练的头像且仍依赖 FLAME，LGM 是生成多视图后的三维资产，不用来替代当前真实照片滑块。

继续研究近期真实图点拖动、mask 条件图像补全与高分辨率 matting 的公开实现，固定版本与模型权重，优先能在当前硬件和实际照片复现的候选。比论文年份更关键的验收是：它是否真的改变指定轮廓、保留身份与纹理、处理背景和相邻层、能否在目标运行环境完成。

已进一步建立 [Inpaint4Drag，ICCV 2025](https://github.com/Visual-AI/Inpaint4Drag/tree/bfb0fafd456ac01ee23ade0cc04b64c9781eaa87) 的隔离实验：原样保留官方 `utils/drag.py`，从原图运行双向 warp，再用现有 LaMa 作本机补全基线。它更贴近“像素重塑 + 局部补全”的任务，但源代码使用 top-4 反距离位移、整数 round 和外轮廓填充，没有无翻折或眼睛保护保证。真实 ±30/±60/+100 对照中，原始形变带动五官，LaMa 补脸颊抵消收窄；因此不接生产。实验路径与限制见 `experiments/inpaint4drag-20261014/README.md`；论文的 GPU/SD 结果与本机 CPU/LaMa 实验分开。

## 落地顺序与验收

1. 连续场候选先替换五官/眉形直接逆偏移；检查眼睑完整外观、正负极值、组合参数、非方图与头部旋转，以及 f32 实际积分的 Jacobian 和逆向一致性。
2. 脸部由连续 forward field 及一致 inverse field 传输 RGB/物理 alpha；静止耳根与移动脸颊共享连接约束，避免 target 外皮肤岛、翻折与旧轮廓残留。数学通过后再以原尺寸图像验收。
3. 用层标签/遮挡和新轮廓生成真正的未知窄带，区分脖子/头发/背景条件，测试近期补全模型；仅接受实际改善而不重新长回旧脸的结果。
4. 通过后复用到腰/腿/衣物轮廓，再做预览与异步精修两阶段。最终结果绑定 source、graph、mask、模型、尺寸与 revision，过期任务结果不得覆盖新滑杆状态。
5. Rust native/WASM 均需同输入对齐；MCP/HTTP 使用同协议和质量边界。模型不可用时保留可用的手工路径，不能返回未编辑原图冒充成功。

每轮保存正负强度、目标控制误差、Jacobian 最小值/负值点数、保护/outside/alpha 变化、原尺寸边缘对照与冷/热耗时。保真合同和数值单测是必要条件，真实照片自然度是独立必要条件；不以其中一个替代另一个。
