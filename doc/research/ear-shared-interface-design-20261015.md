# 耳脸共享界面与耳饰附着：联合 SVF 设计

本文件只设计下一步接口，不新增 V9 渲染，不修改生产。依据是 `doc/qa/ear-accessory-attachment-v1-20261015.md`：新 ZIM 耳层找回漏掉的下耳垂；整耳固定压低脸部变形；只固定上根后用单个刚性耳旋转，整条接缝仍错位 2–5px。即使在同一上根下求最优旋转，接缝 RMS 仍为 1.06–2.46px，并牺牲耳垂目标约 2.7–4.6px。这个问题需要共同约束整条界面。

## 1. 可复用输入与合同

`PortraitAttachmentContext` 应随源图分析产生，与某次滑杆强度无关：

| 字段 | 含义 |
|---|---|
| `sourceIdentity` | 原图哈希、原始尺寸、分析版本；禁止跨图复用 |
| `coordinateFrame` | 原图像素中心坐标、crop→source 仿射；统一像素索引与 +0.5 语义 |
| `jointPhysicalCoverage` | 脸与耳这一连续表面的总物理覆盖 D；与语义置信度分离 |
| `materialOwnership` | face / ear 的软归属 Q，连续表面内部 Qface+Qear=1；不是两张互不相干的物理 alpha |
| `sharedInterfaces[]` | 有序源曲线 Γ(s)、面侧/耳侧法向、有效区间、定位不确定度、两侧可见材料证据 |
| `rootAttachments[]` | 上耳根与头部的真实连接区间或可信固定支持；不能只用一个任意点代表整片连接 |
| `accessoryAttachments[]` | 有可见支持的 lobe 点/小面片、金属挂点、原始相对向量、刚体形状、置信度 |
| `occlusionLayers[]` | 头发/金属等前景遮挡的独立物理覆盖和顺序；保留不确定的遮挡次序 |
| `unknownRegions` | 被遮挡且无法从原图观测的背后颜色/纹理，不能标成已知背景或皮肤 |

耳脸内侧界面不是外部人物轮廓。界面曲线可由 neural ear ownership 与可见连续皮肤共同提取；遮挡或断开的区间标记为 unknown，不用直线跨过耳饰、头发去假造接口。当前 ZIM 单图输出仍是模型假设，官方 score 只用于候选选择，不等于抠图真值。

已实现可复用组件：

- `experiments/ear-accessory-attachment-v1-20261015/run_ear_matte.py`：源图自动提示、左右独立耳材料、保留全部候选与 official argmax。`ear-matte-v6/` 有真实耳垂支持及对比图。
- 同目录 `attachment.py::observed_lobe_contact`：要求 ear/skin 可见材料靠近金属挂点；拒绝“数学挂点相连但实际耳垂缺失”。
- `attachment.py::attachment_transforms`：可以复用刚体附件保持向量和形状的部分；**不应继续把整耳 rigid pivot 作为默认变形模型**。
- `test_attachment.py`、`test_partition.py`、`test_contact.py`：7 项合同检查；`verify_native_ears.py::transport` 可用于同一源点的实际前向位移验证。
- `audit_v8_seam.py`：整条界面对应点的 RMS/max 和最优刚性拟合反证。不能用单个 hook gap 替代这个指标。

## 2. 联合场：同一接缝只有一个位移

整体脸型模式与局部五官/脸颊滑杆先产生一组语义目标，再交给同一个联合变形求解器；不要先做一次整体瘦脸，再对某个局部叠另一张独立变形图。耳作为共同表面里的一个较硬材料域，脸与耳共享 Γ 上的自由度。

可以保留现有 stationary velocity field (SVF) 表示。设共同速度场为 v，实际图像映射 φ=exp(v)。在同一个 basis/网格中，耳侧和脸侧使用 Γ 上的同一变量，故同一源点只积分一次，得到唯一 φ(Γ(s))。若实现需要分域求解，也必须施加 `v_face(Γ)=v_ear(Γ)`，并在有限宽度接口邻域惩罚导数跳变；不能各自算完目标再用 alpha 羽化掩盖错位。

能量项建议：

1. 脸型语义目标：源轮廓到目标曲线的实际 φ 位移误差，沿弧长采样并包含曲率/转折约束。整体脸型模式给完整目标曲线，局部控制调整其中一个可解释分量。
2. 耳部形状：相对源耳的局部旋转/应变惩罚，允许为连续连接而产生小的非刚性余量；不强求整耳只剩一个旋转角。
3. 共享接口：同一节点强制相同位移；有限带宽平滑导数，避免耳垂附近局部剪切。上根使用观测支持，显式用户保护保留最高优先级。
4. 整体可行性：Jacobian 下界、逆映射误差和必要的碰撞/遮挡检查。数值无翻折仅是几何必要条件，不保证纹理、视觉自然度。

SVF 的目标位移不等于速度值。先求速度，再积分 exp(v)，根据实际目标残差迭代校正；每轮检查整条界面及真实源轮廓，而不是只检查控制点或最大位移。重复使用同一连续场有利于连续性，但有限采样/积分仍需验证，不能承诺“数学上永远无裂缝”。

## 3. 材料合成与可选耳饰刚体

脸和耳是相邻连续材料，不应把两个语义置信度分别当作透明度做 source-over。可用同一总覆盖 D，内部用归属 Q 分配预乘颜色：`P=D*(Qface*Fface+Qear*Fear)`。共享界面和两侧邻域使用同一个逆映射、同一次采样足迹，再与外部背景合成；这样不会因为语义归属切换而在不透明皮肤内部凭空扣掉覆盖。

头发、金属等实际前后遮挡仍用独立层。耳饰选择“保持附着”时，在耳垂有可见支持的小面片上取联合 φ 的实际运动，给金属一个保持距离/角度的刚体变换。吊坠可以保持重力朝向而仅随挂点平移；穿孔刚体可跟随局部旋转。两种是明确模式，不从单张图自动声称能推断其物理行为。用户显式冻结耳饰时，冻结约束参与脸/耳联合求解，不能合成末尾硬贴回原图制造接缝。

禁止继续使用 `native image + new model - old model` 的静止残差方式作为最终可动材质实现：V8 在较大位移下已显示旧耳和金属的残影。最终 compositor 应接收原生材料/覆盖和共同映射，从源图重建目标，不在已变形结果上再搬一遍。

## 4. 遮挡未知与验收

缩脸露出的背景、扩脸后耳朵背后的皮肤都可能是原图未知。联合几何只能把“哪里新露出”算准，不能凭空得到纹理。先输出 disocclusion mask 与支持来源；可见邻域推断、神经补全分别标明估计。补全只处理新露出区域，不能全图重绘或拿未知区作为下一轮的已知 donor。无 AI 时仍保留手工图形功能与局部修复工具，但不能把无依据复制的纹理宣称为原图真实内容。

下一轮最小有效验收为：相同源点上整条 Γ 的目标间隙、导数跳变和曲率；真实 lobe/金属向量和材料支持；全曲线实际位移保持；零值逐字节 identity；透明度守恒；源耳/金属旧位置残影；无关背景及显式保护；1×/局部放大视觉。先用户 ±100 的共享界面通过，再加 ±30/0 和更多耳型、侧脸、遮挡样片。当前尚未通过，接口设计不等于达到 8 分。

这些输入/目标/诊断应是平台无关数据，Rust native/WASM 使用同一合同；MCP 或 AI 只提交整体脸型模式、局部参数、附件模式与 source identity，调用同一操作层并得到实际生效幅度/质量诊断，不另写一套 AI 专用变形算法。
