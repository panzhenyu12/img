# 基于近期研究推进人像形变算法

日期：2026-10-14。用户授权：找不到适合的现成算法时，根据最新研究自行推进。目标仍是可用的脸型、五官和身形重塑；效果、身份与细节保持优先，性能随后验证。

## 技术依据和本项目需要解决的问题

ICCV 2025 的 [Inpaint4Drag](https://arxiv.org/abs/2509.04582) 支持将像素形变与未知区域补全分开；我们的 [原照复现](../qa/inpaint4drag-20261014/review.json) 同时发现官方 top-4 位移插值带动五官，通用 LaMa 补全把脸颊补宽。采用它的任务拆分，重新设计形变、固定连接与物理覆盖率，不直接复制官方场。

DragDiffusion/FreeDrag 的内容保持、跟踪与回溯思想可以用于目标控制和迭代验收，但真图反演/训练不能成为手工滑杆的强制依赖。[官方适配核验](drag-avatar-liveportrait-applicability-20261014.md) 已记录真实用途和硬件边界。近期 matting/条件补全模型作为独立候选，不以模型名代替本地实拍结果。

这是一条本项目的算法研发路线，借鉴公开研究并作针对性改造。RBF、速度场积分等数学组件本身并非本项目发明；尚未做发表级创新性核验、也不宣称 SOTA。

## 形变场设计

1. 在像素坐标中，以源轮廓和可靠五官/解剖位置定义控制点 `s_k`，滑杆给出要求的目标 `t_k`。耳根、眼睛、发丝、饰品与用户保护明确进入运动约束。请求目标、约束后目标、实际到达位置分别保存，防止保护导致无作用却被记成成功。
2. 以紧支撑光滑基函数表示速度场：`v(x) = g(x) Σ c_i φ(||x-s_i||/r_i)`。当前人脸隔离候选使用 Wendland C2 和成熟 nalgebra 分解；`g` 是由编辑范围和可信固定域得到的连续运动权重。它不是背景位移场。
3. 从速度场积分 `dF_t(x)/dt = v(F_t(x)), F_0(x)=x`，正向 `F_1` 传输轮廓，逆向 `F_-1` 采样像素。RGB、物理 alpha、目标边缘由同一映射决定，避免“轮廓一套公式、颜色另一套公式”。当前数值原型使用 f32 RK4，步数随梯度预算增加；离散实现仍需检测，不能仅以连续方程声称绝不翻折。
4. 以实际 `F_1(s_k)-t_k` 残差迭代拟合系数，配合正则化，减少曲线目标与流场实际到达位置的差异。每次更新检查三角有向面积/Jacobian、反向误差与固定域，失败则回溯或拒绝候选，不在最终图像上硬切掉问题。
5. 固定域不从“本人低置信边缘”猜另一人。`subjectMask` 在现有 face host 里是类别组合的 personAlpha，不能直接视为独立人物 instance。对可疑固定岛记录来源、类别概率、物理 alpha 和上下文，单因素验证；真实另一人、衣物、耳饰与用户冻结不能因这项修正被放开。

相较直接 `x + displacement(x)` 或最近曲线段切换，这条路线的可检查优势是：可逆流对应、统一 coverage、约束域中的连续衰减和实际目标残差。它仍需要正确的解剖目标与底层材质；数值无翻折不等于照片自然。

## 分层与露底重建

已观察的背景保持原坐标。移动脸部/身体层以逆流采源物理 alpha：`a_new(p)=a_old(F_-1(p))`；前景颜色按预乘格式采样，原始 RGBA alpha 和图层物理 coverage 分开。耳朵/头发/饰品按原层保持，扩张时只允许目标主体遮住本来可编辑的背景。

露底来自旧/新覆盖以及其他可见层的遮挡顺序。将真正未知区域分为脖子、头发或场景，只重建相应下层，再以新主体 alpha 合成。不能直接让模型改已经合成的人脸边缘，或允许它把场景露底重新生成脸皮。当前 LaMa 直接合成图修补的失败见 [露底消融](../qa/face-local-refinement-20261014/review.md)。

后续条件补全须同时使用：原图可见内容、新轮廓/coverage、可用材质/遮挡先验、目标输出权限。模型负责缺失纹理，不替代几何和保护。客户端和服务端可用不同模型 runtime，但允许修改范围和合成器共用 Rust 定义；没有模型时保留已验收的手工路径。

## 新假设：保留真实连通皮肤，取消内部分类切口

固定上颈与移动脸缘存在真实冲突，v18把请求20px约束成约8px就是证据。另一个可验证假设是：脸和可见上颈属于同一连通前景，用同一速度流运输；face/neck分类交界是内部材质标签，不应被当成透明边缘。下颈/衣领保持零速度，不把皮肤alpha在任意高度截断。只在真正skin与背景/发丝的外边界重建露底，减少猜隐藏颈部的范围。

现有parser的skin组在阈值前已经聚合face-skin/neck概率，联合faceContourMask可改善这一内部交界；两个阈值后的group取max仍不是raw概率union，更不是物理真值。它只是有限种子，需要原RGB边缘校正、可信连通组件和固定层排除。此路线不扩大图像授权范围，不移动背景，也不能由face标签位移冒充外部轮廓位移。因果分析、源码位置和测试契约见[联合上颈分析](face-upper-neck-joint-alpha-causal-20261014.md)。

一次隔离v19已实现、运行并冻结：同一原图±30/±100四档保留请求幅度，+100实际源face polygon约20.075px；估计联合外边缘y535左右内收约18/20px，原尺寸RGB可见大黑楔与脸颈斜接明显减少。四档耳发饰品/9个五官内部/region外/alpha变化0；收缩scene变化0，扩张允许的新覆盖单独记录。原ROI附近实际mapper在本图归零，不能推广。新增joint输入/内部scene洞/低颈固定测试与原face测试共40通过，3.00–4.72秒native总进程不算实时。仍有12px原皮肤岛、耳根细点、硬边与多原片缺口，未接生产/公共WASM、未达8，见[v19主QA](../qa/face-joint-v19/review.md)与[独立原尺寸评审](../qa/face-joint-v19-root-review/review.md)。

## 验收和下一轮研究

- 每个脸型/五官参数至少零值、正负中强度与极值，组合、旋转、非方图、硬/软选区、冻结和相邻人物。既检查目标轮廓位移，也在原尺寸看裂缝、阶梯、光照与纹理。
- 检查**完整实际采样映射**的 Jacobian 与逆向误差，不能只测试积分内核。最终静止供体回退、保护合成或额外矫正可能重新引入断层。
- 保存同输入/检测/参数/模型/二进制哈希；输出权限、alpha、固定五官、背景纹理分别验证。失败不能用缩略图、减强度或另换检测掩盖。
- 为露底建立有 clean 参考的受控实验：用原照片扩张主体遮住已观察背景/脖子，再收回，比较重建区域与原来的真实像素。它是同一原照的派生实验，不增加独立样本数，也不代替真实瘦脸目视验收。
- 验收后再做稠密场缓存、局部计算、GPU 重采样与“拖动预览/停下精修”两阶段；记录真实端到端冷/热耗时。MCP 通过同一 Operation 调用，不另写算法。

这轮的完成依据是实际失败被修复、正确范围有可见效果且无新副作用。论文年份、构建成功和像素变化量都不能代替它。
