# 人像美颜与图形修图功能清单

版本：v0.1

范围：这是完整产品需求目录，不是本期 Demo 的已实现清单；P0/P1/P2 是完整产品优先级。本期交付与限制以 [第一期计划](phase1-development-plan.md)、`doc/func/` 和 QA 记录为准。

定位：第一阶段实现不依赖 AI 和网络的本地修图能力。AI 后续作为自动识别、自动生成蒙版、自动推荐参数和生成式修复入口，不能成为基础编辑功能的前置条件。

优先级：

- **P0**：第一版必须支持，构成离线手工修图闭环。
- **P1**：第一版完成基础架构后加入，构成商业人像修图能力。
- **P2**：后续增强，通常依赖更复杂模型、生成式算法或云端任务。
